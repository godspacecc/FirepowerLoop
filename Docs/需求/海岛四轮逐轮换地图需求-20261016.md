## 1. 已确认目标与范围

海岛保留四轮主线战斗，**每轮进入一张不同的地图**。四图共用海岛风格，但地形、路线、地标与主要事件不同，不能仅替换背景或旋转场景。

本项只整理首个海岛主题，不扩展到全部40轮。四轮暂采用固定布局和固定的入口安排；入口组合随机以后单独研究。轮内按既定进度切换来敌方向属于本项事件，不等同于随机入口系统。

| 已确认事项 | 需求口径 |
| --- | --- |
| 四图顺序 | 登陆滩头→礁石湾口→沉船浅滩→营火高地 |
| 事件规模 | 每轮突出一种主要空间应对，采用入口、浅水路线与营火，不加入实时涨潮、断桥等复杂事件 |
| 宝藏房 | 保留第3轮后的安排；完成或按现有规则退出后直接前往第4图 |
| 普通轮离场 | 清场后允许拾取剩余物品，由玩家主动进入出口并确认前进，不因继续射击自动换图 |
| 随机变化 | 本项先不做入口组合随机、随机地图或随机主路径 |
| 中途退出 | 每轮开始前保存；未完成轮中断后，从该轮开始前节点重试，不必重打整个海岛 |
| 临时武器和增益 | 跨图保留剩余时间；转场不计时、不清除、不刷新、不重复发放 |

地图名称为工作名。尺寸、摆放细节、事件预警时长和表现素材尚需细化及验证，不因此改变上述范围。

## 2. 主线流程

**第1图／第1轮→第2图／第2轮→第3图／第3轮→宝藏房→第4图／第4轮→巴比伦遗迹或弹幕林地。**

宝藏房属于第3轮后的奖励流程，不计为额外战斗轮，也不代替四张主线地图中的任何一张。敌群分批进入、入口接替也不增加轮次数。

普通轮清场后：结束本轮新生成与伤害事件，保留可拾取的剩余物品，显示出口；玩家进入出口后确认离场。确认前明确提示未拾取物不会带入下一图。未确认时不因开火、靠近地标或等待而自动开始下一轮。

第3轮清场后走宝藏房流程，不提供绕过宝藏房直接去第4图的新入口。宝藏房保留现有奖励、限时与退出方式，不改成普通清场后的不限时拾取。其既有返回／时间结束等出口结果应衔接第4图，不再返回旧地图开启第4轮战斗。

第4轮完成后保留两个后续主题方向及原路线条件；通过对应出口确认选择。不新增金币买路、额外海岛Boss或新的主题结算奖励。

## 3. 四张地图的内容要求

### 3.1 第1轮：登陆滩头

| 项目 | 要求 |
| --- | --- |
| 空间 | 以开阔沙地为主要战斗区域，浅水集中在可辨认的岸侧，少量岩石或棕榈等地标帮助辨方向 |
| 路线 | 出生落脚点安全；保留连续绕行与撤退空间，出口呈现向岛内前进的方向 |
| 主要事件 | 岸线来敌：先让一个方向的入场可识别，再引入另一方向的有限敌群 |
| 玩家应对 | 在陆地保持移动和射击，可绕行或利用现有冲刺解围 |
| 反馈 | 水花、脚步、入口运动或方向提示与实际生成方向一致 |
| 结束 | 清除本轮有限敌群，开放前往礁石湾口的出口 |

本轮帮助认识水陆区别，不新增溺水、潮汐伤害或设施任务。不能要求必须消耗炸弹／冲刺才能过关。

### 3.2 第2轮：礁石湾口

| 项目 | 要求 |
| --- | --- |
| 空间 | 两侧湾口由礁石或残骸地标分隔，中部及外围有连通路线 |
| 路线 | 玩家可以观察并转移到另一侧，不形成无法预判的死角或单向堵死通道 |
| 主要事件 | 湾口换防：两侧入口按固定顺序分段接替，换向由既定敌群批次进度触发 |
| 玩家应对 | 根据预告提前换位，或保留原站位处理绕来的敌人 |
| 反馈 | 新方向启用前有声音及可见方向提示，不在玩家脚下突然生成 |
| 结束 | 清除本轮全部既定敌群，开放前往沉船浅滩的出口 |

换向停止旧入口后续生成，不删除已进场敌人，也不无限追加敌人。错过换位只带来局势压力，不额外判定任务失败。此处换防指玩家站位变化，不涉及炮塔。

### 3.3 第3轮：沉船浅滩

| 项目 | 要求 |
| --- | --- |
| 空间 | 以沉船／大型残骸为主题地标，陆地形成弯曲且连续的环路，浅水提供较短跨区路线 |
| 路线 | 陆路较长但保持正常移动效率；浅水近路承担减速风险，两者均可达 |
| 主要事件 | 水陆取舍：水侧与陆侧的有限来敌批次配合路线，使转移路径成为实际选择 |
| 玩家应对 | 根据敌群位置选择长陆路或浅水近路，冲刺为可选手段 |
| 反馈 | 岸线、水色、敌人入场过程可辨，玩家进入浅水前能理解路线差异 |
| 结束 | 清场后进入既有宝藏房；宝藏流程结束后进入营火高地 |

浅水保持固定，不实时改变碰撞或岸线。近路不能成为唯一出口或唯一躲避路径，不增加采集材料、护送或付费开门要求。

### 3.4 第4轮：营火高地

| 项目 | 要求 |
| --- | --- |
| 空间 | 营火位于中部，外围保持连续可绕行通路，离岛方向有清晰地标 |
| 路线 | 不消耗冲刺也可绕过危险区；营火不能封死出口和唯一退路 |
| 主要事件 | 营火启用：活动战斗阶段启用营火危险，配合外围固定方向的有限敌群 |
| 玩家应对 | 识别危险边界，利用外围路线转移、射击，避免追物品时误入中央 |
| 反馈 | 火星、声音和地面危险范围一致，正式伤害开始前有可读预警 |
| 结束 | 清场后关闭伤害条件，开放巴比伦遗迹与弹幕林地的后续出口 |

“高地”先表达场景层次，不要求加入跳跃、攀爬或落差战斗。营火不追踪玩家，不扩展为随机多火圈；敌我伤害与机关计分关系沿用现状核对，不作为本项重做内容。

## 4. 换图继承与临时效果

### 4.1 连续带入的状态

当前角色、已持有装备、生命、命数、分数、倍率及应急库存保持连续；换图不等于重新开局，不额外赠送或补满。原有按轮补给规则仍在对应轮次执行一次，不因地图加载或宝藏进出多执行。

敌人总量、同屏上限、武器强度、敌人强度及原有按轮恢复不在本项主动重定。实施前核对原规则，避免把场景初始化误当作新局初始化。

### 4.2 临时武器和增益：明确继承规则

1. 离开地图时保存当前临时武器／增益的身份、剩余时间，以及已有剩余次数、护盾量等必要状态。
2. 下一图恢复同一份效果与剩余状态，不能重新按完整持续时间发放；已耗掉的次数和额度不恢复。
3. 出口确认后的转场、卸载、加载及等待可操作期间，不消耗这些效果的剩余时间，也不继续自动攻击或结算效果。
4. 回到可操作的局内状态后，按原玩法计时规则继续；不新增“只有敌人在场才计时”的规则。清场后仍在原图自由拾取的时间，不自动算作转场冻结。
5. 普通暂停遵循原暂停规则；仅暂停或重开界面不刷新效果。若剩余时间本已耗尽，不因换图重新激活。
6. 宝藏房进出同样不因加载额外扣时或补时；房间内实际活动期间仍按原规则处理，不把整个宝藏阶段都算作转场冻结。宝藏本身计时规则不在此重做。

跟随物、固定锚点或临时视角等特殊效果须在实施前逐项核对：身份与逻辑状态要保留，旧地图实例不能直接残留，也不能因重建重复发放、恢复耐久或多生成一份。新地图的挂接与合法位置适配是技术待核对项，不能以此默认取消已确认的跨图继承。

本项不新增临时效果，也不为解决适配而顺带改变箱子、商店等获取方式。

### 4.3 离场清理

旧图敌人、弹丸、伤害区域和未拾取掉落不带到下一图。清理世界实例时必须区分上述内容与应当继承的角色效果，不能用“清场景”一并清除临时武器和增益。

恢复后当前轮次、地图、敌群预算、入口批次与主要事件必须一致。旧图危害不得在新图隐形生效，新图也不能重复保留旧图的自动攻击实例。

## 5. 轮级保存、中断与恢复

### 5.1 已确认的玩家体验

每轮正式开始前建立安全节点，至少包含当前轮次、目标地图、既定入口／事件进度起点、角色状态、库存、临时效果剩余状态及已有成绩。

战斗轮中途退出后，从该轮开始前节点重试，不保存半空弹丸或敌人的即时位置。该轮未提交的奖励、拾取、库存消耗、生命及临时效果变化一并回滚；不能只保留奖励、只回滚损失。已完成并提交的前轮不必重打。

这与“效果不因换图刷新”不同：正常换图保留离场时的实际剩余时间；整轮重试恢复该轮节点的整份状态，不是给现有状态额外补时。界面需明确说明恢复位置与该轮未提交进度会回滚。

### 5.2 第3轮与宝藏房的特殊边界

第3轮开始前有轮级节点；第4轮节点只能在宝藏流程结束、其奖励及消耗确定后建立。不能只记“第3轮已清完”便跳过尚未完成的宝藏，或恢复时再次发放已提交奖励。

本项不额外要求新增宝藏房中途续玩。最小恢复口径为：宝藏中断时回到第3轮开始前节点，将第3轮及其后宝藏的未提交收益和消耗整体回滚；第4轮节点建立成功后，才从第4轮开始恢复。此为落实轮级保存的文档口径，具体存储流程需技术核对，不允许留下已领宝藏、读档再领的路径。

### 5.3 转场失败与旧存档

目标地图及节点建立成功后才进入战斗。加载或保存失败应提供可重试状态，不扣命、不重复计轮、不重复发补给或奖励，不启动无地图战斗。

轮级存档涉及原整场存档的兼容。现有存档版本、迁移或旧局继续方式须实施前核对，不能提前宣称兼容完成；不把静默删除旧进度列为本项处理方法。

## 6. 固定布局与表现边界

本项四张布局、主路、宝藏衔接、营火位置及入口顺序固定。第2轮入口换向是固定脚本过程，重试时一致；随机组合留待后续独立讨论。

障碍物的画面、移动碰撞与射击遮挡需一致，通路能够支持现有角色移动、敌人进入和冲刺。每张地图都要有不用特定库存或特定武器也能完成的路径。

优先完成轮廓、通路、入口与危险区可读性，再完善水花、换向、营火启停及出口反馈。优先盘点现有沙滩、水岸、岩石、棕榈、营火素材；沉船等资源的可用性待核对，不以摆放装饰代替有效地形差异。
