# 农场（配置22，本局第3关）

2026-10-22正式接入，累计第9—12轮。farm-v3四区、牛v1和FarmArt-v1环境均获确认；竞速暂缓，不插入半成品竞速。

- 场地半宽、半高均30.5米，四个约28米区域通过固定门洞和破墙互通，石墙、棚屋和草垛等实体区域不可穿过。2026-10-23按用户采用的Unity候选将满地积雪替换为低饱和草地与少量土斑，树冠绿色、屋顶棕色、草垛金黄、墙顶石色；保留原模型、通路与角色尺寸。配置号和文档路径沿用原标识，不影响旧存档。
- 四轮复用固定地形。敌人总数均分到四条真实出入口，通道随机排序且不重复；一批实际刷出一半即开启下一通道，原通道继续按该轮间隔刷完，共享原总数及存活上限，无额外方向提示。
- 牛群首次在8活动秒生成，之后间隔18秒。每批五头、单排、间距1.65米，沿南侧缺口东西交替穿场；起势0.8秒、速度12米/秒、行程66米、接触半径0.65米。均为项目参数，不是原作精确数值。
- 牛只在冲撞阶段伤害：玩家最大生命25%、敌人最大生命100%，经过原护盾、冲刺、无敌、护甲与死亡入口。同一头牛同次冲撞对每目标至多一次；场景伤害不冒充玩家击杀发奖。
- 整排先同步推进，再裁决可能触发复活的伤害；暂停、清场、加载和复活等待冻结。换图清理，轮前恢复不保存半次冲撞；双人同步同一权威姿态。
- 每轮清场有金币宝箱；普通轮走通道，第4轮结束在北侧中央门洞(0,14)出现整关传送门，避免十字墙中心堵住门，前往配置5。
