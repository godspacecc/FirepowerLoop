# 码头（配置21，本局第2关）

2026-10-22正式接入，累计第5—8轮。布局docks-v2与DockArt-v1外观已获确认，四轮复用同一固定地图；不是海岛第二轮的小码头。

- 场地半宽20.5米、半高19.5米，连续木平台、吊架、货箱、泊船和右侧水槽。平台与船梯可走，水面和实体货箱不能穿过；三条真实入场/离场通路。

- 沿用普通僵尸及载桶敌人；载体存活5秒后卸下独立吞物桶，提前击杀则沿原爆炸契约伤敌。预置桶(-3,2)，电塔(7,7)，不叠加旧军械库、破坏箱或护甲敌人。
- 四轮各有一次清场金币宝箱；普通轮清场接触通道过轮，第4轮清场后中央传送门前往农场22。新前三关只结算实际拾取，不额外自动发旧清轮/清关现金。
- 每轮六个空投候选点、两次投放，3—8秒首投，随后20—30活动秒再投，沿既有进度池和时效。枪械、基础AK与骷髅规则见[最终效果说明](../../Plans/前三关已确认制作最终效果-20261022.md)。
