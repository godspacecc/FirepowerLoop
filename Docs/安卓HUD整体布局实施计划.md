# 安卓 HUD 整体布局

用户已确认并授权实施。使用当前 Unity 项目，不创建 worktree、不打包、不自动提交。

- 左上保留任务目标、时间与撤离状态；右上提供现有暂停入口。
- 背包移到左侧摇杆上方；右侧保留滑屏、攻击和条件交互。
- 手机状态区独立序列化，底部居中，生命在上、四项原圆形进度条及数值在下；电脑布局保持原样。
- 手机隐藏操作说明与六格快捷栏，不更改物品、任务、撤离或联网权威规则。

实施顺序：先调整手机显示回归用例；通过 Unity MCP 修改 Prefab 并运行 UI 生成器；控制器响应输入模式变化；运行限定范围 EditMode 测试并检查引用和画面。

## 实施结果

- 手机状态区、左上任务区使用独立 Prefab 子树；生成器已生成 View 并完成引用绑定。
- 背包移到摇杆上方；移除摇杆英文占位文字；自定义摇杆避让背包和状态区，不覆盖保存的布局。
- 手机隐藏快捷栏和常驻操作说明；常规离线地图保留右上暂停入口，复用原热键仲裁。联机和街机仍遵循各自现有 HUD、暂停规则。
- 任务进度、目标、时间、撤离门禁仍读取原模型。电脑与手机的任务进度、语言和实体撤离门禁用例通过。
- 共 28 项限定范围 EditMode 用例通过，返回的测试名和执行数量均符合过滤要求；未运行完整套件或 Player Build。
- 额外两项旧流程检查失败：状态 HUD 用例期望加载后隐藏整张视图，而原控制器只隐藏内容；恢复远征用例被玩家缺少有效手电筒聚光灯阻止。没有扩展修改这些既有流程。
- 已检查正式 Prefab 渲染预览；安卓真机手感、刘海与系统手势区域仍需设备验收。未提交。
- 用户纠正状态样式后，手机四项恢复原圆环素材、颜色和内部数字排布；生命条仍在上方，整组保持底部居中。此修订的 5 项布局、实时状态和自定义摇杆避让测试通过。
- 后续用户确认：手机温度取消进度环，使用温度计图标与完整 °C 数值；图标和数值沿用原低温蓝、正常白、高温橙红判断，其余三个圆环保持原样。电脑温度显示不变。
- 最新确认方案已接入：手机能量、水分、体力分别使用鸡腿、水滴、跑步小人，图标居中，百分比位于原圆环下方；低于 20% 时图标和圆环转为警示色，恢复后还原。百分比按当前值与上限归一化，电脑仍显示原始数值。
- 温度计改为 56 高的长管与 44 高的液柱，液柱在 30～45°C 显示范围内升降；36～38°C 白色，向上下限连续渐变为蓝色或橙红色，下方保留实际摄氏温度。此映射仅负责表现，不改生存规则。
- 手机血条使用无圆角边界的等粗素材与水平填充；状态区高度调整为 124，将百分比纳入触控避让范围。正式图标位于 `Assets/Game/Art/UI/PlayerCondition/`，原第三方资源未修改，正式 HUD 不依赖备用目录。
- 本次 3 项 AndroidHudLayoutTests、1 项手机状态集成测试和 1 项自定义摇杆避让测试通过；所有 40 个生成引用有效，已检查正式 Prefab 渲染。未运行完整套件、打包或安卓真机验收，未提交。
- 最新收敛方案：安卓血条常驻；能量、水分、温度、体力以 44×44 图标组紧凑排列在血条上方，组间距 8，移除四项数值。能量、水分、体力仅未满值时显示；温度在 36～38°C 隐藏，异常时仍用液柱和渐变色提示。HorizontalLayoutGroup 居中收拢可见项，无隐藏占位；状态区高度为 92。
- 新布局的 3 项 Prefab/横屏检查、1 项实时显隐与居中集成检查通过，35 个生成引用有效；电脑继续保留原数值布局。人物属性分页未纳入本次实现。
- 最新位置调整：四项状态改为血条上方左对齐，从血条填充起点开始排列，行宽 200、间距 8；未满/异常显隐逻辑不变，隐藏项向左收拢。右侧预留 160 的异常状态显示空间，本次未接入异常状态图标。3 项布局检查与 1 项实时显隐/左对齐检查通过。

- 图标正式副本位于 `Assets/Game/Art/UI/UtilityButtons/`，无备用资源依赖；暂停竖线复用正式 Solid Sprite。Prefab 生成引用已绑定，上次 MCP 重试产生的重复暂停副本已清理。12 项按钮/暂停检查通过，图标最终替换后复验 4 项引用、布局、暂停和摇杆避让均通过；同步更新了旧背包位置和摇杆占位文字断言。未提交，安卓真机仍需确认操作手感。
