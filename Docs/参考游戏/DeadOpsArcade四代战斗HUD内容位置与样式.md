# Dead Ops Arcade 四代战斗 HUD 内容位置与样式

核对日期：2026-10-19。用途是确定原作实际显示什么、放在哪里、怎样显示，再与 FirepowerLoop 当前实现比较。范围先覆盖俯视战斗 HUD，优先首岛；不把设计建议图当成原作，不在此决定界面改版。

四代不能共用一份布局描述。二代样本的名字位于横条下方，三、四代样本位于分数上方；三、四代的倍率区也不是二代的横条。四代完整首岛图可见左上玩家信息、右侧竖排图标、底部轮数及敌人数。FirepowerLoop 桌面保留左上玩家卡片和右上独立炸弹与冲刺区；2026-10-19 接入的手机布局另用紧凑信息、竖向倍率条及右侧技能列，见[实际预览](../当前项目/FirepowerLoop手机横屏HUD确认布局.md)。

### 俯视战斗信息

位置数值为锚点下的 anchoredPosition；尺寸为 sizeDelta。左上锚点向下是负 Y；底部锚点向上是正 Y。表中的容器尺寸不表示整块区域一直有背景。

| 内容 | 当前落点与尺寸 | 当前样式 | 显示条件 |
| --- | --- | --- | --- |
| 玩家列表 | 左上 (24,-24)，容器 500×520 | 纵向行，间隔 8，本机排第一 | 实际人数驱动；不是固定显示四张空卡 |
| 单个玩家卡片 | 500×124 | 本机深蓝底，队友深灰蓝底；近不透明 | 列表中每个实际玩家一行 |
| 玩家名、血条、生命数 | 卡片首行，局部 x=12 / 154 / 310，y=-17 | 名字及生命白字；血条绿色，≤55% 黄、≤25% 红 | 血量和剩余命是两个独立内容 |
| 本局金币、分数 | 卡片第二行，局部 (12,-48) / (238,-48) | 金币金字，分数白字；均是带本地化文字的数值 | 当前分别显示，不能当成同一项 |
| 倍率文字与进度 | 卡片第三行，局部 (12,-79) / (150,-79) | 白色倍率，金色横条；满档条内显示状态文字 | 读取实际倍率与进度 |
| 倒地、重生、重连状态 | 卡片底部，局部 (12,-108) | 较小白字 | 有状态才显示 |
| 临时武器 | 左上 (540,-24)，容器 68×280 | 独立武器图标和消耗进度 | 剩余秒数大于 0 才显示 |
| 辅助效果 | 左上 (620,-24)，容器 360×280 | 图标、进度；有次数才显示次数；缺图时用短字占位 | 有有效效果才显示，条目随效果增减 |
| 炸弹、冲刺库存，桌面 | 右上 (-24,-128)，164×64 | 独立图标和次数；耗尽图标变灰 | 桌面显示；未与生命、分数合并到同一个玩家区 |
| 场地或挑战信息 | 底中 WaveStatus 内 (0,-1)，600×32 | 一行本地化文字 | 单人首岛优先地图名；联机显示场次；挑战替换为挑战信息 |
| 轮次、敌人数和阶段状态 | 底中 (0,2)，600×42 | 一行文本 | 轮次及敌人数；出口、休息、宝藏、拾取、加载等状态替换该行 |
| 轮开始、轮完成、岛屿完成 | 中部偏上，锚点 (0.5,0.68)，680×92 | 大字横幅，随时间淡出 | 阶段事件短暂显示，不暂停战斗 |
| 重生倒计时 | 中心偏上 (0,70)，880×112 | 中央提示文字 | 正在重生时 |

当前卡片的名字、金币、生命、分数、倍率文字均启用自动字号，常用范围为 19–23；状态为 17–21，满档文字为 18–22。不能只读取 m_fontSize=30 就断言实际显示 30。当前分数与普通字段使用相近字号，和 A3/A4 中“分数显著放大”的层级不同。

临时效果消耗条在剩余 ≤3 秒变橙红；平时武器条为金色，辅助条为青色。没有武器时整个武器容器隐藏，没有辅助效果时对应容器隐藏。
