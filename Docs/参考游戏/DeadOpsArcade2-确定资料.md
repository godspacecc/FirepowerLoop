# Dead Ops Arcade 第2代确定资料

整理／联网核对：2026-10-17。第2代序号不等于 Black Ops II。

| 项目 | 确定内容 | 证据 |
| --- | --- | --- |
| 名称 | Dead Ops Arcade II: Cyber’s Avengening | [官方系列回顾，2025-09-24](https://www.callofduty.com/blog/2025/09/call-of-duty-black-ops-7-zombies-deep-dive)，The Origin Story |

## 已确认的扩展

开发者回顾确认，第2代加入可持续一段时间的第一人称体验、Black Ops III 武器、新的连杀奖励、专家武器、载具及拾取物。对手 Cyber 是 Cosmic 的兄弟。[Treyarch：Dead Ops Arcade is Back!，2020年12月](https://www.treyarch.com/game-intel/2020/12/Dead_Ops_Arcade_is_Back)

“一段时间的第一人称体验”不能扩写成“本代从发售起就能全程第一人称”。武器和载具类别得到确认，也不代表其全部名单、伤害、操控或出现概率已经核实。

## 资料缺口

本次尝试读取 MKillBill 的[第2代攻略](https://gamefaqs.gamespot.com/ps4/145061-call-of-duty-black-ops-iii/faqs/72570?single=1)，正文获取失败；搜索结果只能确认攻略身份，不用于补写完整规则。未确认该攻略当前版本和完整更新时间。

因此本稿不确定：完整轮数与路线、所有奖励房及挑战、命运分配、生命经济、临时第一人称持续时间、载具参数、武器数值与平台支持差异。也不把第3代的 Solo Advanced Start 或第4代的 SlayerMart 归入本代。
