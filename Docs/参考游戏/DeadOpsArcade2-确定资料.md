## 移动、生命、积分倍率、核弹与冲刺

俯视时移动与射击方向分离。开局3生命、2冲刺、1核弹；每20万分给本人额外生命。倍率关系到积分续命，不能与生命库存混写。核弹用于清场，冲刺用于穿敌脱困。[MKillBill：Controls／How to Play](https://gamefaqs.gamespot.com/pc/209446-call-of-duty-black-ops-iii-zombies-chronicles/faqs/72570/controls-how-to-play)、[已取得的早期完整正文](https://www.cheatcodes.com/guide/dead-ops-arcade-ii-guide-call-of-duty-black-ops-iii-ps4-102803/)

键鼠绑定、倍率增量、无敌秒数与死亡重置仍须按版本核对，不把初代或后续代规则自动填入本代。

## 武器、临时第一人称、载具与拾取

## 奖励房

社区条目可辅助定位房间类别：Treasure Hoard偏宝物；Chicken Farm有待孵化蛋；Mystical Armory偏武器与支援；Nuke Armory偏核弹；Church偏防护拾取；Hangar偏载具。这是**二级资料分类**，库存数量和概率不在此定稿。[Call of Duty Wiki本代奖励房段落](https://callofduty.fandom.com/wiki/Dead_Ops_Arcade_II%3A_Cyber%27s_Avengening)

[MKillBill奖励房章节](https://gamefaqs.gamespot.com/ps4/145061-call-of-duty-black-ops-iii/faqs/72570/bonus-rooms)存在另一组房名，不能把别称直接相加为房间总数。TheMoZProject实录说明也列出实际遇到的奖励房时间戳，适合后续对照画面归一。一次流程不等于完整抽取表；本次没有证据支持“固定出口必得某房”。

## 四命运、获取与审判升级

19轮后经Temple Fortress到命运房；四角石形可辨，不能沿用早期镜像“无法辨认”的结论。基础效果如下。[MKillBill v2.5：命运与审判](https://gamefaqs.gamespot.com/ps4/145061-call-of-duty-black-ops-iii/faqs/72570/the-rooms-of-fate-and-judgement)

| 提示／别称 | 基础效果 |
| --- | --- |
| Fortune／Fortitude | 拾取持续时间延长；倍率保底2 |
| Destruction／Firepower／Fury | 默认Death Machine；武器红骷髅保底 |
| Companionship／Friendship／Favor | 常驻鸡；默认LMG紫骷髅 |
| Swift／Swiftness／Force | 常驻移速提升；新轮至少2冲刺 |

优先按提示与效果识别，不照搬Wiki当前名称错配。审判房升级已有命运；首次合作升级归属涉及石像伤害及救援表现，权重未公开。时间轴把石像／审判列在37轮后，应警惕二级资料写到44轮后的冲突。[同一攻略章节](https://gamefaqs.gamespot.com/ps4/145061-call-of-duty-black-ops-iii/faqs/72570/the-rooms-of-fate-and-judgement)

## 合作救援与借命

本代有**自动借命**，不能写成由玩家按键主动捐命。TheMoZProject在2026年3月的跨代说明中明确：DOA1／2从第1轮起就可能发生自动借命，而且没有手动捐赠。该说法来自长期实录／教学作者，属于一手社区说明；不把同一回复中DOA4的1生命保护规则归入本代。[TheMoZProject原回复](https://www.reddit.com/r/DeadOpsArcade4/comments/1ruptx1/thank_you_to_awf_and_ogranic_yall_were_excellent/)

队友援救与从队友库存自动借命应分开记录。自动借命的精确扣命条件、供命者奖励全表和援救时长仍需补证，不能把攻略中的“donation”字样翻译成已确认存在主动捐命按钮。[MKillBill：Critical Intel](https://gamefaqs.gamespot.com/ps4/145061-call-of-duty-black-ops-iii/faqs/72570/critical-intel)

## 特殊挑战与Cyber Boss

实录说明明确列出四种Silverback Challenge及入口；玩法类别可与[MKillBill挑战章节](https://gamefaqs.gamespot.com/ps4/145061-call-of-duty-black-ops-iii/faqs/72570/silverback-challenges-160-160-160-160160)对照：

- [Redins Rally，13:46](https://www.youtube.com/watch?v=0AqVpwwGtnY&t=826s)：竞速。
- [Temple Fortress，30:02](https://www.youtube.com/watch?v=0AqVpwwGtnY&t=1802s)：登塔，随后进入命运房。
- [Chicken Bowl，47:18](https://www.youtube.com/watch?v=0AqVpwwGtnY&t=2838s)：推蛋入篮。
- [Tank Vault Heist，1:45:46](https://www.youtube.com/watch?v=0AqVpwwGtnY&t=6346s)：坦克迷宫收集。

普通场地的Challenge Round与这些独立小游戏应区分。奖励门槛、时限和固定出现规律不能从标题推断。

64轮对手Cyber Silverback是初代Cosmic的兄弟；官方身份来源为[Treyarch回顾](https://www.treyarch.com/game-intel/2020/12/Dead_Ops_Arcade_is_Back)。Boss流程可定位到[实录2:34:23](https://www.youtube.com/watch?v=0AqVpwwGtnY&t=9263s)，更细的攻击与杂兵应对见[Silverback Trail](https://gamefaqs.gamespot.com/ps4/145061-call-of-duty-black-ops-iii/faqs/72570/the-silverback-trail)，不凭记忆填血量、减伤或技能间隔。
