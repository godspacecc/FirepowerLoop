# Dead Ops Arcade 第4代确定资料

整理／联网核对：2026-10-17。名称为 **Dead Ops Arcade 4: Papaback in Black**，所属 Call of Duty: Black Ops 7。项目主要参考本代 **Casual**，不混用 Normal、Hardcore 或其他代数值。

## 官方可确认的范围

2025-11-06发售介绍确认单人至四人、Casual 与 Normal、俯视与第一人称；有武器、载具、奖励房、Silverback Challenges、Slayer Maps 和70多项 SlayerMart 升级，以及弹药模组、战场升级、口香糖和统一玩家经验进度。文中80关／20多个竞技场是总览口径，不能直接当作 Casual 单局长度。[官方发售介绍](https://www.callofduty.com/blog/2025/11/call-of-duty-black-ops-7-launch-zombies)

官方2025-09-24的前瞻列出了 Papaback、Z-Rex、Guardian Golem、Mega Abomination 等对手与三种 Slayer Map，并把 Hardcore 和 Standard Advanced Start 列为发售后计划。该文摘要与正文的武器／拾取物数量不同，本稿不合并为精确总表。[官方玩法前瞻](https://www.callofduty.com/blog/2025/09/call-of-duty-black-ops-7-zombies-deep-dive)

## 攻略身份与商店事实

2026-10-17继续核对时，通过同一攻略的[PS4站点入口](https://gamefaqs.gamespot.com/ps4/539653-call-of-duty-black-ops-7/faqs/82246/the-papaback-trail)取得v1.45完整路线正文：Casual所有分支均40轮，击败Papaback结束；全局总量表独立于主题，单人40轮11650、双人13650，第30—40轮每轮分别400／450。作者标明为游戏行为与社区验证，并非官方数值表；不把其耗时估计当生成间隔。前文FAQ只有摘要的记录仍保留为首次核对状态。

本次取得的 MKillBill PC攻略页面页首为 **Version 1.45，Updated 04/08/2026（2026-04-08）**。这是攻略版本，不是游戏补丁号；本稿不声称其覆盖2026-10-17游戏全部最新调整。

该攻略明确：购物现金与普通积分分开；重抽券刷新库存；每次访问展示16项随机商品，并显示价格、图标、说明和可购买次数，现金不足锁定。商品包含独立强化、护甲、弹药模组和战场升级。[SlayerMart机制与策略](https://gamefaqs.gamespot.com/pc/539641-call-of-duty-black-ops-7/faqs/82246/slayermart-info-and-strategy)

原作完整价格、概率、叠加和多人领款机制并未因此全部查明。FirepowerLoop 的24候选池、等权抽取、优先未拥有、个人等额现金、每箱2000和交易幂等均为项目已定合同，不能根据“16项随机库存”扩写为原作事实。

## 主题与轮次编号

攻略目录列出以下20个主线主题：The Island、Babylon、Barrage、Graveyard、The Henge、Volcano Lair、Fort Courtyard、Church、Evil Garden、Koi Crossing、Piazza、Estate Courtyard、Motel、Museum、Nuketown、Homestead、Shiver River、Swamp、Spore Jungle、Papaback’s Lair。[攻略目录](https://gamefaqs.gamespot.com/pc/539641-call-of-duty-black-ops-7/faqs/82246/slayermart-info-and-strategy)

目录标题把Barrage标作9—12，但同页Casual实测表是本局5—8轮。**主题／目录位置与本局累计轮次必须分开。** Barrage页记录周边爆桶、多处敌人入口、中央绕行空间和倾斜屋顶；提示屋顶会落下爆桶。[Barrage正文，v1.45](https://gamefaqs.gamespot.com/pc/539641-call-of-duty-black-ops-7/faqs/82246/barrage-9-12)

该页Casual表：单人5—8轮150／160／170／180敌人，双人200／210／220／230；下一场可选Graveyard或Nuketown。这是整轮总量，不是同屏数，也不证明本项目所有主题已使用相同密度。该页提示爆炸可能伤及玩家，与仓库此前敌人条目研究存在冲突，未据此确认所有桶的伤玩家规则。
