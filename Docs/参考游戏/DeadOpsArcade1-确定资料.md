# Dead Ops Arcade 第1代确定资料

初次整理：2026-10-17；玩法补充：2026-10-19。对象为2010年《Black Ops》内的第1代，以下玩家攻略不覆盖移动端移植版，也不把后续代规则倒推到本代。

## 版本身份

| 项目 | 确定内容 | 证据 |
| --- | --- | --- |
| 所属作品 | Call of Duty: Black Ops，2010年 | [官方系列回顾，2025-09-24](https://www.callofduty.com/blog/2025/09/call-of-duty-black-ops-7-zombies-deep-dive)，The Origin Story |
| 初始入口 | 主菜单隐藏电脑终端中的彩蛋 | 同上 |
| 操作类型 | 街机式双摇杆射击 | 同上 |

## 已确认玩法

开发者回顾明确：玩家从主菜单挣脱审讯椅，在终端输入 DOA 解锁；初始三条命、无限弹药，逐关消灭僵尸，拾取武器、财宝及强化，支持合作，主要对手为 Cosmic Silverback。[Treyarch：Dead Ops Arcade is Back!，2020年12月](https://www.treyarch.com/game-intel/2020/12/Dead_Ops_Arcade_is_Back)

这些事实足以确认本代的“移动射击—消灭敌群—拾取—生存推进”基础。无限弹药不证明所有临时武器无限持续；三条初始命也不证明生命上限或加命阈值。

## 一局怎样进行

按玩家攻略，玩家独立移动、转向和开火，在竞技场内躲避敌群，轮间收集财宝并选择出口；每个场地连续四轮，地图会改变朝向或可见条件。普通僵尸接触即可致命，操作重点是保持退路，而不是站着承伤换血。多人最多四人，但单人、两人和多人合作的站位与资源分配不同。[PC实战攻略，2014-04-16](https://steamcommunity.com/sharedfiles/filedetails/?id=249845040)

## 生命、计分与两种主动能力

初始3条命、1枚核弹、2次闪电冲刺。每累计200,000分给本人加1条命；财宝和宝石还会推动计分倍率。普通死亡会损失倍率，因此拾取与保命互相影响。[MKillBill攻略，Controls / How to Play、Item Pickups](https://www.supercheats.com/playstation3/walkthroughs/callofdutyblackops-walkthrough10.txt)

核弹用于清理围困敌群；闪电冲刺穿过敌阵，既能开路也能杀敌。它们是可消耗资源，不是普通射击。攻略记载普通角色开新轮时，冲刺为零会补至至少1次；不能理解为每轮额外叠加1次。[MKillBill攻略，General Advice](https://www.supercheats.com/playstation3/walkthroughs/callofdutyblackops-walkthrough10.txt)

合作还存在零命队员自动借用队友生命的机制；这不同于FirepowerLoop的主动捐命按钮。借命对象、间隔和补偿细节仍需专项复核。

## 武器如何改变打法

默认武器是无限弹药的M60；特殊武器是拾取后临时使用的火力，不能把“无限弹药”理解为特殊武器永久保留。以下仅概括用途，不给出未核实的伤害或精确射速。[jimmythesnowman攻略，Weapons](https://www.supercheats.com/pc/walkthroughs/callofdutyblackops-walkthrough01.txt)

| 武器 | 玩法差别 |
| --- | --- |
| Death Machine | 更强的集中连射，适合持续压制 |
| SPAS-12 | 扇面散射，处理近距离敌群 |
| China Lake | 榴弹落点爆炸，处理成群目标 |
| RPG-7 | 火箭与爆炸火力 |
| Ray Gun | 特殊能量弹，弹道与即时命中表现不同于机枪 |
| M2 Flamethrower | 持续燃烧；火焰会遮挡画面，着火敌人仍可接近 |

## 掉落不只有武器

第一代已有战斗鸡、加速靴、诱饵猴、旋转防御物，以及坦克和直升机等临时载具。战斗鸡随玩家提供火力；载具把短时间的移动与攻击方式一起改变。不能把这些当作第二代才首次出现的类别。[jimmythesnowman攻略，Power ups and special attacks](https://www.supercheats.com/pc/walkthroughs/callofdutyblackops-walkthrough01.txt)

拾取物的价值取决于当前处境：例如安全时留意火力和财宝，被夹住时先用核弹或冲刺脱身；多人应把重复强化留给更需要的队友。这是攻略中的实战思路，不是强制分配规则。[PC实战攻略](https://steamcommunity.com/sharedfiles/filedetails/?id=249845040)

## 命运房与四种本局永久强化

命运房位于13—16轮的洞穴区间，是正常推进必经的特殊房间。每名玩家取得一种持续本局的命运，不是局外技能树。[jimmythesnowman攻略，The Room of Fate](https://www.supercheats.com/pc/walkthroughs/callofdutyblackops-walkthrough01.txt)

| 命运 | 基本效果 |
| --- | --- |
| Firepower 火力 | 默认武器改为Death Machine；其他临时武器结束后回到它 |
| Friendship 友谊 | 永久战斗鸡；后续拾取战斗鸡的持续时间也获得增强 |
| Furious Feet 疾足 | 永久加速靴效果，开新轮冲刺至少补到3次 |
| Fortune / Fortitude 幸运与坚韧 | 延长武器与强化持续时间；死亡后倍率底线为×2 |

基础效果见[第一代词条的Room of Fate条目](https://callofduty.fandom.com/wiki/Dead_Ops_Arcade)；Fortune在第一代的延时记为两倍，不能套用第三代数值。[Fortune跨代效果区分](https://callofduty.fandom.com/wiki/The_Fate_of_Fortune)

攻略还有通过出口箭头出现顺序辨认命运的技巧，但涉及多人镜头可见范围和观察时机，不写成固定方位选择表。

## 奖励房与军械库

| 区域 | 内容与作用 |
| --- | --- |
| Bonus Room 奖励房 | 四处财宝堆，主要补积分、倍率，也可能有武器和强化；不增加排行榜轮数 |
| Armory 军械库 | 四处补给堆，以核弹、冲刺、武器和强化为主，为后续战斗补充资源 |

资料：[奖励房](https://callofduty.fandom.com/wiki/The_Bonus_Room)、[军械库](https://callofduty.fandom.com/wiki/The_Armory)。它们是免费收集区域，不是购买商品的SlayerMart。

**入口口诀存在冲突：**奖励房词条自身同时出现“固定路径”和“每局不同”的说法，MKillBill攻略则明确反驳“跟着猩猩／固定选左或右必进奖励房”。因此不采用保底进入口诀，也不据此编造生成概率。奖励房内容可参考，精确入口分配仍待验证。

## Boss与后续循环

第40轮普通敌群结束后进入Cosmic Silverback战，之后并非结算退出：胜利后回到海岛开始第41轮，更难的循环继续；攻略还记录了第80轮双Boss。Boss冲锋前有动作提示，玩家需要横向避让或用自己的冲刺拉开距离，并处理同时出现的敌群。[PC实战攻略，Boss Round及Rounds 41—80](https://steamcommunity.com/sharedfiles/filedetails/?id=249845040)

这与当前FirepowerLoop“40轮后独立Boss、胜利结算、不循环”的设计不同。

## 来源版本与仍需核实的细节

- **官方回顾**：2020-12-09的Treyarch文章确认初始生命、无限弹药、合作和基本循环，不提供完整数值表。
- **早期PC攻略**：jimmythesnowman，v1.20，2011-01-16；GameFAQs原入口可查，正文通过SuperCheats镜像读取。部分武器命名和计分表有明显局限。
- **后续PS3攻略**：MKillBill / Bill Albrecht，当前读取的镜像内部版本为v2.41、2012-05-08；不能使用搜索结果的抓取／更新日期代替攻略版本。
- **PC实战攻略**：MrAssassiN，Steam，2014-04-16。站位、难度评价与打法属于作者经验。
- **社区词条**：本次用于补充房间及命运分类；涉及入口的自相矛盾已在对应段落标明。

尚缺逐轮敌人数与生成间隔、伤害与掉率、临时效果完整时长、宝石精确积分／倍率进度、借命完整算法及各平台补丁差异。早期攻略把宝石效果笼统处理，后续攻略区分大小，不能拼成精确掉落表。轮次结束的时间条件也需复核，不从“清敌推进”的概述推导源码合同。

## 与 FirepowerLoop 的关系

本代说明街机循环、临时火力、命运和奖励区域的历史玩法，不是当前逐项复刻基线。项目的两人上限、40轮结束方式、血量、炸弹与冲刺补足规则，应查[当前项目功能资料](../当前项目/FirepowerLoop已实现功能.md)。本次仅补资料，不改变游戏规则或授权载具、循环周目等新增功能。
