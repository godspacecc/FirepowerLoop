# Dead Ops Arcade 第二代关卡与流程对照

整理日期：2026-10-21。对象是《黑色行动3》中的 **Dead Ops Arcade II: Cyber’s Avengening**。这份资料用于和[当前20个主题的关卡说明](../当前项目/关卡配置/README.md)对照，方便决定参考哪些内容。

第二代的主线是**16组场地、每组4轮，首轮循环共64轮**。普通战斗之间穿插奖励房、独立小游戏、命运选择和审判升级，击败Cyber后继续下一循环。它与当前项目的40轮分支路线有不同的推进节奏。[主线路线攻略](https://gamefaqs.gamespot.com/ps4/145061-call-of-duty-black-ops-iii/faqs/72570/the-silverback-trail)

以下轮次均指首个循环。英文场地名采用MKillBill攻略的定位名称；中文为便于对照的译名。

| 第5关 | 17—20 | Temple Grounds／神庙庭院 | 第17轮暗影敌人 |
| 第6关 | 21—24 | Marketplace／集市 | 小场地密集围攻 |

**一局中穿插的流程：**

1. **普通轮：**清理敌人、收集财宝和临时火力，清场后选出口；奖励房可能插入过渡。
2. **第11轮后：**首次遇到Redin’s Rally，驾驶车辆竞速。
3. **第19轮后：**进入Temple Fortress，沿螺旋高塔向上，抵达顶部后进入命运房；结束后继续主线。
4. **血池阶段：**首次遇到Chicken Bowl，驾驶车辆把蛋推入对应篮筐；攻略记为通常在第26轮后。
5. **第37轮后：**进入石像守卫战，随后进入审判房，处理已有命运的升级。
6. **第47轮后附近：**首次遇到Tank Vault Heist，驾驶坦克在迷宫收集财宝。
7. **第64轮：**Cyber终局战；获胜后领取奖励，经传送出口进入下一循环。

四种独立小游戏及其首次时机见[Silverback Challenges](https://gamefaqs.gamespot.com/ps4/145061-call-of-duty-black-ops-iii/faqs/72570/silverback-challenges-160-160-160-160160)。石像节点见[环形场地段落](https://gamefaqs.gamespot.com/ps4/145061-call-of-duty-black-ops-iii/faqs/72570/the-silverback-trail)，命运与升级见[命运房和审判房](https://gamefaqs.gamespot.com/ps4/145061-call-of-duty-black-ops-iii/faqs/72570/the-rooms-of-fate-and-judgement)。

普通场地里的“特殊敌人挑战轮”，仍占用正常轮次；上面的竞速、登塔、推蛋和坦克迷宫是另外插入的小游戏。42轮以后还可能再次随机遇到小游戏，Temple Fortress除外，因此不能只按四个固定节点理解整局。[小游戏出现规则](https://gamefaqs.gamespot.com/ps4/145061-call-of-duty-black-ops-iii/faqs/72570/silverback-challenges-160-160-160-160160)

**命运房与审判房：**

命运房提供四种持续到本局后续的能力方向，玩家接近对应石块领取：

| 方向 | 基础作用 |
| --- | --- |
| Fortune／幸运 | 延长武器、道具持续时间，保底2倍积分倍率 |
| Destruction／火力 | 基础武器改为Death Machine，武器有红骷髅保底 |
| Companionship／伙伴 | 常驻战斗鸡，默认LMG有紫骷髅强化 |
| Swiftness／速度 | 常驻加速，每轮至少2次冲刺 |

审判房在石像守卫战后升级已有方向，例如更强火力、冲刺火焰或更强伙伴；合作中并非直接给全员相同升级。不获升级者也有补偿奖励。这样，一局中的强化有两个较明确的阶段节点。[命运与审判攻略](https://gamefaqs.gamespot.com/ps4/145061-call-of-duty-black-ops-iii/faqs/72570/the-rooms-of-fate-and-judgement)

**奖励房：**

奖励房随机出现在清场选出口后的流程中，不能保证某个出口必得某房。按同一份攻略的命名，可归纳为：

| 奖励房 | 收集重点 |
| --- | --- |
| Treasure Horde／财宝房 | 金币、冲刺和部分支援 |
| Chicken Farm／鸡场 | 等待蛋孵化，获得武器、道具及财宝 |
| Hidden Mine／隐秘矿洞 | 宝石与积分倍率 |
| Armory／军械库 | 武器与核弹补给 |
| Bomb Storage Locker／核弹仓库 | 大量核弹 |
| Wolf Hole／教堂外观的道具房 | 锯、爆桶、拳套等强化 |
| Mystical Armory／神秘军械库 | 特殊武器和支援 |
| Hangar／机库 | 载具及机械支援 |

这些名称沿用攻略分类；房间作用和主线场地分开看，不能把“机库”或“命运房”当作第17、第18个普通关卡。[奖励房正文](https://gamefaqs.gamespot.com/ps4/145061-call-of-duty-black-ops-iii/faqs/72570/bonus-rooms)

**第64轮之后：**

第65轮回到海岛，继续同一局。后续循环加快来敌、延长轮次并增加电塔；不重新发放基础命运，但可以再次遇到审判房。攻略把128、192等轮的Cyber数量列为逐次增加，因此这里的64轮是第一个Boss循环的长度。[65轮以后的规则](https://gamefaqs.gamespot.com/ps4/145061-call-of-duty-black-ops-iii/faqs/72570/advanced-level-strategy-65)

第二代还包含临时第一人称、BO3武器、连杀与专家武器、载具和支援拾取；这些会改变局部战斗，但主线仍围绕轮次生存推进。[Treyarch官方回顾](https://www.treyarch.com/game-intel/2020/12/Dead_Ops_Arcade_is_Back)

**与当前FirepowerLoop方案对照：**

| 要比较的内容 | 第二代 | 当前项目方案 |
| --- | --- | --- |
| 主线长度 | 首个循环16场、64轮 | 每条路线10场、40轮 |
| 关卡推进 | 上表的场地顺序 | 20份主题配置组成分支路线 |
| 战斗变化 | 新敌种逐步加入，部分轮集中考验某类威胁 | 逐轮配置特殊敌人、环境事件和主题Boss |
| 局内强化 | 命运选择，再通过审判升级 | 临时武器与强化已接入；SlayerMart已接入但正式入口关闭 |
| 奖励流程 | 随机奖励房，外加竞速、登塔等独立小游戏 | 当前有按场次安排的奖励区域与首批Slayer挑战流程 |
| 场地结构 | 包含立交桥、登塔、高低屋顶等结构 | 当前战斗规则以平面场地和障碍为主 |
| Boss后的目标 | 回到海岛继续冲更高轮次 | 击败Papaback后结束本局 |

当前项目一列依据[现有关卡文档](../当前项目/关卡配置/README.md)、[已实现功能](../当前项目/FirepowerLoop已实现功能.md)及[商店发布开关](../../Config/DataCsv/arcade_slayermart_ability.csv)。

对照时可以分别考虑三件事：是否采用二代64轮顺序，是否采用命运与审判作为本局强化节点，以及是否加入载具小游戏和高低场地。它们是可以分别取舍的设计内容，不必一次全部采用。

敌人数量、生成间隔、伤害、掉落概率和完整多人判定没有取得可直接用于配置的原始表；本文只整理关卡与流程，不用当前项目数值替代二代数值。来源主要为MKillBill攻略v2.5（页面更新2020-10-11），可配合[TheMoZProject完整单人实录](https://www.youtube.com/watch?v=0AqVpwwGtnY)定位画面；实录时间导航见[既有第二代资料](DeadOpsArcade2-确定资料.md)。
