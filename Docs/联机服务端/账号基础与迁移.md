# 账号基础与旧身份迁移

当前 FirepowerLoop 的正式账号入口使用独立 MongoDB，仍由 ET GameGate→Account→Player 负责认证和玩法连接。与 3DBase 分别维护代码；不共用数据库、不导入 AnotherDay 数据、不迁移街机局状态。

## 玩家行为

用户名为3–32位英文字母、数字或下划线，不区分大小写。新注册密码为10–128个UTF-16字符、UTF-8不超过256字节。登录不存在的账号不会自动创建；界面在账号或密码错误后提供显式注册确认。只为从当前项目schema4快照迁入的旧凭据兼容原0–8位密码。密码不写入客户端偏好，断线后需要重新登录。

用户名与非零PlayerId均由Mongo唯一索引保护；已有重复玩家映射会使初始化失败，需要先核查数据，不能绕过约束启动。

账号密码使用PBKDF2-SHA256、600000次迭代、随机16字节盐及32字节派生值。5分钟内5次错误锁定10分钟；按Socket真实IP每分钟120次认证/心跳请求。限流和失败窗口是本进程有界内存状态，重启不保留。账号禁用、封禁和会话世代存于Mongo；登录递增世代，重复登录替换旧连接，已认证心跳重新检查状态。目标Player的断线宽限及房间生命周期保留。

账号错误200101–200108保持兼容；200201限流、200202锁定、200203禁用、200204封禁，200205预留账号不存在。房间200109–200137不挪用。公共线协议保持MemoryPack及两字节小端分帧；内部账号/玩家消息增加持久SessionEpoch字段，服务端组件需同步部署。

## 启动

为本项目设置 `FIREPOWERLOOP_MONGODB_URI` 和 `FIREPOWERLOOP_MONGODB_DATABASE`（默认 `firepowerloop_accounts`），凭据由环境注入，不写日志或提交。启动入口仍为 `Server/GameServer/Tools/start-local-online-server.ps1`，默认GameGate端口31011。数据库缺失或初始化失败时账号服务拒绝启动；不会退回JSON。

`--OnlineStore` 现在只用于检测未迁移的旧身份快照。该路径存在时启动失败，必须先完成下面的离线迁移和归档。`--OnlineArcadeStore` 仍是目标自己的局结果存储，与账号迁移无关。隔离测试可指定 `--OnlineLoopbackOnly=true` 将GameGate限制到127.0.0.1；它不改变诊断HTTP的权限要求。TCP未实现TLS，本机通过不表示公网生产就绪。

## 显式迁移

停止本项目服务，备份当前项目schema4账号快照及目标Mongo数据库。迁移工具只接受当前仓库内显式指定的源文件，不读取其他项目数据。首先仅校验：

```powershell
dotnet run --project Tools/AccountIdentityMigration -c Release -- --source Server/GameServer/Store/Online/identity-store.json
```

确认环境变量指向当前项目数据库，再执行同一命令并添加 `--apply`。工具先校验全份身份和编号水位，再导入缺少的身份；重复执行允许完全一致的记录，遇到冲突停止，不覆盖现有记录、不删除源文件。导入不是跨账号事务，中断后可重跑；始终离线执行。保持AccountId、PlayerId、资料版本、旧密码派生值，抬高编号水位，不回收已预留编号。测试只使用构造数据，尚未迁移真实玩家数据。

核对旧账号登录、账号/玩家编号、重新登录世代及玩法局结果后，手动将源文件归档至备份位置，保证原 `--OnlineStore` 路径不存在，再启动服务。回退前停止新服务并恢复已备份的旧服务与账号文件；新增Mongo账号不会自动写回旧JSON，须在回退决定中处理这部分数据。

## 验证入口

推荐统一执行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File Tools/NetworkFoundationChecks/run-account-foundation.ps1`，要求测试Mongo环境变量，自动构建、复制独立运行目录、验证并重启本项目ET服务，最后停止自建进程并删除随机测试库。证据保存在 Backup/Artifacts/AccountFoundation-*；不启动Unity或Player。原 run-online-lifecycle-tests.ps1 默认调用此入口，旧JSON故障注入专用参数会明确报退役，不再执行失效断言。

- `dotnet run --project Tools/NetworkFoundationChecks -c Release`：本项目正式TCP/RPC源码与真实回环Socket检查。
- `FIREPOWERLOOP_TEST_MONGODB_URI` 指向隔离Mongo时运行 `dotnet run --project Tools/AccountFoundationChecks -c Release`：随机测试库，结束删除，仅测试数据。
- 已启动隔离ET服务后，`dotnet run --project Tools/NetworkFoundationChecks -c Release -- --native 127.0.0.1:31011 <测试身份标记路径>` 检查真实注册、登录、心跳、顶号；重启同一测试库的服务后加 `--resume` 验证持久身份与世代。仅对隔离实例运行，不连接玩家数据。
- Unity使用限定类 `EtNetworkTransportTests`、`EtNetworkFrameTests`、`TcpOnlineLoginTests`、`OnlineHeartbeatTests` 与账号界面相关用例；运行证据及未完成项见本轮计划。

旧JSON首次登录自动建号、JSON写失败注入等历史用例不能作为新Mongo入口验收。原房间/街机测试共用的注册密码须符合新规则；不得以旧自动建号结果证明当前身份库行为。
