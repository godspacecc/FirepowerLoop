# 美术资源来源总目录

2026-11-24 · 当前项目已采用的外部资源包。

在 Unity 打开 **Project → Assets → Art**，按发布商展开包目录，打开后直接看到包内分类，可以浏览模型、贴图、动画、预制体和音效。本机已从缓存补齐 17 个在用来源的 15,329 个素材文件。查看包内容不需要联网或重新下载。

按游戏现有资源、已下载候选、My Assets 中已购买但尚未下载的资源依次选材。备用素材库里的 GUID 与正式游戏独立。包内脚本、工程设置和嵌套安装包留在缓存，部分原包演示功能需要这些文件。完整原始归档仍在本机 Asset Store 缓存中。
