# FirepowerLoop 国内 Android 发布实践

目标：以国内 Unity 手游客户端求职为目的，完成真实的发布准备、平台测试、问题定位和更新维护，保留可核查证据。第一轮保留现有单人、双人联机和本局强化，仅保存分数及本局结果。

本目录区分离线已验证、待实施和人工待验，不将材料准备等同于平台审核通过或商业上线。

- [Android 离线发布体检（2026-10-21）](Android离线发布体检-20261021.md)：现有两个 APK 的实际身份、签名、权限、调试标志、内置地址及包体对比。
- [发布准备与后续实施清单](发布准备与后续实施清单-20261021.md)：无需手机即可推进的事项、平台材料和后续设备验收。
- [原始离线证据](Artifacts/20261021-Android/apk-inspection.json)：使用 Android SDK 工具读取 APK，含退出码、哈希和证据文件索引。
- [渠道候选包与自动检查使用说明](../../Tools/Android/渠道候选包使用说明.md)：独立渠道构建入口、正式签名环境变量和不打包的已有 APK 检查菜单。
- [渠道候选模式实施与验证记录](渠道候选模式实施与验证-20261021.md)：本轮代码范围、46 项限定测试、最终 APK 检查结果及待验证边界。
- [正式签名本机配置](../../Tools/Android/正式签名配置记录.md)：随后生成的独立正式密钥、已验证的本机接入及需要自行保留的备份。

- [启动数据流与隐私初始化检查](启动数据流与隐私初始化检查-20261021.md)：启动及菜单自动请求、账号和诊断字段、本地与服务端存储，以及六项检查发现（协议日志密码输出已修复，其余待处理）。

- [协议日志密码脱敏修复](协议日志密码脱敏修复-20261021.md)：日志隐藏 Password，实际网络密码不变，11 项限定回归通过。

SDK 文本证据在提交前统一了换行并移除行尾空白，未改变命令、工具结论或 APK 内容；原始与规范化后的文本 SHA-256 记录在离线证据 JSON 中。

人工设备验收按用户要求后置。已知主测机：红米 K50 Ultra；Android 版本、系统版本、安装及运行结果尚未提供。

当前 AGENTS.md 禁止 Unity 打包和 Player Build。本轮已实现渠道候选构建入口与只读 APK 检查器，并完成限定 EditMode 验证；没有执行游戏打包、重新签名现有游戏包、服务器部署、账号注册或平台提交，也没有提交 Git。
