# 协议日志密码脱敏修复

2026-10-21。已修复网络诊断日志完整输出登录密码的问题。开启协议日志后，发送与接收消息的 `Password` 字段统一显示为 `***`；实际请求、回包及网络编码不因日志处理而改变。

## 修改与验证

问题位于 `NetworkDiagnostics.LogProtocol`：原实现直接序列化整个消息。现实现先创建独立的 JSON 日志副本，再递归隐藏对象和数组中的 Password 字段，字段名匹配忽略大小写。用户名、RPC ID、普通消息正文及其他诊断字段保持原样。

日志开关关闭时仍提前返回；null 消息继续输出 JSON null。序列化失败时仍只记录异常类型，不打印异常正文，不回退输出原始对象。没有修改生成协议或实际发送路径。

新日志示例使用虚构账号，仅说明格式：

```text
[Network] Send C2G_Login={"RpcId":1,"UserName":"example_user","Password":"***"}
```

本次只按字段名处理 Password，不对任意自由文本推断或替换秘密。其他日志出口、历史日志、未来新增认证字段和自定义序列化方式仍需按实际接入检查。
