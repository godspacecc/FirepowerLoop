# 基地手机三指操作实施

目标：实施聊天中已确认的基地俯视三指方案，移动、方向、开火与装填各自独立。

范围：只在手机模式、基地固定俯视显示新控件；远征、街机、越肩、电脑操作保留现状。不添加跳跃玩法，不执行打包，不自动提交。

架构：触控 View 捕获自己的 pointerId 并提交原始意图；MobileInputSystem 统一门禁与暂存；PlayerInputSystem 发布现有攻击/装填事件，武器系统继续裁决弹药与冷却。布局在 Prefab 安全区内，ReferenceCollector 变更后运行 UI 生成器。

- [x] 定向 EditMode 合同测试先证实基地控件缺失。
- [x] 新增方向摇杆和独立按压开火/装填触控，保证抬手、隐藏、阻断、失焦释放，不接收滑入。
- [x] 接入方向保持、连续攻击与装填意图；装填期间不由旧按压自动取消。
- [x] 通过 Unity 编辑 Prefab 并生成 View；新装填按钮显示权威动作进度。
- [ ] 最终定向测试与真机手感验收。

检查重点：三指不抢占；只瞄准不攻击；松手保持朝向；装填不被持续按压取消；阻断后旧触点不恢复开火；右上开火避开暂停入口。

验证记录：MobileBaseCombatTests 初次运行 1 项，因控件缺失按预期失败；接入后 3 项通过。PlayerCameraModeIntegrationTests 运行 30 项，全部属于该类且通过，但事前声明上限误写为 29，超过声明，按项目约束停止所有后续 Unity 测试，不使用该运行作为验收证据。

后续静态布局预览发现新增按钮继承原越肩按钮的隐藏状态，已修正并补合同断言；不再运行测试。Unity 实际反序列化检查确认生成引用有效且两个按钮 activeSelf 为 true。手动预览采用临时 PreviewScene，未进入 Play Mode、未修改 Boot 场景。最终变更仅核对编译及源码，新增可见性断言、双输入装填消费修正尚未复跑；发布包和真机三指操作未验收。
