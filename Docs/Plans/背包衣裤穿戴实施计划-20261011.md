# 背包衣裤穿戴实施计划

> 执行方式：本会话直接执行，使用 executing-plans；不创建子代理、worktree 或提交。用户已确认接入设计，继续执行其授权范围。

**目标：** 衣裤作为真实库存物品穿脱，角色、装备页、存档和联机状态一致。
**架构：** 独立身体穿戴状态与库存候选事务；本机由 System 提交，联机由服务器提交；角色及 UI 消费快照。
**技术：** Unity 2022.3、QFramework、Luban、ET、Humanoid 蒙皮。
**设计：** [背包衣裤穿戴接入设计](背包衣裤穿戴接入设计-20261011.md)。

## 全局约束

- 两个正式穿戴槽：上衣、裤子；不改手持引用语义，不增加属性效果。
- 替换旧衣物返回来源格；卸下满包拒绝；空槽内搭；旧档不赠送物品。
- 不更改正式掉落或商店定价，通过现有物品入口取得衣物。
- Unity MCP 优先；仅指定类/方法测试；不打包；保留其他任务的改动。

## 复审重点

过期来源不可换出另一个物品；满包替换和卸下须区别；损坏档不可静默吞掉装备；远端初见/重连需完整快照；空槽与第一人称不能露洞或仍显示未装备衣物。
