# 紫色桶爆炸正式接入验证

用户在紫色画面及能量音效候选后回复“可以”，据此正式接入主预览 A。本次只处理地面固定桶、独立落地桶和提前击杀载桶敌人的爆炸；背桶与大漩涡浓雾的造型仍为此前预览。

## 正式实现

- 新增 `Assets/Game/Art/Arcade/VFX/Barrel/VortexBarrelBlast.prefab`，六层粒子：紫白闪芯、紫色爆发、径向火星、紫烟、紫色桶碎片、淡出余烟。独立中性烟雾／光晕材质，避免普通火焰贴图带橙色。
- 通过现有 `ArcadeObstacleVisualSet/Content` 资源租约加载，地图内独立12组缓存，满后复用；先清粒子再移动，切轮／离场释放。普通武器的模板、配色、声音与缓存不受影响。
- 单人及服务器桶爆炸使用共享 Kind14；屋顶撞击仍为原 Kind3。客户端对权威事件ID去重，不创建持续危险圈；模板未到时不消费ID。声音沿当前音频系统播放 `ArcadeExplosionSciFi`，桶独立0.15秒限音，不阻止画面。
- 单人事件编号持续递增，同地图切入Boss保留未到期已结算爆炸并重算剩余寿命；Boss死亡仅清危险。新地图清旧爆炸。单人及服务器快照均直接投影当帧已结算的桶爆炸，修复最后一击后领域停钟导致的漏播。
- 保留桶爆炸只伤敌人、武器自身爆炸不丢失的既有规则；不改配置、协议结构、存档或伤害参数。
