## Global Constraints

- 只开发 FirepowerLoop 街机；保留单人、现有双人和本局强化，不引入基地、远征、局外奖励、成长钱包或另一项目玩家数据。
- 不默认创建worktree；不触发Unity打包或Player Build。
- 所有视觉改动先提供可查看的预览并说明效果，取得用户明确确认后才制作、修改、替换或接入正式资源。静态出图，动态提供可播放预览；角色与正式主角同框比较，明确临时、概念和正式实拍。
- 尚缺视觉确认时继续不依赖该确认的已授权代码、规则与验证工作；不得把整张计划视作所有视觉方案已获确认。
- 功能实施前用玩家能理解的语言说明操作、行为变化和失败结果；不重复要求审批普通技术方案。
- Config为配置唯一权威源，经Config/gen.bat双端生成；协议经Tools/gen-protocol.ps1生成；保留资源及.meta，核心手写类、函数、字段补中文注释。
- 测试先发现并核实真实非空短testClass或完整testMethod，声明每次范围和最大数量，includePassingTests=true；不得执行完整套件或无效过滤回退。
- 每个实现批次验证且无未解决问题后，仅提交该批相关文件，以中文提交信息提交并推送当前分支的origin；失败先修复，不能将本地提交说成已推送。
- 发布准备、后台下载、构建产物、平台提交和人工设备验收列后续；不得为今晚计划自行打包或部署。

## Review Focus

1. 主题ID21／22只表示地图身份，不能让实际第2／3场获得后期敌人属性、掉落或清场收益。
2. 新局路线替换不破坏旧主题、布局版本、旧后继和既有存档恢复；第12轮后仍能接回40轮主线。
3. 竞速、奖励房、商店与Slayer节点不能同时进入；超时、重复回包或返回不能重复发奖或重复推进。
4. 同枪升级与骷髅补时不能分叉；在途弹丸保留发射状态，双人竞争拾取只消费一次。
5. 暂停、加载、复活、清场和离场后的牛群、桶、火流、特效、音频及异步资源不能继续伤害或残留。

### 任务2：制作场地和动作预览，收集视觉确认

- [ ] 为农场制作浅色积雪地面、草料堆、围栏与建筑的独立静态预览，保持可躲牛群的移动空间。

- [ ] 将海岸样板作为第一关可选视觉候选，清楚展示与当前正式关卡的区别；前三场设计中“第一场保持现有内容”继续有效。
- [ ] 分项记录用户确认的图、动作与适用范围；旧撤回图不算确认依据。未确认部分仅保留临时素材。

交付：静态图、动态预览、来源与确认记录；正式海岛、码头、农场、牛和车辆的改动分别受对应确认约束。

### 任务3：码头与新路线

- [ ] 按已确认设计追加21号码头、22号农场及8张轮级布局，新局1→21→22→5，旧2／3／4／15保留；只有完整链路满足进入条件时才启用正式新路线，避免接到半成品农场。
- [ ] 码头复用载桶、漩涡桶、电塔与已确认紫色爆炸；移除新码头对旧护甲、破坏箱和固定军械库的继承，不改旧地图本身。
- [ ] 第5轮突出载桶敌人，其余轮组合普通战斗；检查沿用旧敌群是否出现明显降密度或拖长。生成间隔、同屏上限和敌人数分别评估，本轮建议不当作已批准精确数值。
- [ ] 定向覆盖主题身份与实际场序分离、解锁池、旧档恢复、清场／军械库隔离、40轮长度和两端一致性；验证正式模型占地、移动／冲刺、敌人绕障、武器点和出口连通。

交付：视觉确认范围内可运行的码头与完整路线接线；配置生成及验证完成后才标为已接入。

### 任务4：农场牛群与第11轮后竞速

- [ ] 牛群先按既有权威职责实现预警、锁向、冲撞玩家和僵尸；护盾、冲刺与无敌仍有效，View不裁决伤害。
- [ ] 牛群暂停／加载／清场冻结，切图回收；轮前恢复不保留半次冲撞。
- [ ] 竞速包含驾驶、转弯、撞僵尸与沿路收集；完成或超时均回农场第12轮，不额外增加普通轮数。
- [ ] 结果、奖励、返回一次提交；隔离旧地图输入，明确竞速、奖励区域、原商店及第12轮后Slayer的先后与互斥，保持商店当前发布门禁。
- [ ] 定向验证牛群保护、敌人结算、竞速完成／超时、重复返回、恢复、双人同步与慢加载；正式牛车模型和动作仅在相应预览确认后接入。

交付：可返回普通主线的农场与竞速闭环，失败与超时有明确结果；隔离模拟不能代替真实双端验收。

### 任务5：骷髅与武器升级，完整纳入并分两批

- [ ] 基础批：细化普通→红→紫、同枪升档、大小骷髅补时与封顶转换表；未知原作参数明确作为项目选择，武器时钟与强化时钟分别处理。
- [ ] 统一普通拾取与奖励房领取入口；不同枪清原强化、低级不降紫、补时不缩短；单人与双人使用一致规则，保留发射时弹丸等级。
- [ ] 为紫级轻微移速收益使用独立参数，覆盖靴子、冲刺、浅水组合，以及暂停、死亡、清场、切轮、恢复和军械库边界。
- [ ] 专属批：紫级火箭三联追踪、射线反射触电、榴弹快速连发均列入制作队列；射线反射对象／方式等未定细节先补证或形成明确项目方案，不凭空填原版规则。
