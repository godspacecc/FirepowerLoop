# 主角整套造型测试指令实施记录

用户已确认：使用当前主角 POLYGON City 资源中的九套造型，先通过测试指令切换，不增加正式游戏选择入口；整套人物暂时隐藏分部位衣物，保留装备数据，恢复后显示最新装备。

## 使用方式与范围

- 编辑器或开发版的既有测试指令界面（默认 C 键）中输入 `#appearance list` 查看编号。
- `#appearance <1-9>` 切换整套造型；例如 `#appearance 8` 是男夹克，`#appearance 3` 是女商务装。
- `#appearance reset` 恢复分部位换装。
- 切换只接受就绪、Playing 状态的离线基地或远征。联机、街机及加载中拒绝修改。
- 编号仅由 TestCmdModel 保存于本次运行会话；离线切图重新应用，不写角色存档、装备、背包或网络协议。指令历史继续沿用既有测试工具设置保存规则。

## 实现边界

TestCmdSystem 校验、提交编号并发布 PlayerTestAppearanceChangedEvent；PlayerCtrl 与当前可见 ClothingPreviewPresenter 读取同一模型，释放时退订。ClothingAppearanceView 在现有骨架上切换整个身体网格或 ClothingParts 根，不更换 Animator、武器 Presenter、挂点、碰撞或战斗权威。衣物快照在隐藏期间持续更新，恢复时显示最新衣物。

GrayboxPlayer 原有九套模型均复用正式 PlayerCityCharacters.fbx；ClothingCharacterPreview 补回此前移除的九个 Renderer，并复用预览的 49 骨。Tools/Unity/PlayerAppearanceAuthoring.cs 负责幂等绑定与提取对应手臂，正式 WholeBodyArms 中的九个 Mesh 保留原骨序、UV 和绑定矩阵，交由既有第一人称采样流程显示。未修改备用资源包。

Config/DataCsv/test_cmd_entry.csv 加入列出、切换与恢复条目；通过唯一 Config/gen.bat 生成，客户端 tbtestcmdentry.bytes 更新，服务器目标未产生本功能差异。不修改测试指令 UI Prefab 或生成 View。

## 2026-10-12 造型切换后主角不可见修复

正式 GrayboxPlayer Prefab 的九套整身造型中，除 7 号男连帽衫外，其余八套 SkinnedMeshRenderer 保留了禁用状态。ApplyWholeBody 只激活人物节点并隐藏分部位衣物，导致切换成功但人物无法绘制。

通过 Unity MCP 修正这八个 Renderer 的启用状态；九套造型仍由节点显隐控制，默认保留分部位换装。PlayerAppearanceAuthoring 同步显式启用整身 Renderer，避免后续资源整理保留旧禁用状态。没有修改指令语义、装备数据、存档或相机运行时代码。

PlayerAppearanceTests 增加可绘制状态检查及退出第一人称后的恢复检查。修复前准确捕获八套造型失败；修复后该类 11 项和 ClothingAppearanceTests 6 项全部通过，每次核对结果名称与数量，无范围外执行。结构化证据见 Client/Assets/Tests/Results~/PlayerAppearance/visibility-fix-20261012.json。

Tools/Unity/PlayerAppearanceVisibility.png 是正式 Prefab 在隔离编辑模式场景中的九套整身渲染，从左到右对应 1～9；已人工检查九套均可见。该图不代表手机实机验收。Boot 场景保持干净，未触发打包或 Player Build；手机开发包需要用户手动更新后试玩。

Tools/Unity/PlayerAppearanceCapture.cs 使用隔离 UI 夹具，通过真实测试指令渲染男夹克、女商务装与恢复原装备的两页截图，输出于 Tools/Unity/PlayerAppearanceCandidates/Applied。已检查背包男夹克、装备女商务装、恢复装备以及两种第一人称静态手臂图。它们是实际 Prefab 的编辑模式渲染，不是整局实机验收；连续移动、持枪和攻击过渡及设备体验仍待试玩。未运行 PlayMode 全套或打包。验证后 Boot 场景保持干净。
