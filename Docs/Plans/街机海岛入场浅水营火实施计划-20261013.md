# 街机海岛入场、浅水和营火实施计划

本次用户已确认三项目标并授权实施，在现有工作区执行，不提交、不打包，不改宝藏/出口/第二场。

1. 双端共用 ArcadeOpeningRules 定义北侧岸边与南侧水侧入场，按当前波生成序号交替使用，横向通道限于中部避开外沿装饰。出生于玩家边界外一段可见引道；瞬时敌人状态记录入场目标，按原移动速度连续前进，抵达后恢复原追击。入场期间不经过通用边界/拥挤修正；击退亦不得瞬移回边界。数量、预算和生成节奏不改，协议/存档不变。
2. Island 原模板补浅水岸线；按配置 WaterMinY、场地尺寸和入场引道宽度配置沙滩/浅水，二者相接而不重叠。采用浅水与深海材质区分，不增加额外水纹系统。水面低于角色/掉落/弹丸。只改 Island 子模板，不重建 Content/出口或其他分支。
3. 营火复用 BurningGround，增加轻量燃烧烟；火焰大小按 CampfireRadius，独立危险圈显示现行玩家中心触发距离 CampfireRadius+PlayerRadius。战斗有效状态由共同规则函数提供，原伤害入口不变；清场/离场/死亡等待关闭。
4. 完成三项与差异自审后集中做现有聚焦 EditMode/服务端独立检查，Unity 工具严格类过滤。短人工播放通过正式入口和临时档做静态观察，不运行自动驾驶或 PlayMode 自动化；如未完整四波清场，明确未验收，不用跳波代替真实流程。

失败/回收重点：对象池不残留入场标志；异步模板晚回调不提交；火焰/烟切换关闭时清空粒子；原资源句柄唯一释放。
