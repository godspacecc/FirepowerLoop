锤击预警、火球、火球爆炸、燃烧地面、火焰路径、电击风暴。橙红火焰、蓝白电弧、收缩红圈，适配固定高角度俯视。只制作表现资源，不确定技能范围、伤害、持续时间、控制规则或网络行为。

正式资源限定 `Client/Assets/Game/Art/Arcade/VFX/FirstBatch/`。工具为 `Tools/Unity/ArcadeArtFirstBatch.cs`，通过 Unity MCP 编译执行。共享场景、角色/玩法 Prefab、运行时代码、Config、生成文件及另外两份设计文档均不修改。不提交或推送。

## 来源与交付

火焰采用备用 ARPG Effects 的 `fire_16x4.png` 项目副本，副本使用独立 GUID，保留其生成后的 meta；原包不变。发光采用已正式接入的 `Game/Art/Effects/ArcadeARPG/Textures/basicglow.png`。环形网格、电弧网格和动画由工具生成，材质采用 URP。所有 Prefab 只使用 Unity 内置表现组件，不复制第三方行为脚本。

六个 Prefab：`HammerTelegraph`、`Fireball`、`FireImpact`、`BurningGround`、`FlamePath`、`TeslaStorm`。本批不接入游戏，后续功能会话负责权威状态驱动、播放与停止、缩放和对象池。

## 验证

六项已通过 Unity MCP 生成并重新执行验证：无 `Assets/Art` 依赖、无 MonoBehaviour 行为脚本、无 Collider，全部材质为 URP。每项粒子系统数依次为 0、3、4、2、1、9；没有运行 Unity 测试或 Player Build。

固定高角度俯视渲染 30 帧，采样 15 fps、约 2 秒；检查第 2、8、23 帧，收缩预警、爆炸扩散与火焰/电弧变化可见。合成带中文标签的 `overview.png` 与 `preview.gif`，路径为 `Client/Assets/Tests/Results~/ArcadeArtFirstBatch-20261011/`；该目录被 Git 忽略，供本机审核。`asset-audit.txt` 保存逐项引用检查结果。

发现并修正原贴图的命名误导：`fire_16x4.png` 实际有 16 列 5 行，原第三方 Prefab 也使用 16×5，正式副本按真实行列采样。电弧采用局部空间网格，避免相机对齐将水平网格渲染成不可见侧面。

临时预览场景已关闭，MCP 最后查询只有 Boot 且未脏。当前 Boot 未运行街机；现有宝藏预览仍为色块占位，不属于本批验收。隔离资源预览不能替代游戏中实际光照、密集敌群、遮挡和移动设备性能验收。

## 原作对照修订

用户要求尽可能接近 DOA4 原作。已读取并检查 [官方 Zombies 深入介绍](https://www.callofduty.com/uk/en/blog/2025/09/call-of-duty-black-ops-7-zombies-deep-dive) 中的 DOA4 图片和 [官方演示短片](https://www.callofduty.com/cdn/blog/blogs/BO7/BO7-ZOMBIES-INTEL-BLAST-062.mp4)。仅用于视觉研究，不将原作媒体作为游戏资产。

本轮 FireImpact 新增白亮爆心、径向拉伸火星、扩散烟尘，并复用备用 cloud 贴图的独立项目副本。预览使用临时 Bloom；最终导出目标使用 sRGB，已用有/无后处理对照确认先前背景过暗来自线性 HDR 导出，而非共享 Volume。未修改正式场景后处理。

新版 30 帧实际 Unity 渲染已重新生成，另有 `reference-comparison.png` 展示官方爆炸参考与独立素材。原作短片没有明确展示 Guardian Golem 与 Tesla Storm；六项仍是待对照细调的资源，不能声称已完全还原或通过局内验收。接入时需确认正式相机 Bloom 和移动端预算。

## 接入约束

- Prefab 原点是技能中心，地面为局部 Y=0；火球核心高约 0.8 米仅作样本，实际投射物跟随由功能会话接入。
- `HammerTelegraph` 有固定边界与向内收缩圈，内置 Legacy Animation 循环 1.2 秒仅为展示速度。接入时按真实蓄力时间控制 AnimationState.speed，技能结束停止或归还资源，不能让展示循环决定攻击时机。
- `FireImpact` 是一次粒子爆发，其余粒子素材循环播放。复用时清除旧粒子，禁止遗留上次技能的效果；本批不提供池管理脚本。
- `BurningGround` 样本半径约 1.8 米；`FlamePath` 样本沿局部 +Z 长约 3 米，可拼接。边缘圈仅供辨识，不是判定器；功能接入须使画面与真实危险范围相符。
- `TeslaStorm` 是玩家附近短电弧的独立素材，尚无敌人端点、受击或眩晕接入。预览尺寸、闪烁频率、八条电弧都属于美术参数，不能解释为技能目标数或范围规则。
- 下一步由本会话根据用户画面反馈调整素材；共享场景、玩法 Prefab 与技能驱动的接入另行协调，不抢写。
