# 手枪、连射与散射效果实施验证

日期：2026-10-17。用户确认从三枪开始，按批验证后中文提交推送。起点30c2b04；工作区已有打包工具、DLL及设置等其他改动，本批不纳入。

## 现状与首批方案

七种枪械已有模型与枪声。三种普通枪及镭射枪原共用普通短弹；三枪普通命中复用12组短火星。穿透、火箭和榴弹有独立弹体。单人普通弹撞障碍缺接触反馈，火箭／榴弹／镭射引爆入口只播声音，完整可见爆炸仍待后批。联机火花与爆炸通知缺口继续单列，不以本批共享枪口／弹体接线声称双端验收。

本批保持现有URP暖色亮芯短尾，采用现役共享武器Presenter及表现帧：手枪清楚短促；连射闪光更小、弹体更细；散射单次闪光更宽、五枚弹体更短、枪体回弹更重。只增加表现，不改伤害、射速、速度、寿命、散射数量／角度或命中规则。

## 枪口调查

旧`PistolMuzzleFollowsVisibleBarrelThroughAimAndFire`实际复现约0.35975米偏差。但该测试调用旧`ConfigureArcadeWeaponPresentation`，现役Prefab带共享Presenter且未绑定武器，`GetProjectileOrigin`无法从Presenter取枪口，返回兜底位置。旧测试不代表正式共享路径偏移。未为它改动现役模型或CSV枪口。

用正式`ConfigureSharedArcadeWeaponPresentation`及当前目录核对三枪，多段动画采样下模型前端与枪口距离小于0.1米。探针局部坐标：手枪前端约(0,.05219,.22643)，枪口(0,.05,.23)；连射前端(-.0075,-.04185,.62705)，枪口(-.01,-.04,.63)；散射前端(.00008,.07165,.54045)，枪口(0,.07,.54)。

## 第一批：开火、回弹与三种弹体

- PlayerView按当前共享武器ID调整自有枪口粒子的尺寸、寿命，切到其他武器恢复原模板值。没有增加逐帧MonoBehaviour或每发分配数组。
- Presenter在已有表现帧推进短枪体回弹，从解析的基础姿态重算，不累加手骨变换；换枪、受击、死亡、禁用使用原清理入口。手动造型库采样不受回弹干扰。
- CSV三枪仅填独立弹丸视觉名，经`Config/gen.bat`双端生成。两端`tbarcadeweapon.bytes` SHA256一致：`513DBE5003E562EA11FEADE0FEE84DA3BA3F201D177369B0E1CB629946189330`。
- 使用Unity正式Prefab编辑接口原位增加三种短弹子节点，保留原GUID、根缩放、Collider、Rigidbody、默认弹体和特殊模型。普通三枪走短弹载体，敌弹、弓箭及特殊模型保持箭载体；按地址分池，复用时覆盖所有模型开关。

## 第二批：撞障碍接触火星

普通三枪实际撞障碍时，在原规则确定的接触点发一次纯表现通知。三枪之外、敌弹和寿命到期不播墙面火星；不更改原命中、移除或伤害。墙面火星向来弹反方向成锥形短散开，不发送敌人身体命中音。与敌人命中共用原12组池，复用时重置形状、朝向、尺寸、速度、寿命和发射量，离场沿用既有清理；不新建生命周期或每次命中分配发射数组。
