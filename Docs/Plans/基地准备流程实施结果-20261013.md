# 基地准备流程实施结果

日期：2026-10-13。功能实施与定向检查已完成，未提交推送。用户明确要求跳过可人工完成的剩余验收。

## 实施范围

- 正式配置涵盖48种物品重量、20千克负重规则、技术分类、地图准入、普通商品价格及四种基础开放商品。通过 `Config/gen.bat` 生成客户端46张表与原服务端28张表；不手改生成代码或bytes。
- 基地日历、新档及支持的旧档一次性80金币、跨日发放、次日08:00免费休息与恢复、写盘失败整体回滚。加载/暂停/主菜单/离线不推进；远征恢复读取基地权威分区，结算按稳定远征ID去重。
- 物品、装填弹药、分割移动与世界掉落保存剩余探索来源。成功返程兑换前开放仍携带的当地普通商品；死亡不开放。来源用“当前远征ID + 当地数量”表示，基地数量先消费，无需逐批单调序号；此项替代早期设计中的来源批次数组。现有制作事务仅允许基地仓库状态，基地制作不标当地来源。
- 随身重量计入背包、口袋、穿戴与装填弹药，手持只引用库存；仓库不计。超重仍可拾取，移动减速与冲刺消耗受配置上下限约束。出发在异步加载前后均检查。
- 正式状态Page增加日期、金币、休息；章节页增加规则、重量、禁带滚动列表、调整物资。生成器完成View及宿主引用绑定，保留身体仪表、资源准备和地图解锁流程。
