- 轮节点保存独立计时和显式恢复资格，零命活动者可继续切轮；默认 RoundAlive 的旧状态不能被当成零命恢复授权。全员倒地仍失败，不靠倒地时钟无限续局。
- `CoopRescueOnline`，声明最大 10、includePassingTests=true：先观察 1/10（缺失计时／活动身份），实施后 10/10。覆盖实际致死、60 秒恢复、重复倒地、付命复活、团灭、轮节点克隆恢复、双方零命活动、挑战隔离与切轮冻结。
- `SlayerMartRoundOnline`，声明最大 17、includePassingTests=true：17/17，确认现有商店及切轮事务仍通过。
- Unity：连接路径 `E:/GitHub/FirepowerLoop/Client/Assets`，Boot 干净，修改前最近十分钟 Console Error 为空；同步导入成功。`CasualPopulationFlowTests`（最大 10、includePassingTests=true）实际执行 10/10 通过，证明正式客户端配置加载与现有普通轮准备兼容。双端规则 bytes SHA256 均为 7C048196164953CB8F0CD508956EB64A9763B5585964E56FB69234357A017BBB。
