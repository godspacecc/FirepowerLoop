# 前三关做完后的效果

**已确认内容已正式接入；竞速按你的要求暂缓。**

- **海岛**：四轮固定海岸地图，中间更宽敞，外围山林与海岸挡住不可走区域。敌人从真实通道分段进入，每段方向随机，没有额外方向提示。基础枪换成已确认的 AK，首关空投只有喷火器和无人机。
- **码头**：木板平台、吊架、货箱、停船和海面采用确认版。水槽不能穿过，通路可以正常走；载桶敌人、吞物资的桶和电塔共同出现。新码头不会混入旧军械库、破坏箱或护甲敌人。
- **雪地农场**：采用确认版雪地、石墙、木门框、棚屋、草垛和树木。四个大区域通过门洞与破墙连通；每批五头牛排成一排，起势后穿场冲撞，能撞玩家和僵尸，护盾、冲刺与无敌保护仍有效。
- **掉落与强化**：只有空投武器和无人机放大，箱子缩小；金币和骷髅保持原尺寸，地面不显示名字。弱敌低掉率、强敌高掉率。每轮清场落一个金币宝箱，爆开散落完整播完才能捡；整关第四轮完成后才出现传送门。
- **武器与无人机**：同枪逐级升红、升紫，强化至少补至20秒；紫级移速增加10%，紫火箭三联追踪、紫射线反射触电已接入。无人机与玩家同步红紫强化，限时快结束时有目标才冲撞爆炸，无目标正常消失。

新局顺序为 **海岛→码头→农场→原第四关**，后段保留十关四十轮。单人与既有双人均有实现和定向验证；竞速、发布准备与打包继续后排。
