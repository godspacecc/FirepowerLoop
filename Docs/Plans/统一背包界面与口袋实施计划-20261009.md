# 统一背包界面与口袋

## 已确认范围

手机横屏，通过现有背包按钮进入全屏管理界面。默认显示背包，底部固定六个点击页签：背包、装备、状态、地图、任务、日志；后五页仅占位，不重做已有领域功能。左侧固定四格独立口袋，下方显示现有十二格背包，右侧详情与使用、转移、拆分、丢弃操作。所有物品均可放入口袋，沿用堆叠和使用规则。暂不实现重量、负重或背包装备扩容。

## 实现与边界

- PlayerBagModel 持有独立 Pocket 容器，保存为同一玩家分区内的 pocketSlots。旧档缺少字段时恢复空口袋；显式损坏字段拒绝读取。口袋与背包共同承担原有远征风险。
- InventorySystem 提供口袋地址、转移与带容器身份的使用/丢弃入口；UI 不直接修改容器。失败保持原物品，变更只通知一次。
- BagUICtrl 继续作为统一入口和宿主。稳定布局在 Bag.prefab；复用 InventorySlotBox 与 CustomListView，通过 ReferenceCollector 和 UI 生成器更新 View。
- 仓库和搜索容器的伴随背包仍使用现有紧凑布局，避免全屏宿主遮挡双栏操作。
- 当前服务器库存没有口袋协议，联机继续读取服务器背包；不把本地离线口袋当作联机物品。首版口袋在离线基地/远征使用，联机明确显示不可用，协议接入另行处理。
- 只在当前 Unity 绑定工作区实施；不建 worktree、不自动提交、不打包。保护已有材质与字体改动。
