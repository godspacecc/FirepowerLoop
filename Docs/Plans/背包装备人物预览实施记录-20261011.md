# 背包与装备分页人物预览

2026-10-11。用户确认在背包左侧显示人物、装备页放大人物并围绕七部位按钮，支持拖动旋转与切页保留朝向。

## 实现

- 背包完整管理页调整为人物、物品格、详情三栏；装备页扩大人物区域。复用正式 `ClothingCharacterPreview.prefab` 与当前主角的七部位资源。
- `BagUICtrl` 拥有背包预览，`EquipmentManagementPageCtrl` 拥有装备预览；每次切页先释放旧预览，再传递水平角度、观察俯仰和缩放并创建可见页预览。状态等其他分页不创建人物。
- `ClothingPreviewDragView` 接收左键或单指拖动，按预览宽高与画布缩放转换转身和俯仰意图；滚轮和双指伸缩调整缩放，双指期间不转身。按下时确定手势归属，隐藏清空触点，第三指不接管。俯仰范围为 -10 到 75 度，正交半高度限制为 0.55 到 1.5 米。预览相机只拍模型，不接入玩法角色、库存权威或存档。
- 背包人物底板和装备人物底板使用管理界面的同一不透明底色，避免独立色块形成窗口感；离屏纹理空白仍透明，只合成人物。缩放与旋转不会改变衣物、库存或存档。
- 离线从 `ClothingEquipmentModel` 读取七槽，联机从已确认 `SelfInventory` 快照读取；穿戴事件与在线快照事件刷新外观。
- 隐藏和销毁幂等释放模型、相机、灯光、RenderTexture 与拖动订阅。播放模式先禁用旧根再延迟销毁，防止同帧两个模型重叠；宿主直接销毁有独立生命周期监听。
- 口袋与背包保留原 `CustomListView` 和独立格子 Prefab，布局复用 `InventoryManagementGridLayout` 自适应四列宽度。背包页安全区基准与其他分页统一。
- 仓库与搜索的伴随背包继续使用紧凑布局。本次不修改穿戴规则、物品配置、协议或存档。

## 制作与证据

`Tools/Unity/InventoryCharacterPreviewAuthoring.cs` 通过 MCP 执行 `Run` 更新 Prefab 并运行 Page/UI 生成器；等待生成和编译结束后执行 `Bind` 修复宿主对生成 Page 组件的引用。不要在 `Bind` 内再次生成 Page，以免延迟回调替换组件身份。

`Tools/Unity/InventoryCharacterPreviewCapture.cs` 使用真实界面夹具、正式模型与图标，在临时场景内渲染并恢复原编辑场景。截图位于 `Tools/Unity/InventoryCharacterPreview/`，包含两页的 1920×1080 与 1440×1080 画面，TMP 检查未发现溢出。
