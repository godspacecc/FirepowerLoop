# 和家村局部地图

## 使用

1. 打开现有的 `Assets/Game/Scenes/GeneratedMaps/HeJiaVillageLocalPreview/HeJiaVillageLocalPreview.unity`。
2. 用 `Tools/地图/局部散图制作/地物参考` 在 Scene 视图查看森林、建成区、水域和道路参考图；此预览不写入场景或 TerrainData。
3. 如需更新源笔触，可在 `Tools/地图/局部散图制作/区域标注（和家村卫星图）` 编辑并保存标注资产。

场景位于 `Client/Assets/Game/Scenes/GeneratedMaps/HeJiaVillageLocalPreview/HeJiaVillageLocalPreview.unity`。它把保留在 `Client/Assets/Game/MapTerrainSources/HeJiaVillage/TerrainData/` 的四块 DEM 源地形中 Unity XZ `x=720..1488`、`z=976..1744` 裁成独立的 768 米正方形 Terrain。局部 TerrainData 已恢复对应区域的地表权重；其中植被层使用从备用 `SimpleNaturePack` 地面取色制作的局部绿色 TerrainLayer。558×699 卫星图上保存的水域、道路、植被和田地笔触仍保留为标注源数据；场景中的贴地标注色块已移除。

该场景最初用于编辑器内核对地形和标注的相对位置，现在是唯一可进入的和家村任务地图。保留稳定 ID `map.hejia-village`，默认解锁、零击杀目标，沿用原有进入与返回规则；出生点在局部坐标 (220, 37.58, 460)，地图资料图片为 `MapHeJiaVillageLocal`。两个既有地图道具 ID 均打开这张地图，以兼容现有背包和掉落记录。旧 2048 米、2×2 可玩场景及其地图图片已移除，四块 DEM TerrainData 保留为生成源。

场景已配置 MapContext、动态对象根、地形碰撞和昼夜天空盒。植被采用从备用 `SimpleNaturePack` 精选并复制到 `Client/Assets/Game/Art/Environment/HeJiaVillage/SimpleNaturePack/` 的资源；场景中有 1,500 株树、900 株灌木和 200 株花，Terrain 细节层另有约 10 万丛草。草层使用 Unity 的实例数散布模式，保留出生点净空，避开道路、水域及田地标注。地图图片直接拍摄局部场景，不叠加旧大图的道路遮罩；目前尚无正式几何道路、水面或 NavMesh；高度草图的人工高差尚未合入。

初版生成器拒绝覆盖已有预览目录，以保护场景中的手工调整；不能用它更新当前正式地图。若后续要根据新标注重新生成，应先设计保留现有场景内容的迁移方式；不要直接用“通用地形工具/地图地形生成”覆盖这份局部地图。
