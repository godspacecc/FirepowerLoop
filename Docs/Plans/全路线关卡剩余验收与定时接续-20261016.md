1. 读取 AGENTS.md、本文件和验证记录；检查当前 git 状态、重叠文件和 Unity MCP 项目路径、场景及 Console。不要还原并行任务内容，不默认创建 worktree。

3. 优先利用已存在且版本匹配的客户端/服务端及设备。没有可用双客户端或移动设备时先记录缺失条件，再做独立可推进的单人、表现或资源项；不能为了验收偷偷触发 Player Build。

5. 配置只改 Config 并运行 gen.bat 双端生成；协议只改源并运行 Tools/gen-protocol.ps1。保留 .meta 和原资源，核心手写代码补中文注释，遵循职责及业务技能。
6. 新证据记录日期、环境、操作、实际结果和文件位置；满足条目条件才勾选。失败记录现象、最小复现、影响及下一步，不把模拟服务端检查写成真实双人实连。
