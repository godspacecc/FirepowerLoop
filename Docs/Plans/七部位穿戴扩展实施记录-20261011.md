# 七部位穿戴扩展实施记录

日期：2026-10-11。用户确认补齐头、手、脚、背部、护甲，延续现有背包穿脱与 POLYGON City 主角风格。

## 实现范围

- 七槽身体穿戴独立于手持武器。Torso=1、Legs=2 保留原值，Head=3、Hands=4、Feet=5、Back=6、Armor=7 追加。UI 原 accessory 入口显示护甲。
- 物品从随身背包/口袋穿上，替换旧装备回来源格；卸下需要背包空格。满包、过期物品身份和旧版本拒绝路径沿用现有事务。
- 旧衣裤存档仍可读取，新增槽位缺省为空；七槽保存与领域回滚共同生效。损坏或部位不匹配数据拒绝恢复。
- 客户端协议、服务端账户、库存候选、初见/重连/变化快照、死亡尸体物品均携带七个部位。客户端消费权威快照，不把联机物品写到离线穿戴模型。
- Blender 复用当前角色骨架与色板，制作便帽、工作手套、短靴、帆布背包、工具背心。基础手、鞋、头部兜帽分离：戴帽隐藏兜帽，戴手套/换鞋隐藏对应基础网格，人物脸和身份保持一致。
- 第一人称提供基础内搭、红色上衣、橄榄色上衣分别与工作手套组合的三套手臂网格。
- 正式角色、装备页展示 Prefab、九件装备图标已生成。UI Prefab 通过原 Page/宿主生成器绑定。

本轮只实现穿戴和外观。护甲防御、背包扩容、地图掉落概率、商店、配方和开局赠送没有新增规则。现代造型仍用于换装技术验证，不等同于首章历史美术定案。
