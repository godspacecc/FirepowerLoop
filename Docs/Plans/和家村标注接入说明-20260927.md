# 和家村区域标注接入：首版粗布局

> 历史记录：旧 2×2 和家村场景及“局部标注投影到现有全图”编辑器工具已退役。以下步骤不再适用于当前正式局部地图；原始区域标注与粗布局样板资产保留作为来源记录。

## 入口与输入

- Unity 菜单：`Tools/地图/现有和家村全图/局部标注投影到现有全图`。
- 打开一块现有的 `HeJiaVillage_*_*.unity` 场景，选中其中的 Terrain 或 `GeneratedTerrainTile`，再点击“检查选中地形块”。
- 输入是已保存的区域标注资产、已确认的 558×699 卫星底图、原 DEM 和现有 2×2 TerrainData。工具校验底图与 DEM 指纹、TerrainData 尺寸和底图到 Unity XZ 的四角映射。高度草图未保存时继续使用现有 DEM，不生成额外地形高度。

## 工作流程

1. 在区域标注编辑器保存笔触，再保存目标地形场景和 TerrainData。
2. 在接入窗口检查选中地形块。窗口显示各语义层落在该块内的底图像素数；这不是实测面积。
3. 点击“在 Scene 中预览”，核对位置、朝向和跨块边缘；关闭预览不会写场景。
4. 点击“生成选中地形块粗布局”，将贴地网格、透明色块纹理和材质保存到 `Assets/Game/MapTerrainSources/HeJiaVillage/GeneratedAnnotationBlockout/`，并在该场景的 `GeneratedTerrainRoot` 下新增 `AnnotationBlockout_<版本>`。只保存这一块目标场景及新增资产。

蓝色代表水域、橙色代表道路、绿色代表植被、黄色代表田地。待确认区域不生成内容；未标注图层保持空白。粗布局网格没有碰撞，也不作为水平水面、道路通行面、植被 Prefab 或 NavMesh。它不会改变 Terrain 高度和原地表层，不生成建筑。

同一块已有 `AnnotationBlockout_` 时，工具拒绝覆盖，以保护可能发生的手工修改。重新生成前应先检查旧产物和来源版本，再明确移除旧粗布局及其对应生成资产。不要把现有地图交给“地图地形生成”按钮重建：该生成器会拒绝同名目录，接入窗口处理的是现有场景的增量内容。

## 当前来源状态

2026-09-27 的区域标注资产已保存水域笔触；道路、植被、田地和待确认层尚为空。首版只能从实际笔触生成水域粗布局色块。该标注资产当前仍未纳入 Git；要让他人复现生成结果，应连同 `.meta` 一并提交。正式水面、道路网格、植被资源和高度修正需要在粗布局核准后分别接入。

已用当前标注在 `HeJiaVillage_2_1` 场景生成一块样板，版本为 `d6d3b6ea9cf9`，该块命中 864 个水域底图像素。样板资产位于 `GeneratedAnnotationBlockout/HeJiaVillage_2_1_d6d3b6ea9cf9/`；它仅供核对投影与区域范围，不代表真实水面已建成。
