# 和家村场景现实还原路线图

> 状态：阶段 A 静态资料核对已完成，阶段 B 已进入用户选定卫星视野的粗布局确认。各阶段状态以本文记录为准。最后核对：2026-09-27。

## 1. 目标与范围

- 以现实中的和家村为参照，在现有 2048 米 × 2048 米、2 × 2 Unity Terrain 范围内，尽可能还原地貌、道路网络、水域位置、林地与开阔地分布，以及近景自然环境。
- 和家村场景不制作建筑，也不放建筑占位盒体；卫星图中的建成区只作为地表和道路判断的参考，不转成场景房屋。
- 保持地图身份、加载事务、远征时间、玩家和其他运行对象的既有职责。场景保存地形、静态环境和后续导航数据；玩法对象继续经正式配置动态创建。
- “尽可能接近现实”指在现有证据精度内可追溯、可复查。不得把参考图像素、人工描线或重采样网格宣传为实测精度；来源不明确的位置保留待核查记录。

## 3. 制作原则

1. **现实资料先于美术资源。** 先确认位置、路径和区域，再选择贴图、树木和水面表现。用候选资源测试观感，不让资源包决定真实地貌或道路走向。
2. **保留可替换的空间依据。** 道路中心线、水域范围、植被区域和人工校正记录独立于插件生成结果；占位模型与最终 Prefab 共用稳定的摆放位置或散布规则。替换时重检尺寸、贴地、碰撞、LOD 与性能。
3. **来源与不确定性同存。** 每项人工修正记录来源、日期、坐标、判断理由和信心程度。高程、遥感分类、OSM 与目视地图发生分歧时，不以单一来源自动覆盖其它来源。
4. **一块验证后再铺全图。** 先在 `1_1` 完成包含道路、池塘或排水边缘、植被与开阔地的可行样板；验证四块拼接方法后扩展，不把整图一次性手摆成难以替换的对象集合。
5. **遵守正式资源边界。** 第三方包先在原始目录或隔离场景验证；正式接入时只整理必要资源及依赖到 `Client/Assets/Game/Art/`，保留 `.meta`，不长期直接依赖备用包原始目录。

### 阶段 A：现实对照与样板范围

- 固定地图范围、WGS84/UTM49N 与 Unity 坐标对应关系，给 `1_1` 选出可重复拍摄的地面观察点和俯视对照视角。
- 将现有道路、池塘、林地、建成区参考叠图逐项审查，记录来源和模糊处；尤其区分道路中心线、路宽推测、水面保守内部与完整岸线推测。
- 产物：样板区对照图、要素核对表和争议记录。完成条件：每个计划落地的线或区域都能回指来源；未知部分明确标注，不用想象补全。

### 阶段 B：`1_1` 地形与通行样板

- 核对出生点与主要道路的高差、坡度和实际可步行区域；仅对有证据支持的局部明显误差做受控修正，并保留原 DEM 与修正记录。
- 根据已校正的中心线制作一段可行走道路，分开保存中心线依据与道路表面；路宽、路肩、坡面衔接以参考和游戏通行为约束，不能直接套用地图遮罩的符号宽度。
- 对明确可见的池塘制作水面与岸边过渡；未确认的沟渠、水线暂不实体化。
- 产物：可在编辑器对照参考图复查、可在游戏视角观察的样板。完成条件：道路连续贴地，水面不穿地，地形与相邻瓦片接缝无明显断裂，现有地图加载仍正常。

### 阶段 C：全图道路与水域

- 将阶段 B 的做法扩展到其余三块，处理道路跨瓦片连续性、池塘边界、交叉口与陡坡处的特殊形状。
- 对每条已核准的道路和每处水域保留源 ID 与场景对象或生成产物的对应记录。道路、池塘的现实形状发生修正时可以重建表现，不需重新猜测已有坐标。
- 完成条件：2 × 2 范围内的已确认道路段与参考拓扑一致，跨瓦片路段没有可见断头；已确认池塘位置与参考叠图一致，未核实水系仍标为未核实。

### 阶段 D：植被、地表与自然物

- 根据林地/开阔地参考和现场可辨资料确定分布区域、密度等级及可确认的植被类别。树种缺乏证据时按外形类别占位，不把候选资源名称当作当地树种证明。
- 先散布可替换的树、灌木、草与岩石；排除道路、水面和必要通行区。近景单独复查尺寸、随机方向、地面穿插和重复感；不预留建筑布局。
- 对比地表贴图、季节、色调与光照，保留已有昼夜时间权威；场景工具不能建立另一套时间状态。
- 完成条件：俯视分布与参考图相符，地面视角具有可信层次，替换一种植被 Prefab 不需要重画其分布区域，目标设备性能符合项目阶段要求。

### 阶段 E：导航、玩法接线与验收

- 在静态地形、道路和主要阻挡物稳定后制作导航数据；核对四块拼接、玩家通行、边界碰撞及未来敌人出生区域。新增敌人、物资或撤离点时再按 Luban 来源和地图运行对象职责另行设计与实施。
- 记录固定视角的编辑器/运行时截图和对照图；检查缺失材质、资源引用、加载/卸载与昼夜表现。安卓表现由用户手动执行打包工作流后在真机确认；代理不得触发 Unity Player 构建。
- 完成条件：形成可重复的视觉对照与通行检查记录，并把仍与现实资料不一致或证据不足的项目列入下一轮修正清单。自动化测试只按 `AGENTS.md` 的明确类或方法过滤执行。
