# 首轮持续涉水登陆

2026-10-18。用户确认延长涉水路段、增加水花和波纹，保持生成间隔并注意手机性能。沿用现有海岛流程，直接实施已确认的范围，没有新增玩法或更改敌人总量。

首轮四侧浅水带改为4.6～4.8米，外缘和四入口位置保持；出生内缩后仍有至少3米涉水路段。第一轮沙滩内缘相应内收，其它轮的轮廓不变。正式出生点、障碍和干燥出口的定向检查通过。客户端规则、服务端和地形网格仍共用ArcadeIslandRegion，生成间隔保持0.45秒。

涉水效果由ArcadeCombatViewController接收已有敌人位置并通过现有帧循环推进。每次实际移动产生少量水花与扩散波纹，重复快照、静止、传送不补播。出水停止发射，已有波纹0.7秒内淡出；移除敌人、隐藏或释放地图清理。暂停冻结。只对镜头内浅水中的敌人采样。

手机最多20组、桌面32组波纹和水花，循环覆盖最早槽位。一个动态网格、一个材质／Renderer；手机最多660顶点、540三角形。共用已登记资源中的顶点色Shader，无新增纹理、粒子系统、物理碰撞或逐敌人Update。圆周预计算、顶点和颜色数组复用；预热后200帧移动和网格更新实测托管分配0字节（Editor定向测量，不代表手机帧耗）。
