# 敌人尸体保留与淡出

普通敌人的死亡表现改为最多保留 8 秒，最后 1.2 秒淡出。原普通失衡 0.16 秒后模拟 1.4 秒、爆炸模拟 1.8 秒的物理时长保留；活动物理预算仍为手机 4 具、桌面 8 具。可见尸体另设手机 12 具、桌面 24 具上限，超额回收最旧尸体，清图立即清理。

物理预算超额只停止旧尸体的求解。尚未倒地或仍在空中的实例使用骨骼贴地回退姿态，避免长时间站立或悬空。显示时长只影响表现对象，不延长战斗实体、碰撞、伤害或掉落生命周期；单人与联机共用 EnemyCtrl。

淡出使用实例持有并复用的透明材质副本，保留逐槽颜色和覆盖块；回池恢复共享材质与覆盖块，地图释放、初始化失败和最终销毁均释放副本。特殊轮无 EnemyView 的旧燃烧轮廓仍沿用原短时表现。

验证范围：

- EnemyPhysicalReactionTests：31 项通过，覆盖物理预算、可见上限、普通／爆炸早停贴地、控制器淡出回池、覆盖块复位与材质释放。
- EnemyDeathPresentationTests：8 项通过，覆盖单人死亡来源、联机同轮移除和不重复播放；同时修正旧测试反射构造未适配火焰死亡参数的问题。
- 独立编辑器 PhysicsScene 实拍：2.2 秒时物理已冻结，5 秒仍可见，7.4 秒半透明，8 秒完全淡出。画面与空地的像素差见 verification.txt；05 为超额预算贴地回退实拍。
