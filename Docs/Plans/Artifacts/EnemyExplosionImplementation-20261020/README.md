# 爆炸死亡血雾接入验证（2026-10-20）

用户确认右侧“暗红血雾＋少量碎屑”预览后接入正式敌人表现，本记录与功能单独提交。

- 单人与双人既有死亡事实经过同一个 `EnemyCtrl.RemoveEnemy`：只有 `playDeath && explosive` 喷发，静默移除、普通死亡、电球普通范围伤害不补播。死亡记录去重沿用原链路。
- 七个正式敌人 Prefab 只增加同一个特效 Prefab 的资源引用；活敌人不挂额外粒子系统，模板依赖随敌人原有加载句柄持有。
- 每组血雾12粒、碎屑22粒、低位尘雾8粒；血雾约0.32～0.65秒消散，整组0.9秒内回池。世界坐标独立喷发，沿冲击方向偏移，碎屑没有刚体和粒子碰撞。
- 手机最多6组／252粒，桌面最多12组／504粒；超额复用槽位，过期、隐藏、清除及地图释放都清理。使用表现专属随机数，不消耗战斗或Unity全局随机序列。
- 共用现有控制器更新，通过手动粒子模拟跟随缩放时间，零步长暂停。保留既有炸飞参数、尸体寿命、可见数量和物理预算。

验证记录：新增 `EnemyExplosionFeedbackTests` 先运行9例，7例因缺少接入失败、2例原有不触发行为通过；接入后定位并修正预制粒子停止态必须先初始化的差异。最终新增9/9、`EnemyDeathPresentationTests` 8/8、`EnemyPhysicalReactionTests` 31/31，共48例通过。各次均为真实短类名筛选、`includePassingTests=true`，未执行完整套件或Player Build。
