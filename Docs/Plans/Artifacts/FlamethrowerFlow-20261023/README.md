## 侧喷证据

`player-loop.json` 读取本项目当前 Unity PlayerLoop，顺序为动画求值（DirectorUpdateAnimationBegin/End）、ParticleSystemBeginUpdateAll、ScriptRunBehaviourLateUpdate。现有 CharacterWeaponPresenter 在读取枪口及 LateUpdate 的握持处理校正喷火器主手朝向；自动连续粒子更新存在动画已重置、帧末还没校正的窗口。

`probe.txt` 使用正式 GrayboxPlayer、共享武器目录及正式火焰资源，对站定、前进、横移各采样24帧，直接测粒子速度而非仅枪模。站定时动画求值后枪口约左偏44～45度，再次校正后归零；在求值后、校正前实际Emit出的粒子速度也向左。前进/横移动作同样有偏差。粒子为World空间，之后转正枪身不会追回已发出的火焰。

`flow-timing.gif` 为1120×630、20fps、72帧、3.6秒循环。两侧均为相同正式角色与粒子资源，左按“动画→粒子→校正”、右在临时实例中改为“动画→校正→粒子”，依次站定、前进、横移。只显示近枪口粒子以隔离侧喷来源，不包含飞行判定载体，不是自然对局或双端实战录像。右侧只验证时序修正，没有解决移动拥挤，不代表完整修复候选已通过或被采用。三个PNG为对应原始关键帧，无后期改画。

## 移动拥挤证据

权威CSV `arcade_rule.csv` 玩家基础移动速度6.5米/秒，`arcade_weapon.csv` 喷火弹速8米/秒、间隔0.1秒、3路18度扇形。静止连续同路发射间距为0.8米，向前移动时中心路仅0.15米，侧路纵向约0.140米。当前弹速不继承玩家移动速度。近端World空间粒子速度5～7米/秒，未开启inheritVelocity；玩家可以追上或超过较慢火团。右侧前进画面也可见火焰聚到枪口/角色附近。紫级喷射更频繁且移速再乘1.1，会进一步缩小间距；这些是当前项目参数，不是参考游戏规则。
