# 宝藏奖励写实方向与散落摆放（2026-10-19）

根据已认可的概念预览调整实际 Unity 资源：金条使用连续倒角、压印表面和环境反射；蓝宝石使用冠部、腰线、亭部切面与固定四步内部反射/折射近似。采用正式 Prefab 引用 Shader、网格、表面图和反射图，不在运行时生成资源。

## 摆放与奖励

- 12 个金条领取点呈现 3/4/5 枚组成的小堆，共 48 枚金条；4 个宝石领取点呈现 2/3 颗的小堆，共 10 颗宝石。保留炸弹和冲刺两个正式道具模型。
- 金条与宝石穿插散落，角度、大小和交叠固定。权威落点来自 Config/DataCsv/arcade_treasure_room.csv，已通过 Config/gen.bat 双端生成；房间出生点和返回入口保留净空。
- 每堆只有一个原有奖励 ID，整堆领取、到期和渐隐。18 个领取项、单项数值及规则不变，基础分值和进度总量各为 2200；最终得分仍取决于倍率和领取次序。
- 纯视觉浮动幅度改为 ±0.018 米，缓慢旋转 2 度/秒，不改变水平拾取点。宝石分别保留对象坐标，金条小堆合并网格。

## 验证

EditMode 使用真实短 testClass、includePassingTests=true：奖励表现 7 项、规则 32 项、流程 40 项、联机表现 32 项，共 111 项通过。共享分支同名类有其他新增用例，实际数量超过执行前对流程和表现类的预估上限；未使用完整套件或无效过滤。最后穿插金条/宝石位置后再执行奖励表现类 7 项。

独立只读审查未发现 Critical/Important；旧版说明已标为历史记录。双端宝藏配置 bytes SHA256 一致，见 verification.json。没有触发 Player Build。
