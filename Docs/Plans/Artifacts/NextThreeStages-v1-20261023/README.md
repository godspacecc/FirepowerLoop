## 本次提请确认的简短设计

- **墓园**：直径约52米的环形围墙场地，四处可见门洞、中央交叉通路，墓碑组之间与外圈都可绕行。特色敌人先从翻动的泥土中升起，再追击；正式规则拟避开玩家脚下，并在出土结束后开始移动/接触伤害，不用HUD或箭头提示。
- **神庙庭院**：约54×54米，四边实体墙和门洞，中央石狮形成可绕行地标。暗影敌人由乌鸦与蓝光现身；拟采用一次换位重生：首次打倒化蓝影移到另一安全位置，第二次击杀才彻底消灭、给分与掉落。尚存蓝影时不能提前清场。本候选只演示一次换位；具体数值/比例在实现计划与定向检查中落地。
- **集市**：约48×44米，外围建筑封边，四侧各两处巷口，摊位靠边，中央与外圈保留绕行空间。以普通敌群加少量已在神庙引入的暗影敌人为特色，复用已确认的随机通道、半批重叠刷怪规则，不另造专属怪物或场景机关。动态图为一次抽样顺序示意，不固定正式开局方向；24个角色仅供看入场动作，不能当作正式轮人数/同屏上限。

三关拟各保留4轮，复用各自固定场地。清场金币箱落在玩家附近，动画结束才可拾取；整关四轮完成出现传送门。延续已有武器时效、红紫强化、掉率按敌人强度以及单人/双人规则。

本次先确认布局、尺寸关系及特色玩法/动作。正式物件造型、材质、完整动态美术须单独展示采用；本文件中的临时石狮、墓碑、乌鸦、蓝影和摊位不因布局采用自动转为正式资源。三关接入时的后继、现有40轮路线与旧档兼容需要在正式实施前明确，不从“再做三关”推导自动改为二代64轮。原作神庙阶段的独立爬塔小游戏属于另一项流程，尚未作为这三组普通关卡的制作内容获得具体确认。

## 原作依据与本项目提案的区别

主要核对 [MKillBill v2.5 场地攻略](https://gamefaqs.gamespot.com/ps4/145061-call-of-duty-black-ops-iii/faqs/72570/the-silverback-trail) 的检索正文及 [v1.0 早期镜像](https://www.cheatcodes.com/guide/dead-ops-arcade-ii-guide-call-of-duty-black-ops-iii-ps4-102803/)。支持墓园出土敌人、神庙中央石狮/乌鸦蓝光/暗影换位重生、集市紧凑多入口/普通及少量暗影敌人。后期攻略记暗影需击杀2—3次，早期记重生一次；本候选推荐固定一次重生，属于待采用的项目方案。场地米数、通道宽度、摆件位置、动作时长均为本项目候选，不宣称测得原作参数或完整方位。
