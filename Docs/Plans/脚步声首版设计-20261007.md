# 脚步声首版设计

日期：2026-10-07。

状态：用户确认方案并要求直接实施，未另写实施计划。运行时代码、正式资源和基地/河谷标记已接入；43 项定向 EditMode 测试通过，人工听感与双端/真机验收待完成。

## 1. 目标与范围

让玩家在基地与河谷移动时获得可区分地表的脚步反馈，本机玩家与联机远端玩家使用同一套计步、选音和播放规则。脚步仅是客户端表现，不参与移动权威、战斗伤害、敌人仇恨、联网协议或存档。

首版包括草地、泥土、碎石三类地表，支持走路与较快移动的音色、节奏区别。浅水、敌人脚步、落地音、装备拟音和动画事件精确对脚暂不接入。其他地图没有明确地表标记时保持静音。

自动执行不进入 Play Mode、不触发 Player Build、不默认创建 worktree、不自动提交。真机、双端联机与听感验收由人工运行；自动测试只允许已核对存在的具体类或方法。

## 3. 方案选择

采用实际距离计步。它能同时复用本机碰撞结果和远端插值结果，适配现有多套持武器移动动画，顶墙、停步和原地转身不会凭输入播放。

按时间或输入计步容易在顶墙时误播；动画事件对脚更精确，但需校准基础、持弓、持枪和方向动画，并处理混合时重复事件。首版接受距离计步与脚掌触地存在相位误差，后续只有在人工验收认为误差不可接受时再评估动画同步。

## 4. 职责与组合

新增名称和路径均为设计拟定，不代表当前仓库已有文件。

| 责任 | 归属 |
| --- | --- |
| 每个角色的距离累积、随机历史、存活门禁、短音效句柄和重置 | 普通 C# 脚步表现辅助对象，由对应 ViewCtrl 持有；不注册新领域 Model/System |
| 音效组与步距、阈值、音量、衰减参数 | 玩家表现配置 ScriptableObject，由 PlayerView 序列化引用；纯表现参数，不复制 Luban 玩法配置 |
| 地表身份 | 地面 Collider 的序列化标记；必要的覆盖区域只用于查询，不改变移动碰撞或地形 |
| 落地与脚下支撑探测 | 表现侧的窄查询辅助函数，不保存地图业务状态 |
| 空间音源、Mixer、异步加载、播放期限、资源释放 | AudioSystem |
| 远端 UnitId/MapInstanceId、实例释放、候选过期 | OnlineWorldPlayerCtrl；远端辅助对象接收当前身份，不自行推断世界 |

PlayerView 只持有序列化引用，不新增每帧更新。辅助对象由既有 Move/Tick 驱动。暂停等状态通知按创建与释放配对注册、注销；需要主动停止时，只操作该角色持有的脚步句柄。

地表标记仅描述 Grass、Dirt、Gravel。不会把碰撞体、Transform 或播放句柄发布为领域事件，也不写入存档。

## 5. 本机与远端数据流

### 本机

CharacterController.Move 完成后，取本次实际世界位移的 XZ 长度。仅在 Playing、角色活动存活、对象可见、Controller 可用、deltaTime 有效且已落地时送入计步器。转身不计距离；垂直重力位移不计距离。

现有 SnapLocal、死亡/复活状态变化、隐藏、释放和暂停通知均清空计步并取消未完成脚步请求。停步的零水平位移同样清空未达步距的累积，恢复移动后重新计步，不立即补播。

### 远端

Tick 先记录插值前世界位置，更新 localPosition/localRotation 后取世界 XZ 差值。父地图根发生位移不得当作角色移动：地图根变换或地图身份变化时重建计步基准。计步不依赖远端被禁用的 CharacterController.isGrounded。

远端通过向下支撑查询确认脚底附近有可站立地面；射线排除角色自身和 Trigger，限制探测距离，避免空中角色命中很远的地面。脚底基准来自角色 Collider 几何，不能把角色枢轴直接当作脚底。

Snap 始终清零。SetTarget 若目标差超过表现配置的纠正阈值，保持既有插值移动，但本段插值不计步；这项判断不改变网络权威位置。建议首版纠正阈值 2 米。

SetAlive 同值通知不重置；仅存活值变化时重置。断线、非 Playing、隐藏、死亡和 Entry 释放期间停止计步并取消脚步请求。恢复后只计新的移动，不补播停用期间的步数。

现有协议不能区分小幅网络纠正和真实移动，因此小幅纠正仍可能贡献距离。首版不承诺消除这类误差，双端验收需覆盖丢包和位置纠正。

## 6. 计步与选音

计步器累积有效水平距离；达到步距后最多发出本次一个脚步，保留不足步距的余量。长帧超过多个步距时丢弃额外完整步数，不集中补播。无效或非有限输入直接重置。

初始表现参数建议：走路步距 0.65 米、较快移动步距 0.90 米、快步音色阈值 4.5 米/秒、最短播放间隔 0.12 秒。它们都是可编辑的听感起点；不改变玩家速度、冲刺体力或动画权威。

脚下地表在发声时查询，切换地表后下一步使用新音效组，不为跨过边界额外发声。每个角色、每个音效组保存上次索引，组内有多个候选时排除上次索引；只有一个候选时正常复用。

草地与碎石分别配置 walk/run 组；泥土的 walk_run 同一组用于两种节奏。较快移动按实际速度选音，本机不读取 Shift，远端不新增冲刺协议。侧移和后退同样按实际距离计步。

## 7. 地表查询与场景制作

首版以明确标记为准。选择最近的有效支撑地面，再读取该 Collider 或其地面专属父节点的标记；不得在整张地图根上挂标记后让所有物体继承同一音色。未知支撑地面保持静音。

场景中一块连续碰撞网格覆盖多种可行走视觉地表时，可使用独立的地表覆盖区域覆盖该支撑地面的默认分类。覆盖区域是无移动碰撞的查询区域，仅在落地后参与选音；范围须贴合已有地表，不能把树、掉落物或角色 Collider 当作地面区域。

覆盖优先级必须显式配置，重叠时按优先级与稳定身份确定唯一结果；每次查询最多选一种地表。地面支撑探测成功但没有标记、或任何探测结果溢出查询缓存时不发声，避免不确定选音。

基地 Ground 与现有路径/碎石区按实际视觉标记；河谷 ValleyGround、ApproachPath、OldCampClearing、RiverbedAndValley 默认按泥土处理，只有明确的草地或碎石覆盖区域才改变分类。多材质河床不按三角形材质猜测是否在水里。首版不改河面，不增加涉水反馈。

场景作者只添加标记与覆盖区域，不改变地形、道路、树木、采集点、河面、NavMesh 或原有碰撞。与其他会话修改同一场景时，实施前重新核对最新内容并从 Unity 当前对象操作，不能覆盖旧整份场景文件。

## 8. 音频与异步语义

复用 AudioSystem.PlaySoundAt，保持现有调用的默认行为；脚步调用通过新增窄重载提供逐次增益、近距离衰减范围和最大开始延迟。逐次增益与 Sound/Master 音量相乘，音量刷新不丢失增益；音源回池时重置本次参数。

建议首版起点：脚步增益 0.6，minDistance 16 米、maxDistance 35 米；手工听感验收同时检查默认 14 米俯视和近距离越肩镜头。参数不改 AudioListener 位置，不改变其他音效默认衰减。

每次脚步请求以不受 timeScale 影响的时间设置 0.15 秒最大开始延迟。异步加载完成时，若句柄已被取消、角色已重置、期限已过或应用不允许播放，则释放资源并静音；不排队补播。暂停期间完成加载的非 UI 音效不能直接开始播放；该兼容性检查需覆盖已有非 UI 音效调用。

角色辅助对象跟踪本角色播放句柄；允许最多两个尚未结束的脚步，第三个请求前停止最旧句柄，控制长尾重叠。重置与释放时停止其全部脚步句柄。音效池满时脚步低优先级请求可被丢弃，不能挤掉高优先级 UI 或战斗音效。

不预加载完整备用资源包。首版使用现有 ResourceLoader 请求路径，资源句柄继续由 AudioSystem 每次播放独立持有；加载未就绪、失败或延迟过长时允许漏掉该步，不阻塞地图准备、角色出生或移动。是否需要针对少量正式音效增加预加载，由移动端延迟测量决定，不在首版先建立缓存子系统。

地图卸载继续执行 StopMapOwnedSounds；所有迟到回调只能释放自己的请求，不重新创建脚步音源。取消发生在同步回调返回句柄之前时，沿用延迟释放标记，保证一个句柄只有一个释放责任方。

### 河谷地表补充（2026-10-07）
