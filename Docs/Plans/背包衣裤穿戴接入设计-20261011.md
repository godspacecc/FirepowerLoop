# 背包衣裤穿戴接入设计

后续状态：用户确认扩展其余五个部位，七槽实现与验证详见[七部位穿戴扩展实施记录](七部位穿戴扩展实施记录-20261011.md)。本文记录首次衣裤接入范围。

状态：2026-10-11，根据用户“开始吧”及“作为背包物品：先获得衣裤，再从背包穿戴”整理。本文提出库存事务及交付范围，待审阅；不是已实现功能说明。

## 已确认目标

在游戏内获得衣裤后，从背包穿戴，装备页显示实际穿戴状态，主角外观随之改变。保留当前 POLYGON City 主角风格和身份。已有 Blender 派生样例包括红色连帽衫、橄榄色口袋上衣、蓝色长裤、棕色工装裤。本次只落实这两个有资源的部位，七部位扩展不冒充已经完成。

## 当前代码证据

- `EquipmentManagementPageCtrl` 只显示七个部位占位，没有装备数据或穿脱按钮。
- `ItemTransferCtrl.UseSelected` 是现有背包“使用”入口；本机武器交给 `WeaponEquipmentSystem`，联机武器交给 `OnlineWorldInventorySystem`。
- 当前手持保存背包格引用，不移出背包；不适合直接复用于身体穿戴。
- `PlayerCtrl` 拥有本机玩家实例和地图生命周期，`PlayerView` 提供表现引用。`OnlineWorldPlayerCtrl` 拥有远端玩家表现。
- `SaveSystem` 接收 `IScopedSaveSectionProvider`，库存和各领域在同一存档事务中恢复。
- 根 `Config/Defines` 与 `Config/DataCsv` 是物品数据源，`Config/gen.bat` 为生成入口；当前物品类型没有衣物。
- 服务端实际源码在 `Server/GameServer/Runtime/`，不是旧文档中的 Unity 源码目录。现有世界库存操作包含操作去重、版本校验、候选提交和尸体转移，身体穿戴应复用这些边界。
- 现有样例只含固定头手鞋和两套衣裤；直接隐藏上衣或裤子会出现缺失身体，不能作为卸装结果。

## 建议实施规则

### 物品与穿脱

1. 四件衣裤均为真实物品，每件占一个格，不堆叠；持有前不能选择它的外观。
2. 穿上后，物品从随身库存移入对应穿戴槽；同一件物品只存在于一个位置。武器手持规则保持现状。
3. 替换时，新衣物进入穿戴槽，旧衣物优先回到新衣物原来的格子，因此背包满时也允许合法的一换一替换。
4. 卸下时，衣物回到背包；没有可用格子则拒绝，原装备及外观保持原样。
5. 校验当前玩法状态、玩家存活、来源格版本/身份、物品配置和部位。失败不发成功事件、不改库存、不制造或销毁物品。
6. 衣裤不增加防御、温度、负重或背包容量。本批不增加耐久、染色或捏脸。

### 获得与基础外观

四件衣裤加入正式物品配置，可通过已有库存及物品测试入口取得后验证。此次不擅自增加正式地图掉落、商店定价或新档赠送；正式投放位置单独安排。

补做同风格的基础内搭，空上衣/裤子槽显示基础内搭，不继续显示一件实际没有装备的样例衣裤，也不露出网格空洞。旧档缺少穿戴分区时为空槽；不凭空补发物品。

### 游戏界面

- 背包衣物详情的操作为“穿戴”，提交物品来源与身份，成功后按库存快照刷新。
- 现有装备页的上衣、裤子部位显示实际物品及“卸下”。其他没有资源的部位继续标明尚未开放，不显示虚假已装备状态。
- 装备页展示同一角色的外观预览；退出界面后，场景内角色保持同样搭配。预览不持有第二份装备状态。
- 失败提示覆盖背包已满、来源变动和当前状态不允许。沿用本地化、现有宿主、UI 输入阻断及 Prefab 生成规则。

### 状态、保存与网络

- 新增身体穿戴 Model 保存稳定物品数据，独立 System 负责与库存的穿脱事务；UI 只提交意图。
- 玩家 Controller 在出生、切图、读档和装备事件后刷新表现；View 仅执行已确认快照。保留原骨架、武器挂点、动画控制器和相机路径。
- 库存与穿戴同时保存、恢复、回滚。死亡、失败和尸体物品沿用现有随身风险规则，不能形成额外安全仓。
- 联机由服务端校验并提交，客户端不能先把物品移出本地背包当成成功。新增独立穿戴协议字段，不复用旧武器字段。
- 初次见到远端角色、重连、重新进入地图均带完整穿戴快照；不只发送即时换装事件。
- 第一人称袖口跟随上衣，并保留现有手部和武器表现；不能仅完成第三人称后宣称整个角色外观一致。

## 修改边界

配置源、生成产物、身体穿戴 Model/System、库存交互入口、装备页 Prefab/生成 View/Controller、玩家及远端表现、存档及服务端库存/协议、相关测试。模型继续使用项目已有资源派生，正式角色引用仅在实际表现验证通过后更新。

编辑器换装窗口保留为辅助验证工具，不作为本功能的交付入口。不修改建筑地图、街机玩法、武器持有语义或正式经济平衡。不打包、不自动提交、不默认使用 worktree。

## 验收

1. 实际游戏：把获得的衣物放在背包，穿戴后该格腾空、装备页显示该物品、角色外观改变。
2. 上衣和裤子独立组合；站立、走跑和持武器时不出现身体空洞或明显接缝破裂。
3. 满背包替换成功且物品守恒；满背包卸下失败且状态不变；重复或过期操作不能复制物品。
4. 切图、读档、重连保持正确装备；远端初见和后续换装均正确。
5. 衣物符合现有死亡/尸体/撤离规则；旧档没有穿戴分区可读；损坏或未知物品拒绝恢复且不静默丢物。
6. 定向逻辑测试覆盖事务与失败分支；所有 Unity 测试使用真实类/方法过滤并事先声明最大执行数。画面单独验证，测试通过不替代视觉验收。
