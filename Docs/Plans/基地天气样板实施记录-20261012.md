## 实现与使用

进入编辑器或开发版的离线基地，按既有 C 热键打开测试指令窗口，直接输入：

| 指令 | 行为 |
| --- | --- |
| `#weather rain` | 立即中等降雨，云量与湿润度为 1 |
| `#weather clear` | 立即放晴，保留湿地，90 秒有效运行时间内逐渐干燥 |
| `#weather dry` | 立即干燥晴天 |
| `#weather demo` | 从干燥晴天开始播放 220 秒过渡样板，结束维持晴天 |
| `#weather status` | 返回阶段、雨量、云量、湿润度，不改变状态 |

进入基地默认晴天；指令只改变当前天气会话，不保存。直接切换终止 demo，重复 clear 不重启干燥时间。暂停停止时序、雨粒子和雨声；切图重置。累计日历与四季本轮未接入。

## 职责及资源

- BaseWeatherTimeline 是纯时序对象，归 BaseWeatherSystem 唯一持有；通过共享生命周期推进，不产生第二套游戏日期。
- TestCmdSystem 解析并委托领域，不直接修改画面。沿用自由输入，不修改 UI、Luban 测试目录或生成产物。
- DayNightView 合成天气与昼夜光照；MapProceduralSkyView 修改地图自有天空材质实例；晴天能恢复原亮度和天空，太阳轨道不变。
- BaseWeatherView 持有雨粒子、雨声和 6 个地面 Renderer 的独立材质，退出恢复原引用。雨粒子为玩家附近世界空间表现，使用自己的随机流，不消耗地图生成随机数。
- 正式资源为 Assets/Game/Art/Environment/BaseWeather 下两张贴图、一段雨声和两个 URP 粒子材质，来自备用 ARPG Effects 的必要副本；原包未修改，依赖不回指 Assets/Art。
- 基地 58 个非触发碰撞体截断雨滴。木屋 Roof 无 Collider，额外绑定该 Renderer 的保守包围范围截断雨滴；未新增物理碰撞。斜屋顶截断不精确贴合每个瓦面，不能当作完整建筑气候模拟。
- 装配工具为 Tools/Unity/BaseWeatherAuthoring.cs；只修改 BaseMap 场景和专用天气资源，不改 Main 场景、相机及街机既有工作。
