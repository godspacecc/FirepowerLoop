# 海岛四轮逐轮换地图实施计划

依据：[SP-REQ-002](../需求/海岛四轮逐轮换地图需求-20261016.md)。2026-10-16 用户补充授权：只报告仍不确定之处，其余直接修改；不提交、不打包。

## 实施边界

只修改本地单人休闲首场海岛，不改变联机、旧顺序路线、其余主题、敌群预算和现有轮次补空库存规则。复用正式街机地图 Context 和资源加载端口，每轮替换局部地图根、轮廓、障碍、入口和地图地标，而非复制四个含玩家的场景。四图的规则轮廓、浅水网格和阻挡共用同一来源。

现状核对：`ArcadeCombatSystem` 自动切波，`ArcadeIslandRegion` 共用单轮廓；`ArcadeRunFileStore` 版本一只存整场安全节点；`ArcadeCombatRuntime` 已持有全部临时枪、强化及锚点状态，适合保留逻辑状态并重建表现。海岛移动原先跳过障碍解析，必须与新地形一同修正。

## 工作项与接口

1. 地图：`ArcadeIslandRegion` 增加 roundNumber 构造，默认构造维持原联机语义；新增 `ArcadeIslandLayout.GetObstacles/GetSpawn/GetNameKey`。`ArcadeCombatViewController.Opening` 生成四套不同地形网格，复用沙滩、水、岩石、棕榈及营火材质；沉船使用与矩形阻挡匹配的船壳网格。对应 `ArcadeIslandLayoutTests` 和独立几何检查。
2. 存档：`ArcadeRunSaveData` 增加可空 `ArcadeIslandRoundCheckpoint`；旧版本一无节点仍从原整场起点继续。`ArcadeRunSystem.TrySaveIslandRound(checkpoint,out error)` 先原子写盘，再提交领域快照，保持 Arena，不发布结束战斗事件。存完整角色/临时效果及本场未结算金币，不存敌人与弹丸。对应 `IslandRoundSaveTests`，特别覆盖文件锁失败、幂等、第三轮宝藏回滚和第四轮提交。
3. 战斗：新增 `ArcadeCombatSystem.IslandRounds` partial 管理轮级转场、捕获/恢复、出口确认、固定入口批次预警；`ArcadeCombatSystem` 仅在本地海岛分支接入。每轮准备目标地图并等待资源成功、保存节点后才推进计时或生成敌人；失败维持冻结现场，显式重试。普通清场继续拾取计时，射击/等待不前进。第三轮宝藏沿用原规则，退出直接准备第四图。
4. 特效：保留临时枪剩余时间和强化次数/周期；固定锚点在新地图合法位置重新挂接，不调用重新发放入口。第一人称区域切换释放相机租约但保留逻辑时长，宝藏内原计时继续，回战斗图重建租约。旧敌人、弹丸、掉落及危险区逐项清理。
5. 表现：现有 `IArcadeCombatViewPort` 增加默认地图准备及预警方法，其他端口不受影响。出口复用现有 Message 对话框及 RouteGate。HUD 显示当前地图、转场/拾取状态，恢复界面明确轮起点和本轮回滚。固定文本补中英本地化，不改 UI Prefab 生成合同。

## 验证

每次使用真实非空短类或完整方法；事先声明范围及最多数量，`includePassingTests=true`，不允许无效过滤或整套回退。经 Unity MCP 确认当前连接 `E:/GitHub/FirepowerLoop/Client` 的 Boot 场景与 Console；场景脏时仅重载已授权 Boot 临时状态。

- `IslandRoundFlowTests`：出口确认、射击不换图、转场计时、地图/保存失败重试、效果和锚点继承、宝藏/恢复、入口预告和预算、营火预警、障碍移动及弹丸。
- `IslandRoundSaveTests`：完整节点、写盘失败不提交、幂等/跳轮、宝藏中断回滚、第四轮恢复、旧档以及结果清理。
- `ArcadeIslandLayoutTests`：四图差异与地形通达；独立 geometry 检查保留联机默认轮廓。
- 已受行为影响的 `ArcadeOpeningFlowTests`、`ArcadeTreasureRoomFlowTests` 更新断言后定向回归；相关第一人称和原双端规则按短类定向回归。
- 手动画面验收按需求 A1–A13：岸线/路线可读、入口声音先于生成、沉船绕行和浅水近路、营火边界、出口交互及临时视角重建。自动测试不替代可操作画面验收。

## 技术决定与待验证

入口顺序及敌群批次固定，批次数量从既有完整轮预算分割，不增加预算；预警时长采用现有接触无敌秒数作为初始可验证值，后续试玩再调。地图尺寸使用正式规则半宽半高，保留原移动速度、水减速和火伤。配置权威源若需改动仅通过 `Config/gen.bat` 双端生成；本次几何属于既有代码生成地图布局，不复制配置默认值。

已有资产未找到沉船模型，先交付有真实阻挡和专用船壳网格的布局；是否需要独立精制美术由后续画面验收决定。存档兼容限定本项目已有版本一，不读取或导入另一个项目玩家数据。
