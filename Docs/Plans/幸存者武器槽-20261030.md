# 幸存者武器槽与无人机实施计划

> 使用 executing-plans 在当前会话逐项实施；用户已明确“可以 继续做吧”，不重复审批技术方案。

**目标：** 三个武器槽，步枪初始一级占一槽，三选一获取常驻无人机，拥有后只升级现有无人机。
**依据：** 执行总清单“幸存者武器槽与无人机”及当前会话已确认的 Steam Demo 适配方案。
**架构：** SurvivorModel 持有本局装备状态，SurvivorSystem 裁决获取、升级、射击及暂停；独立 Luban 武器等级表提供数值，不修改闯关无人机规则。UI 读取等级快照，保持原三选一布局。
**技术：** Unity C#、QFramework、Luban。

## 约束与检查重点

- 不创建 worktree，不打包，不改闯关存档；共享工作区仅纳入本任务文件。
- 正式 HUD、卡片视觉与无人机接入须先展示静态/动态预览并确认。
- 连升与旧版本回调只能消费一次；槽满仍允许升级；满级剔除；暂停停止所有武器。
- 第一次选择保证一个无人机获取选项，其余候选不重复；权重来自配置。
- 重开清除装备；资源随现场释放；独立武器伤害与角色全局伤害相乘，射速同理。
