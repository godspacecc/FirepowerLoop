# 海岛轮廓与普通流程提交记录

本记录对应用户“全部提交”要求，保存当前实现与整个工作区已有改动，不作为人工体验验收通过声明。

## 街机实际接入

- `ArcadeIslandRegion.cs` 统一定义沙滩、浅水和可走外缘；`ArcadeIslandMesh.cs`、`ArcadeIslandAuthoring.cs` 与 `ArcadeCombatViewController.Opening.cs` 使用同一轮廓生成和接入网格。单人战斗、服务端权威和联机移动预测读取同一边界；浅水减速倍率仍为配置中的 0.55。
- `ArcadeCombatSystem.Island.cs` 与 `OnlineArcadeRunSystem.Island.cs` 接入岸边/水侧交替入场、边界约束、实际冲刺路径击杀及普通击杀积分。保留四波总量、敌种、生成节奏和同屏上限；危险与清理死亡不计击杀分。
- 普通玩家击杀按基础 100 分乘当前倍率结算，倍率规则来自用户明确确认。统一死亡入口避免重复计分，并沿用积分生命奖励规则，不增加现金或财宝倍率进度。
- 炸弹成功消费后，海岛保护剩余时间至少为 3 秒；视图复用现有护盾资源显示实际保护状态。第四波营火沿用现有配置及伤害入口，火焰、烟和危险范围在现有 Prefab 中接入。
- 双端 Treasure 分支在第三波清场后自动进入现有宝藏房，阻止第四波与休息计时抢先推进；退出或超时后开始第四波。
- `ArcadeRunSystem.cs`、HUD、联机房间控制器和服务器安全节点事务采用空报价普通节点。普通开局和场间不打开购物界面，仍使用现有保存字段、目的地选择与 ready 协议。旧普通节点报价在恢复时清理，已经尝试的特殊挑战保留原恢复行为。实际商店/挑战能力未删除。

资源接线位于 `Client/Assets/Game/Prefabs/SceneObjects/Arcade/ArcadeIslandVisualSet.prefab` 的 `Island/Sand`、`Water`、`Shoreline` 和 `Campfire`；新增网格与浅水/岸线材质位于 `Client/Assets/Game/Art/Arcade/Island/`。资源沿用当前加载句柄、过期回调检查和释放路径。

本轮没有更改 Luban CSV、协议或存档格式，也没有运行配置生成、资源打包或 Player 构建。
