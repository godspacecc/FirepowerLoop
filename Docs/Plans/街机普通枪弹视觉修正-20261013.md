# 街机普通枪弹视觉修正（2026-10-13）

用户确认仅调整枪弹视觉资源及必要接线。普通基础枪、连射枪、散射枪及无独立弹体的镭射枪使用现有短子弹；特殊弹、玩家弓箭和敌方箭形表现保持原样。不扩展武器或敌方弹种。

## 原因与实现

- `ArcadeRunDefaults.ProjectileConfigId` 原为 `projectile.arrow.basic`，普通枪的空视觉字段落到 `GrayboxArrow`。现改为 `projectile.bullet.basic`，实际 Provider 映射为 `Prefabs/Combat/GrayboxBullet`。
- `ProjectileCtrl.PrepareMapAsync` 在街机模式预载现有投射物表，分别保存子弹与箭地址；缺少任一配置或 Prefab 加载/校验失败，准备失败并走原回滚入口。候选地址随地图提交、回滚与释放清理。
- `GrayboxBullet` 的已有特殊模型受到短根缩放影响：直接更换所有投射物载体会缩短特殊模型。因此显式特殊模型继续使用原箭 Prefab 及其模型绑定；普通空视觉字段使用子弹 Prefab。未修改任何弹体 Prefab。
- 现有敌方投射物继续使用原箭载体，并关闭玩家特殊模型。`weapon.bow` 在 `arcade_weapon.csv` 显式登记 `GrayboxArrow`，不改变其规则或新增敌方弹种。
- 复用池按实际 Prefab 地址划分，活动 ID 记录载体地址。相同 ID 改换载体时隐藏并归还旧实例，复用时重新设置模型开关；地图释放销毁全部池中实例。
- `GrayboxBullet` 已登记 YooAsset 街机 `arcade` 资源组，箭 Prefab 保持启动资源组；无需新增下载资源或修改收集地址。街机下载入口仍通过 `OptionalGameplayResourceSystem.GetMapTag` 选择 `arcade`。
- CSV 通过唯一正式入口 `Config/gen.bat` 成功生成；实际变化只有客户端与服务端 `tbarcadeweapon.bytes`，未手改生成文件。Provider 使用实际客户端 bytes 验证通过；服务端未重启、双端在线状态未验收。

## 范围保持

未改伤害、射速、速度、寿命、散射五枚及角度、穿透次数、爆炸半径、规则出弹位置或表现枪口过渡。街机碰撞仍由 `ArcadeCombatSystem` 的二维规则裁决（`ProjectileHitRadius = 0.45f`）；短子弹 Prefab 自身较小的 Collider 不参与该规则，`Bind` 保持无碰撞回调。正式弓箭与箭塔继续沿用原箭资源、Collider 和三维扫描。

- 新增两个 `BowProjectileTests` 方法：实际生成配置、正式资源与真实控制器下验证四种普通枪短弹体、散射五枚及单一可见 Renderer；三轮普通/穿透/火箭/榴弹/弓箭/敌方切换及池复用中无旧模型残留，特殊模型尺寸与原箭 Prefab 一致。
- 普通枪测试先在旧实现失败（基础枪弹体包围尺寸约 0.907 米），修改后通过。收尾恢复最终代码后再次通过。
