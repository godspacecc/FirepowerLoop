# 造型库测试场景

造型库用于从真实游戏入口检查角色 Prefab、Humanoid 动画和武器挂点。先进入**离线基地**，在“测试指令”的“造型预览”分类执行 `#gallery`；仅 Unity Editor 与 Development Build 可进入。街机战斗或联机地图中的同一指令会被拒绝。

场景以附加方式加载，基地地图保持原样；打开期间暂停游戏时间、隐藏原先可见的基地 HUD 并屏蔽正式玩法输入，退出后卸载测试场景、恢复先前的时间缩放与 HUD 显示状态。预览只操作临时实例，不调用正式装备事务、战斗结算或存档写入。

## 操作

### 共享武器与游戏内微调（当前入口）

当前场景使用 `CharacterWeaponCatalog.asset` 的共享武器与动作目录。同一武器在各个人物上共用同一组待机、方向移动和攻击动作；以下旧版玩家分层、原配与试装说明仅对应未启用共享目录时的兼容路径。

- 右侧顶部保留武器与动画选择。“浏览”页选择人物、外观与镜头；“微调”页编辑握持姿态，左侧人物预览立即更新。面板与人物相机共同适配设备安全区，避开刘海、摄像头和底部手势区域；旋转屏幕时同步更新边界。
- 微调页的装备列表不提供“无武器”。从空手预览进入微调时自动选择目录第一把武器，已有武器选择在切页时保留；浏览页仍可选择空手。
- 作用域选择“当前动画姿态”或“武器默认姿态”。位置（米）、旋转（相对主手骨骼的欧拉角，度）、缩放分开显示 XYZ。可直接输入，或用正负按钮按所选步长调整；输入完成时提交。
- 每次只覆盖当前编辑的位置、旋转或缩放组。未编辑分量继续继承默认值。解析顺序为：资源默认姿态、本机默认覆盖、资源逐动画覆盖、本机逐动画覆盖。
- 调整立即在本机会话中生效，正式战斗的 `CharacterWeaponPresenter` 读取同一姿态系统。切换人物、动画和武器不会重置已调整值；退出造型库后未保存值仍在本次会话中保留。
- “保存到本机”写入 `Application.persistentDataPath/Settings/weapon-poses.json`，下次启动自动恢复。保存失败保留未保存标记和旧文件；主文件损坏时尝试 `.bak` 备份。“恢复所选默认”只删除所选武器/动作作用域的本机覆盖，仍需保存。
- “导入 / 导出”打开 JSON 输入区。导出复制整份会话配置（包括未保存调整）；粘贴后导入会替换整份本机会话配置，验证失败保持原值，导入成功后还需保存。Unity 与开发版游戏均使用同一格式。
- 武器按目录 `Id`，动画按 `CharacterAnimationDefinition` 资产名保存身份。重命名动作资产时需迁移已有 JSON；未知武器或动作的导入会被拒绝。

这些调整只影响本机表现，不改变装备、伤害或联机权威数据，不写入原目录资产，也不涉及 Luban 表与生成流程。微调本身可在开发版游戏运行；本次未执行 Player 打包或移动设备验证。

- 右侧依次选择角色、外观、装备、动画。下拉框的条目可滚动，新增内容不需要新增按钮。手枪 `PistolIdle`／`PistolFire` 按正式 Animator 的基础待机与手枪上半身层采样；长枪 `RifleIdleAiming`／`RifleFire` 按正式基础待机与长枪上半身层采样，普通长枪开火预览叠加程序后坐，霰弹枪预览其独立开火状态。玩家动画列表末尾的“实战组合：跑动（按当前装备）”会采样正式跑动基础层及步枪上半身层。其余条目仍是单段原始动画，不能当作实战持枪姿态。
- “播放／暂停”控制动画；拖动进度条会暂停并停在指定时间，点击播放继续循环。
- “切到俯视／切到近景”切换视角。近景可在左侧人物区域拖动旋转、鼠标滚轮或触屏双指缩放；“重置镜头”恢复默认角度。
- “返回基地”或 Esc 卸载测试场景。

切换玩家装备时，如果当前动画仍适用，新列表保持该动画或“实战组合”的选择；不再适用时按手枪、步枪或弓选择对应待机，其余装备退回通用待机。现有动作逐类筛选：近战攻击只在无装备预览中出现，手枪／步枪／弓专属动作只在对应装备中出现，受击和死亡仍可查看。枪械列表中的通用待机与跑动不代表正确握持姿势，界面会提示这一点；弓的正式控制器按玩家朝向下的移动方向混合前、后、左、右四种举弓步法。新加入但尚未分类的片段只在无装备时出现，需确认适用装备后才会列入持武器选项。

玩家装备末尾另有“灰盒弓（仅预览）”：临时实例使用与正式装备相同的 `GrayboxBow` Prefab、`TbWeaponAppearance` 姿态、玩家左手挂点和 Animator 片段，不修改装备数据。弓待机、四方向移动与射箭已接入正式角色；搭箭仍只供姿态筛选。右移采用 Mixamo `Right Strafe Walk` 的直立原地步法与已验证举弓待机上身曲线合成的 `BowAimWalkRightComposite`，避开 `Standing Aim Walk Right` 的弯腰姿态，也不使用会交换握弓手的 Mirror。正式移动由 `PlayerViewCtrl` 传递已结算的世界位移，`PlayerView` 按角色本地方向选择前、后、左、右片段并覆盖基础 Animator 的 Run 槽位；造型库预览相同的动画片段。左移和后移沿用此前下载的 `Standing Aim Walk` 片段；最终美术质量仍需在实际模型上验收。

玩家街机枪械与造型库共用 `PlayerViewCtrl` 的武器姿态选择规则及 `PlayerView` 的副手骨骼求解：正式持枪瞄准和预览中的兼容动作都会在骨骼求值后对齐左手，换弹等需要放手的动作不强制贴枪。握点保存在正式玩家 Prefab 的各武器外观绑定中，造型库不另存偏移。手枪正式 Animator 的独立上半身层包含 `Pistol Aim`／`Pistol Fire`，遮罩不覆盖 Root，以保留基础层的直立站姿；步枪层仍保留原有 Root 覆盖。造型库手枪待机与开火条目直接采样这些正式状态。受击时暂时退出持枪姿态，结束后恢复。其他原始单段预览仍不等同于完整实战状态切换。

霰弹枪在原有长枪待机层上使用独立的 `Shotgun Fire` 状态，开火结束返回 `Rifle Aim`；切换到其他长枪时清理待触发的霰弹枪动作。造型库霰弹枪待机与开火条目直接采样这两个正式状态。其他长枪仍使用原有待机层和程序后坐。

当前角色来源为 `Assets/Game/Scenes/Maps/AppearanceGallery.unity` 中 `AppearanceGallerySceneView.characterPrefabs` 引用的正式 Prefab。动画下拉框从当前角色 Animator Controller 的 `animationClips` 读取；玩家新片段需先分类，才能显示在对应武器选项。玩家装备下拉框从 `PlayerView.arcadeWeaponVisuals` 读取正式街机武器外观。敌人装备选项由正式 `EnemyView` 生成，挂载、切换与清理也统一由 `EnemyView.SetWeaponPresentation` 负责；造型库只调用此入口，不再维护另一套外观实现。近战试装网格与材质统一配置在 `Assets/Game/Art/Arcade/Weapons/EnemyPreview/EnemyWeaponVisualCatalog.asset`，玩家武器外观直接读取该资产引用的正式 `PlayerView`。试装选项标注“仅试装”：正式敌人默认仍用 Prefab 原配武器，试装不接入射击、枪口、弹道、伤害或存档，敌人也仍沿用原攻击动画，因此敌人试装枪械时显示的仍是原角色动作，并非匹配枪械的动画。弓手原配仍是灰盒弓；本地备用库尚无验证过的兼容弓模型。新增角色时，把已验证的正式 Prefab 加入场景的角色引用数组；不要长期引用 `Assets/Art/` 备用资源。

切换角色或动画时，预览会按当前可见角色网格在该动画起始帧的最低点单独对齐展台。展台和其他角色不随之移动；动画后续帧的原始上下运动会保留。

此场景验证**外观、动画和挂点**，不验证武器伤害、弹道或联机同步。测试场景位于 YooAsset 的 `development` 收集目录，正式发布流程仍须确认开发资源没有被纳入正式资源包。
