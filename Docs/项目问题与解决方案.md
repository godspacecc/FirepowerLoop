# 项目问题与解决方案

记录项目中遇到的问题、判断依据、处理步骤和验收方法。后续问题直接追加，条目多了再按主题拆分。

## 导入 Unity 美术资源包后材质发紫

### 问题现象

资源包导入后，场景里的模型、预制体或材质预览显示为亮紫色。商店写着支持 URP，刚导入的 Demo 仍可能发紫。

### 原因与判断

FirepowerLoop 使用 URP。亮紫色通常表示 Unity 无法用当前渲染管线绘制该材质，例如材质仍使用 Built-in 的 `Standard`，或 Shader 丢失、编译失败。先选中一个发紫的物体，从 Renderer 的材质槽找到对应的材质，再看 Inspector 的 **Shader** 和 Console 报错。

商店的兼容性说明和当前本地安装包的内容要分别核对。在包内查看说明、URP 材质目录和附带的 `.unitypackage`。如果没找到，再到 **Package Manager → My Assets** 查看这个包的版本和可用更新。

### 解决步骤

1. **有作者提供的 URP 版本时，优先按包内说明启用。** 如果包内附带 URP 安装包，用 Unity 的导入流程处理。导入确认窗口中核对覆盖范围，再打开原包 Demo，检查预制体实际引用的材质已切到 URP。
2. **只找到 `Standard` 材质时，先停下来确认。** 保留缓存里的 `.unitypackage`。获准后，在 **Project** 窗口定位 `Assets/Art/<资源包名>/`，复制一个代表性 `.mat` 到临时位置，用副本预览。选中副本，执行 **Edit → Rendering → Materials → Convert Selected Built-in Materials to URP**，把它用在临时场景中的示例模型上看效果。预览通过并确认后，才选中该包中需转换的原材质，用同一个命令原地转换，保留 `.meta` 和现有引用。操作范围限定在当前包。 [Unity 官方材质转换说明](https://docs.unity3d.com/Manual/upgrade-material.html)
3. **自定义 Shader、Shader 丢失或转完仍发紫时，定位到具体材质再处理。** 先检查 Console 和包内说明，确认是否缺少作者提供的 Shader、依赖或 URP 版本。需要替换 Shader 或手工适配时，说明影响和工作量，再决定怎么处理。

### 验证方法

- 在 Inspector 检查材质使用预期的 URP Shader，例如从 `Standard` 转出的材质应为 `Universal Render Pipeline/Lit`。核对贴图、颜色、贴图平铺和偏移。
- 打开原包 Demo 或代表性预制体，确认实际渲染正常，检查透明、裁切、自发光等材质效果。Demo 没用到的材质单独检查。
- 确认原来的预制体和场景仍引用正确材质，且游戏正式资源没有新增对备用包的引用。

### 已处理案例

| 资源包 | 本机情况 | 处理结果 |
| --- | --- | --- |
| POLYGON Prototype | 原包附带 `URP_ExtractMe.unitypackage` | 启用作者提供的适配，原 Demo 的 1,154 个材质槽均使用 URP。 |
| POLYGON Icons | 当时本地版本为 1.2.0，包内只有 17 个 `Standard` 材质，My Assets 未提供更新 | 经预览确认后，用 Unity 转换器将 17 个材质原地转为 URP/Lit，保留 GUID。原 Demo 的 525 个渲染材质槽均使用 URP/Lit。 |
