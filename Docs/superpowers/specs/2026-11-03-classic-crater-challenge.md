# 经典巨人城挑战模式实施设计（独立模式确认版）

## 已确认目标
从“开始游戏”的模式选择进入新增挑战。参考 CF 端游经典巨人城废墟，镜头保持项目俯视角，武器有弹匣、换弹时间和备弹上限。首轮按既有单人范围落地。

## 玩家流程
选择挑战 → 进入经典废墟布局 → 逐关击退敌群 → 利用中央补给点补充有限备弹 → 完成限时奖励阶段与泰坦战 → 本局分数及结果。
关卡推进由实际敌群清除和关卡条件驱动。泰坦阶段需分别实现冲撞与地面预警后火箭攻击。弹药耗尽时开火无效，玩家需要回补给点补充备弹。

## 弹药规则
每把枪独立保存弹匣与备弹。按 R 请求换弹，换弹期间停止射击。完成时按缺口和实际备弹中较小值装填。满弹匣或零备弹时忽略换弹。空弹匣继续扣扳机时自动请求换弹。暂停冻结计时，退出回收状态，换枪取消未完成换弹但保留各枪弹药。补给点补备弹至上限，不直接填满弹匣。一发霰弹消耗一枚弹药。弹匣容量、备弹上限、换弹时长按枪配置；具体数值尚未定案，不能标作原版数值。

## 工程接入
入口使用现有开始菜单，新增卡片先预览确认。使用独立 ChallengeModel / ChallengeSystem 和独立配置维护全部玩法状态。基础输入、地图加载和表现端口可复用；不得调用现有 ArcadeCombatSystem 或 SurvivorSystem 的战斗推进。闯关强化、商店、倍率、掉落与幸存者自动攻击不进入挑战模式。弹药由战斗状态持有，输入只提交换弹意图，HUD显示权威弹匣/备弹/换弹进度。配置新增权威源并双端生成，资源按真实 YooAsset 地址校验。局内战斗只保存分数和结果。

## 俯视角适配与验证
高低层需要真正的可行走高度、层间连通与射线遮挡。不得仅把所有道路压平而宣称地图完成。先制作路线俯视图和玩家镜头预览供视觉确认。
定向验证射击扣弹、弹药不足装填、取消/暂停、换枪保留、补给上限；模式入口与结果隔离；真实地图可达性、出怪与清关互锁。所有测试限定方法或短类及最大数量，禁止整套测试和打包。
