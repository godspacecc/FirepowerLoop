# 二代参考：骷髅强化与紫级武器差异设计

**状态：功能方向已确认，列入待做；尚未接入本设计中的新规则。** 本文是待实施设计，不作为已实现功能或原作精确数值表。

## 目标与范围

让玩家通过拾取逐步强化当前武器：普通、红级、紫级形成明确的火力层次；有资料支持的紫级武器保留各自攻击特点。单人和现有双人使用一致规则，每位玩家单独持有强化状态。

采用 Dead Ops Arcade II 可核实的机制，缺少证据的效果不凭空补齐。精确伤害、射速、移速、补时量和持续时间属于待调项目参数，不能标为原版数值。本设计不引入局外成长、钱包或 AnotherDay 数据。

## 当前实现基线

- 当前红、紫骷髅分别使武器伤害及射速乘以 2、3，配置持续时间均为 20 秒；这些是 FirepowerLoop 现有参数。
- 红、紫拾取及弹体等级表现已存在。较低级拾取不会覆盖已有紫级；同武器重复拾取目前只刷新临时武器时间，不升级骷髅等级。
- 当前没有紫级专属移速增益，也没有本设计所列的紫级三联追踪、反射触电接线。
- 换成不同武器、临时武器到期等边界已有清除入口；具体暂停、死亡、清场等待和军械库保时应在实施时分别回归，不能因新增升级规则顺带统一所有时钟。

## 待做功能

### 升级与拾取

1. 武器采用普通 → 红级 → 紫级三个状态，紫级封顶；不把重复拾取计算成无上限倍率叠乘。
2. 重复拾取当前同一把武器可逐级升档，并补充相应有效时间。第一次获得不同武器不当作重复拾取升级。
3. 骷髅用于强化当前武器并补充强化时间；已有紫级不会被较低级拾取降级。
4. 小、大骷髅的升档量及补时量需要明确配置。现有资料能确认大小影响计时条补充，但不足以把“两个小骷髅必定升紫”等完整转换表写成原作事实。
5. 换成不同武器时清除原武器的临时强化；强化到期退出相应等级。换枪清强化作为本项目保留规则，并注明其原作依据目前主要是二级资料。
6. 双人各自计算武器、等级和剩余时间；一个共享地面拾取物只能被实际领取者消费一次。

### 通用强化

- 红级提高当前武器伤害和射速。
- 紫级进一步提高火力，并增加轻微移动速度收益。
- 伤害和射速增益、紫级移速增幅分别配置；不从同一个倍率字段推导所有效果。
- 不把紫级轻微加速直接替换为靴子效果，也不在冲刺、浅水、其他移速加成之间产生未定义的叠乘。
- 强化按发射时状态写入弹丸；后续升级、换枪或到期不能追溯修改已经飞行的弹丸。

### 各武器紫级差异

| 武器 | 待实现或保留的紫级表现 | 依据与限制 |
| --- | --- | --- |
| 火箭筒 | 快速发射三联追踪火箭 | 原攻略明确描述三联、追踪及快速射击；不把发射间隔、追踪转向速度和爆炸半径示意值认作原作参数 |
| 射线枪 | 反射弹及触电效果 | 原攻略明确提到反射和类似电球的触电；反射对象、跳转方式、次数及作用范围仍需补证或明确采用项目方案 |
| 榴弹枪 | 强化为快速连续发射的榴弹发射器 | 原攻略支持快速连发；不额外指定三发齐射、分裂或弹数增益 |
| 连射枪／机枪 | 提高伤害与射速，紫级进一步增强 | 尚无足够依据添加新的弹道机制 |
| 散弹枪 | 保留散射基础形态并增强火力 | 紫级强火力有资料支持；不自行增加穿透、分裂、弹丸数或射程 |
| 喷火器 | 提高火力，保留基础武器行为 | 原作喷火器本身的减速效果不能写成紫级专属效果；本项目减速是否补齐另行核对，不自动并入本次待做 |
| 基础手枪、穿透枪及其他项目武器 | 先按通用等级参数处理 | 不把项目武器强行对应成二代同名武器；没有依据不追加特殊弹道 |

第一关目前开放基础枪、连射枪、散弹枪和喷火器；本设计同时记录后续解锁武器的紫级差异，不为验证这些差异而改变正式解锁关卡或掉落池。
