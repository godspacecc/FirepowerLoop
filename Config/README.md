# FirepowerLoop Luban 配置

`Config/` 是客户端和服务端 Luban 配置的唯一权威源。

- Schema：`Defines/*.xml`
- 数据：`DataCsv/*.csv`
- 目标与组：`luban.conf`
- 唯一正式生成入口：`Config\gen.bat`

从仓库根目录运行 `Config\gen.bat`，一次生成、校验并发布双端产物。生成文件不能手改；服务端配置变化后须重启本项目服务器。

| 目标 | 生成 C# | 生成 bytes | 表数 |
| --- | --- | --- | --- |
| 客户端 | `Client/Assets/Game/Scripts/Model/Config/` | `Client/Assets/Game/Config/` | 26 |
| 服务端 | `Server/GameServer/Runtime/Model/Generated/Config/` | `Server/GameServer/Config/Luban/` | 20 |

共 32 张源表。`c` 组提供客户端共用物品、武器、表现、地图、出生点、玩家、掉落与诊断命令；`e` 组提供 12 张双端街机规则表及敌人与投射物配置；`s` 组保留 6 张服务器基础设施表。基地、远征、撤离、制造、文明、临时建筑和开放世界配置已移除，服务器启动表不再启动 OnlineWorld。

`map.another-day.arcade` 是保留的稳定地图 ID，仍指向 `TaskSampleMap`。`map_scene_part` 与 `map_display` 保留空表以维持共用地图适配契约。历史地图图片及图标资源保留，不由 Luban 生成。旧地图资料生成工具已移除。

`arcade_solo_drop` 仅面向客户端，保留第一场临时第一人称的权重 5、持续 20 秒配置；服务端不生成此表。街机宝藏、装备、强化、金币、商店、挑战及单人/双人规则保留。`arcade_reward` 为现有街机目录契约保留空表，已去除 scrap/core/token 局外奖励行，不提供成长钱包。

发布阶段先读取旧版生成 `Tables.cs` 实际登记的加载名，仅删除这些名称中不再生成的 bytes；C# 仅清除带 `<auto-generated>` 标记的过时源码。现有 Unity `.meta` 与目录中的无关资源均保留。相同产物按内容散列跳过覆盖，避免不必要的 Unity 重导入。
