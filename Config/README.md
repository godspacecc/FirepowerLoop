# FirepowerLoop Luban 配置

`Config/` 是客户端和服务端 Luban 配置的唯一权威源。

设置界面新增文案以 `Localization/settings-visuals.json` 为权威源；`gen.bat` 完成双端生成后调用 `publish-localization.ps1`，仅发布其中声明的键到客户端两种语言 JSON，其它历史文案保留。

退役文案以 `Localization/retired-keys.json` 的明确键清单为权威源，发布时同步从两种语言删除，保留其它键的行序和格式；退役键不得同时出现在增补源中。当前清单525键，覆盖已移除的基地、远征、背包、制造、文明、地图道具、火把和旧物品文案，不删除现役街机、衣物与敌人武器文案。完成正式发布后，通过 Unity 菜单 `Tools/本地化/生成文本常量`（`Game.LocalizationTextGenerator.GenerateTexts()`）重生 `TextsGenerated.cs`，不手改生成成员。

- Schema：`Defines/*.xml`
- 数据：`DataCsv/*.csv`
- 目标与组：`luban.conf`
- 唯一正式生成入口：`Config\gen.bat`

从仓库根目录运行 `Config\gen.bat`，一次生成、校验并发布双端产物。生成文件不能手改；服务端配置变化后须重启本项目服务器。

共 41 张源表。`c` 组提供客户端共用物品、武器、表现、地图、出生点、玩家、掉落与诊断命令；`e` 组提供 22 张双端街机规则表及敌人与投射物配置；`s` 组保留 6 张服务器基础设施表。基地、远征、撤离、制造、文明、临时建筑和开放世界配置已移除，服务器启动表不再启动 OnlineWorld。

`arcade_round_layout.Barrels` 复用入口点坐标格式 `x|y;x|y`，为空表示本图没有预置可射桶。当前仅 Barrage（配置 3）四图各有两个，数组零基索引与地图 ID、Version 共同确定桶身份；该主题布局版本为 2，其余主题仍为 1。桶位由共享参数校验有限数、地标和障碍重叠，并按实际场地尺寸验证可达性。

漩涡桶使用同表的 `BarrelDropSeconds=5`、`BarrelPullRadius=12`、`BarrelPullSpeed=2.5`、`BarrelHealth=40`。载桶敌人按活动战斗中的出生年龄放一次桶，随后成为普通敌人；受控停步不暂停倒计时。提前击杀保留敌人范围爆炸，卸桶后死亡不再爆炸。预置桶和动态落地桶均吸引范围内已落地物资，吞入后删除，不计拾取、不发奖励，炸桶也不返还。未打开的武器空投不被吸取；暂停、清场、切图和全员奖励房冻结。桶耐久归零后只伤敌人，玩家免受桶及载体爆炸伤害。动态桶、剩余耐久与吞物状态属于当前地图现场，沿用轮前回滚，不独立写入存档；预置桶已毁索引沿用既有恢复合同。以上数值为项目参数，不代表参考游戏原始数值。

正式休闲海岛四轮使用固定布局：中央约30×30米保持干燥畅通；山脚实体阻挡在外围，每图三条通道同时作为入场与清场出口。第一轮东海岸、第二轮东南海岸并从停船码头进敌、第三轮西海岸、第四轮南海岸。所有普通关卡轮次按真实通道数均分本轮敌人总量（余数分给前面的批次），随机排列不重复通道；前一批实际刷出一半（向上取整）即开启下一通道，旧通道按原敌群出生间隔继续刷完。各通道独立计时，共用原整轮总数及同时存活上限；单双人使用相同规则。`arcade_round_layout.EntrySegmentSeconds` 保留数据契约，普通轮不再用它定时切换来敌方向。暂停、资源准备、复活、奖励区域和清场等待不推进通道计划；无新增方向预告、箭头或声音，独立Boss和挑战流程保持原规则。

`arcade_arena.EnemySeaApproachDistance` 保留旧顺序模式的深海接近距离；配置1为6米，其余为0。正式海岛借此限定通道外生成距离为 `min(4, distance×0.67)`，当前为场地边界外4米，三条车道偏移共不超过±0.9米；生成后连续追向玩家，不能在活动区直接出现。第二轮木板船梯按干地行走。海上攻击仍按距离与冷却裁决，敌人死亡掉落投影回玩家可达岸内。

`arcade_round_layout.WeaponSpawnPoints` 使用相同的 `x|y;x|y` 坐标格式；80 张正式轮地图各配置 6 个固定候选点，`WeaponSpawnCount=2`。普通轮开始时无放回抽取本轮点位，随后逐把生成：首把按 `WeaponSpawnFirstDelayMin=3`、`WeaponSpawnFirstDelayMax=8` 秒等待，后续每把在上一把实际投放后按 `WeaponSpawnDelayMin=20`、`WeaponSpawnDelayMax=30` 活动秒重新等待，正常第二把约在开战后23～38秒投放。单次推进最多生成一把，大步长不追赶连发。按 `arcade_drop` 中当前进度可用的临时武器权重选枪，复用原拾取、地面寿命及总数量预算；预算满则保留待刷点位，解除阻塞后投放一把，再为下一把完整计时。暂停、切图、奖励房和清场冻结时钟。单人由战斗系统推进，双人由服务器通过相同的共享规则统一推进并同步掉落，挑战及独立 Boss 不额外刷枪。点位参与地图连通性校验；每轮仍只计划两把，不无限补刷。

头骨强化复用 `arcade_powerup` 的 `WeaponSkull`：小头骨倍率 2（红弹），大头骨倍率 3（紫弹），伤害和射速同时增强；两者均为本项目首版 20 秒，进入普通击杀掉落池，不是原作精确持续时间。所有头骨与同枪领取按arcade_weapon_upgrade至少补到20秒且不缩短，低级不降紫，重复拾取不叠乘；换成其他武器或临时武器到期清除，同枪再次领取普通→红→紫、紫封顶，并保留更长武器余量。紫级额外移速+10%，与靴子、冲刺及浅水倍率相乘；时钟在单双人开火前推进，暂停不扣、清场等待仍扣。弹丸保留发射时层级，敌弹和原有支援不继承；限时无人机按当前玩家强化同步；轮级恢复保留原剩余量，不重新领取。

`arcade_drop.EnemyMinArena` 仅约束杀敌掉落：0 表示完全禁用击杀来源，正数与 `MinArena/MaxArena` 共同限制开放关卡，负数非法。击杀掉落候选仅含金条、红头骨和紫头骨，基础权重为38:5:2；具体敌人的禁紫资格见下文2026-10-23修正。2026-10-22 起总概率按敌人实际最大生命和伤害计算：`min(EnemyDropMaxChance, DropChance * sqrt(MaxHealth / EnemyDropHealthUnit * max(1, Damage) / EnemyDropDamageUnit))`。当前基准生命20、伤害10、基础概率10%、上限50%；不输入关卡编号。零生命或负伤害不掉落，零伤害使用1作为计算下限。数值为本项目调参值。炸弹、冲刺、临时武器及其他强化的击杀来源均关闭，配置身份、资源和原权重保留供独立来源使用。地图空投和宝箱不检查该字段，继续按原解锁范围生成。配置由 `Config/gen.bat` 双端生成。定向验证：`ArcadeEnemyDropTests` 37项、`EnemyStrengthDropOnline` 6项、`MapWeaponPickupsOnline` 7项通过；未进行真实两客户端联机验收。

地图刷枪使用空投箱：`arcade_rule.WeaponDeliverySeconds=1.2` 秒，前 75% 从空中落到点位，后 25% 自动开盖并显示武器；开箱完成后才可拾取，30 秒地面存留从此开始。单双人分别由本地战斗系统和服务器计时，联机快照保留空投标记及剩余时间，表现按权威进度采样。宝箱等非空投来源的武器仍立即落地可拾取；空投外观和时长是本项目需求，不作为参考游戏规则结论。
