# Another Day Luban Config

`Config/` is the only source for Luban configuration used by both client and server.

- Schema: `Defines/*.xml`
- Data: `DataCsv/*.csv`
- Generator config: `luban.conf`
- Only generation entry: `gen.bat`

Run from the workspace root:

```bat
Config\gen.bat
```

The script generates both targets in one run:

| Target | Generated C# | Generated `.bytes` |
| --- | --- | --- |
| Client | `Client/Assets/Game/Scripts/Model/Config/` | `Client/Assets/Game/Config/` |
| Server | `Server/GameServer/Unity/Assets/Scripts/Model/Generate/Server/Config/` | `Server/GameServer/Config/Luban/` |

Generated files must not be edited by hand. Change `Defines/` or `DataCsv/`, rerun `Config\gen.bat`, and restart the server process for server-side changes to take effect.

`DataCsv/arcade_solo_drop.csv` is a client-only arcade drop table. The first-arena temporary first-person pickup uses weight 5 and duration 20 seconds as project tuning values. The client provider merges it with the shared drop definitions for single-player combat; the server target does not generate this table or add its entry to the online drop pool. The formal generator checks this separation and expects 47 client tables.

`DataCsv/map_display.csv` only generates client-side map display metadata. Map images and their item icons are offline Unity Editor outputs produced by `Tools/地图/生成地图资料图片`; they are not generated by Luban, and no second Luban entry point is supported.
