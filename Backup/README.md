# 备用资料

[Artifacts](Artifacts/) 统一保存开发预览和验证材料，包括截图、GIF、视频、音频、测试报告、检查日志和必要的工具快照。各批材料沿用原目录名称；具体用途和是否已采用以批次说明及[执行总清单](../Docs/Plans/执行总清单.md)为准。

此目录位于 Unity 工程外，不参与游戏资源导入或运行。制作工具的新预览与验证输出统一写到这里，文档使用指向实际文件的相对链接。

- 候选美术资源仍放在 `Client/Assets/Art/`，遵循[美术资源库使用约定](../Docs/美术资源库使用约定.md)。
- 正式游戏美术资源继续放在 `Client/Assets/Game/Art/`。
- 当前方案和执行记录继续放在 `Docs/Plans/`。

历史日志、检查报告和工具快照中的原始路径保留为当时的记录，不代表现行输出位置。目录迁移不代表预览已被采用，也不改变既有验证结论或待验范围。

## 成果与临时文件

- 需要保留和提交：最终预览、用户采用版本、验证报告及其引用证据、必要的制作或验证脚本。不要整体忽略 Artifacts，也不要通配忽略 PNG、GIF、JSON 或日志。
- 不提交的可再生中间产物：动画源帧目录、提交用源码副本、临时配置生成副本、编译缓存、临时依赖、Git独立索引和修改前备份。对应规则限定在 `Backup/Artifacts/`。
- 新工具优先将临时输出放在本批次 `.scratch/`，将最终成果输出到批次目录；旧工具的 `frames/` 等目录兼容现有忽略规则。
- 批次结束后清理不再使用的临时文件。忽略规则只控制Git展示，不替代磁盘清理；已跟踪的成果不因命中忽略规则自动移除。
- 清理时先核对文档引用、Git跟踪状态和近期活动，不删除仍在使用的资料；暂存删除必须核实真实文件及任务来源，不能直接批量提交。
