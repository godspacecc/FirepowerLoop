# 全地图弹道边界候选 v1

范围依据：用户明确“我要求的是所有的都要能射出去，不要只改一个地方”。覆盖全街机关卡、全部弹种、单人与联机。

`boundary-preview.html` 是可播放的规则示意，不是实际对局、实际武器外观或已实施效果。普通／敌方弹、火箭、紫射线三类路径对比活动外框行为，实体墙命中另行保留。示意里的爆炸圆仅表示命中，不提出新的爆炸特效。

Unity临时渲染工具为 `Tools/Unity/ProjectileBoundaryPreview.cs`。早先帧位于Unity Temp，编辑器状态变化后已不在磁盘；本次重录受到编辑器忙碌及MCP查询超时影响，没有可交付的Unity实拍。不把先前工具返回成功路径当成现存录像。

2026-10-23 用户回复“可以，不要反弹就行”，已采用此动态规则并授权正式接入。最终规则同时取消紫射线对实体的反弹；示意中的旧版对比保留为问题说明。

正式实现：单人与服务器取消普通弹、紫火箭、紫射线的外框拦截；码头水面只阻挡行走；所有弹种对实体仍命中，按寿命回收。紫射线反射配置归零，并在命中入口直接结束，旧在途反射余量也不生效。未改正式视觉资源、场景或人物活动范围。

验证：Unity定向59/59，联机定向35/35通过；全地图用例遍历88轮图、4类弹道分支及四方向。新用例先复现单人0/6、联机0/7，再验证修复。独立只读代码审查通过。旧联机桶计时测试补齐地图加载确认后7/7通过；未运行完整套件、Player Build或真实双客户端验收。
