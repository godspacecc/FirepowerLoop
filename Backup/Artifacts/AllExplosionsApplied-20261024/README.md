# 九项爆炸候选正式接入

2026-10-24，用户在完整展示 [AllExplosions-v1](../AllExplosions-v1-20261023/README.md) 的三组右侧候选后回复“可以”。确认覆盖7项效果精简和2项反馈补齐，并统一用于单人与双人。

## 实现

- 五个正式Prefab共9处Renderer关闭：紫桶的火星／桶身碎片；清场炸弹的火星／碎片／放射光条；无人机与集束榴弹主／子爆的飞散火星；敌人爆炸死亡的血肉碎屑。爆心、烟雾、冲击波、血雾及地面薄尘保持，未删除对象、材质或meta。五个Prefab的meta保存前后SHA256一致。
- 能量弹不再放射火星，青蓝中心闪光尺寸×1.35、寿命0.32秒；池中缓存原尺寸、寿命和颜色，交替复用时恢复普通橙色爆炸原参数，容量仍为12。
- 诱饵到期和玩家爆桶真实触敌时补上已采用的橙色爆心。旧强化槽、现代普通环绕槽、购买环绕桶实例均沿原结算点调用；保留伤害、半径、次数和冷却。现代环绕桶使用实际桶身点，空场诱饵到期仍有反馈，房间内到期不误播。
- 服务端复用既有Kind=3武器反馈、128条有界列表、战斗内单调序列和快照深复制；客户端复用既有时效／基线／去重与声音限频。未改协议、配置、伤害数值，未给无人机追加重复的武器爆炸事件。

## 正式回读

[对照图](comparison.png)左侧为采用版候选，右侧为正式资源回读；[逐帧记录](frame-verification.json)包含9项各48帧的SHA256。正式回读取消临时隐藏覆盖，能量和新增爆心调用正式表现方法，其他效果回读正式资源及既有表现类。

能量、无人机、集束主／子爆、诱饵各48帧逐像素相同。清场、死亡、环绕桶存在细小颜色差异，但每通道超过3/255的变化像素数为0；紫桶最多1.2012%像素不同，未宣称所有粒子帧完全一致。源Prefab仅指定Renderer开关变化，材质及粒子参数未改，主体和隐藏图层已结合代表帧核对。回读为隔离场景，不是真人联机录像，不含声音。
