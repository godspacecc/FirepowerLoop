# 武器反馈单双人对齐

用户先确认仅补齐武器命中／撞墙／爆炸反馈，篝火与第一人称暂缓。现有反馈动态预览为 `existing-feedback.gif`；用户指出外围飞散效果不好，查看 `refined-feedback.gif` 后明确“采用右下，单双人统一”。两段均为正式模板与现有表现代码在隔离场景的动态录制，不是真人联机录像。GIF无声。

实现将服务器真实结算点、来向、半径和时刻同步到客户端；客户端不从弹丸消失猜测命中，首次／重连建立基线，重复／旧轮／过期反馈不重播。暂停、房间、加载期间消费序列但不播放。身体命中和撞墙按单人三枪白名单处理，紫射线墙面沿用专用入口，爆炸从统一结算入口发出。沿用原有声音、距离衰减和限频。

普通武器爆炸关闭外围Sparks，保留橙色主体，单人与双人共用；能量爆炸、紫桶和快捷炸弹各沿用原表现。复用前清空池槽，能量→普通→能量不会串色或残留上次火星。
