## 制作与验证

`Tools/Unity/AllExplosionsPreview.cs`通过Unity MCP分别录制9类，使用正式Prefab克隆与既有炸弹／死亡表现类，修改仅作用于临时实例；未调用Prefab保存、资源落盘或业务接线。每类左右各48帧，共864张600×420原始帧。

编码脚本 `Tools/Unity/encode-all-explosions-preview.py`核验每项48帧、20fps、2.4秒，三组分别192／144／96帧，共21.6秒，成品1200×545。9项代表帧已目视检查。录制后MCP回读本工程路径，编辑态、无编译失败、Boot未脏。未运行玩法测试或Player Build，因为本次未修改运行时代码。
