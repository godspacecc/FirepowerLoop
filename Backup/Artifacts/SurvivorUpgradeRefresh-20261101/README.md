## 刷新规则

已确认：整局免费共享3次，升级不补充，重开恢复3次；不是每次升级3次。

最新修正：每张卡片下面单独刷新，只更换所点卡片，另外两张保持不变；任意单卡刷新均消耗共享次数1次。拟定待随预览确认的边界：排除该旧卡及另外两张，过滤满级项、未持有武器强化、互斥路线，保留既有首次无人机保底；没有合法替代项则不扣次数并禁用该槽刷新。刷新不消耗经验、不给强化、不解除选卡暂停；成功才扣次数并更新版本防旧卡或快速重复点击多领。0次时三个刷新按钮置灰，升级后保留剩余次数。

具体命名、字号与按钮布局尚未采用；用户确认后接入正式View引用、Controller、本局权威计数与Config来源，并做有界测试和真实资源收集检查。当前不把静态预览当成可操作功能已完成。
