# 第五版：整卡选择

用户2026-11-01修正“选择强化没必要用按钮吧 点击整个卡片应该就可以了”。本版取消独立金色勾选按钮，整卡作为选择热区，悬停时以暖金边框及稍亮底板反馈。卡片与外框缩短68像素，去除原按钮占位，提示文案为“点击一张卡片，获得强化”。

- preview.png：默认状态。
- hover-preview.png：中间卡片悬停视觉示意，未额外弹出确认按钮。
- single-refresh-preview.png：只换第一张，另外两张像素完全相同，三个刷新图标内共享计数同步3→2。
- exhausted-preview.png：图标内0并置灰，整卡仍可选择。

刷新按钮在卡片外部，是独立兄弟对象，不作为卡片选择热区的一部分；预期点击刷新只换对应卡片，不会获得该卡强化。整局仍共享3次，不是每卡各3次。
