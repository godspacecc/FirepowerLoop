# 多语言编辑器保护静态记录

标题统一；草稿含未通过校验的键和所有文字，SessionState按工程隔离，窗口关闭和脚本重载后可恢复，本次Unity会话退出后不保留。重载需确认，成功才清缓存；加载失败停止编辑。严格原始配置读取与语言JSON解析，缺键仍可在编辑器中修复。

窗口保存前对比全部语言JSON字节快照，临时文件准备完成再比一次；先准备全部文件再逐个替换，失败逆序尝试恢复，核对恢复字节并明确报告恢复失败。不删除移出清单的旧语言文件或meta。新增语言标明待翻译。生成失败仍明确语言表已保存；此时可独立重试生成，窗口后续保存会要求重载更新基线。

独立C#9语法解析1份源码零错误；静态核对草稿恢复、无状态绘制保护、保存前/准备后冲突检查、逆序恢复及原生成调用保留。没有运行交互或磁盘故障注入验证。多文件操作不是跨进程事务：外部程序在最后核对之后同时写入、进程退出/崩溃不保证自动恢复。

未操作Unity、运行测试、实际保存语言文件、生成代码或构建。
