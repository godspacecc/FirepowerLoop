# 重型候选分开筛选

这两张是本地Asset Store原包缩略图，不是Unity正式替换效果或AI图。仅按真实外形分开筛选，不把缩略图等同动画/挂点验收。

- Meshtint Free Barbarian / Barbarian Wyder.FBX：矮壮低面轮廓可以支持重型辨识，但大头盔和短肢与已接入的军服感染兵比例明显不同；本项目Humanoid重定向、攻击长度、挂点及碰撞匹配尚未验证。
- Barbarian warrior / Barbarian.fbx：肩甲和皮革细节更密集，当前明快清晰低面军服风格下反而杂；仍未完成本项目动画和材质验证。

本批不将任一候选称为已完成重型替换。现有Brute/Boss保持，继续使用正式既有动作与战斗规则。轻型士兵六变体、主题配色和同款背景独立交付。后续如采用重型候选，必须另建本项目必要副本并验证，原包及另一项目只读；不得直接拷贝玩家数据或Library。
