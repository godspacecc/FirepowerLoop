[被否决v1与修订v2动态对比](v1-v2-posture-comparison.mp4) · [正式现版与v2对比](zombie-ground-walk-comparison.mp4) · [预览页](index.html) · [检查记录](audit.json)

v1的问题来自持续将骨盆压低12.5厘米以上、为足端可达继续下降、摆腿抬脚过高及双腿长期深弯；此前数字检查过度关注抬脚与足端漂移，没有约束站立高度和支撑腿姿态。v2删除固定骨盆下沉与额外横向晃动，缩短步幅/周期，普通与瘦弱脚部抬起约6.5厘米、重型约5厘米；支撑腿接近伸直，迈出的腿才适度屈膝。保留原上身移动片段，身体只在当前步幅超出骨长时少量下降，不改变骨长或模型比例。

两条完整视频均18秒、360帧、20fps、1280×720、无声，三种丧尸各6秒（常用俯视角3秒、半速低机位3秒），正式主角持AK原尺寸同框。v1/v2同机位同时间，相同0.9米/秒人工演示位移；正式三种敌人速度并未因此统一。

本版增加姿态检查：骨盆额外下降平均约2.2—2.4厘米、最大4.7厘米；每帧至少一条腿的屈曲不超过约7.6度，不再双膝持续深弯。支撑期单腿范围约7—34度，摆腿最高约46—50度。足端解析求解改为骨盆局部坐标，适配三种原有非等比体型缩放，样本精度内目标误差和连续接触期水平漂移均为0。以上只证明本段临时候选满足数值约束，动作是否自然仍以用户看视频为准。

122个正式文件前后SHA256一致；完整视频解码、18秒/360帧参数、三种体型和代表帧已检查。结束本项目Boot编辑态未脏、无编译/导入与Console错误；无业务测试、资源打包或Player Build。人工直线轨迹与临时骨架采样不能代替实际追击、转向、攻击衔接或真人双端验收。

v2具体视觉待采用，正式接入尚未实施。码头海中攀爬v2独立保留待采用状态，不因地面步态修订而接入撤通道或攀爬出生规则。v1视频与其源码快照保留于上一批目录。
