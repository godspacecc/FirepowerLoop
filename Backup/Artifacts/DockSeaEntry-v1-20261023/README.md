候选去掉右侧全部外伸木通道与横向连接段，保留主平台、其他两路、绳栏、货箱和停船。三只便服丧尸依次从海里露出上半身靠近，在原右侧缺口抓边、撑身、抬腿上平台、起身恢复行走。正式主角同框作为比例参照。

视频15.2秒、304帧、20fps、1280×720：开头3秒布局对比、9秒完整动作、3.2秒半速近景。不含声音。

这是Unity临时场景里的正式地图和角色克隆，骨架动作及位置由人工时间轴采样；不是实际对局、实际碰撞或已接入单双人出生规则。水面波纹为独立临时提示。当前试做只检查方向与动作效果，不宣称游戏逻辑已经完成。

正式Prefab和7个正式码头合并网格，共8个源文件的SHA256在制作前后相同，见[原始哈希](formal-source-hashes.json)与[输出检查](audit.json)。候选仅复制网格并过滤临时实例上的1344个右侧木板三角面；原网格未写入。临时场景未保存，结束Boot无脏状态。

视频已完整解码检查，靠近／抓边／撑身／上平台／站起代表帧已人工查看；没有运行业务测试或Player Build。制作中曾将Generic丧尸当作Humanoid读取骨骼导致临时调用失败，已改为缓存正式骨名并重新生成全部有效帧；最终输出来自成功的完整采样。
