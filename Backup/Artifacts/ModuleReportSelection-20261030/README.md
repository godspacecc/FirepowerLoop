# 模块报告选择与说明静态记录

范围：保留原菜单，提供最近修改报告/手动选择/取消，展示选择依据、报告平台版本时间，展示全部已统计标签，明确标签重叠及下载量区别。读文件或枚举目录异常给出失败提示。

独立Roslyn C#9解析1份源码，零语法错误，见syntax-check.json。源码精确比较确认收集器检查、报告解析统计、构建报告校验及结果数据结构保持不变；无构建或切换平台调用。自动选择仍按文件修改时间，时间相同按路径排序。人工审阅取消、缺少报告、读取失败及多标签展示分支。

仅静态检查；未操作Unity、编译Unity工程、运行测试、真实文件选择交互或构建。未验证编辑器实际弹窗行为。
