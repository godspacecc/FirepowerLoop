# 第二关电塔外形与蓄能候选

来源：2026-10-23 用户指出第二关电塔“不太形象”，塔上没有电流蓄能，塔本身也不像电塔。本批仅制作视觉候选，待用户明确采用后再制作、替换或接入正式资源。

`tower-comparison.gif` 来自 170 张、20 fps 的 Unity 隔离临时场景渲染，播放 8.5 秒循环，非实际对局录像。GIF将安全阶段相同画面合并为92帧，总播放时长保持8500ms。左侧直接调用正式 ArcadeHazardPresentation 和 ElectricTower 模板；右侧全部为独立内存网格、材质和候选动作；中间加载正式 GrayboxPlayer 与基础武器作同框比例参照。脚下木平台为临时比较背景，不是码头正式环境。

候选采用金属变压器底座、铜线圈、陶瓷绝缘盘、侧电极及冠顶放电环。安全阶段熄弧，预警阶段电流向上聚集、顶部电团逐渐增强，通电阶段从塔顶闪出分叉电弧。周期与 1.2 米半径直接读取正式21号码头配置：安全4秒、预警1.5秒、通电3秒，不改变玩法、伤害或判定。

`safe.png`、`charging.png`、`active.png` 是相同镜头的三个代表状态。GIF字幕仅用于本次候选说明，不是新增游戏HUD。

生成入口：`Tools/Unity/ElectricTowerPreview.cs` 由 Unity MCP script_execute 动态执行，不放入 Assets、不保存场景、不保存 Prefab。结束销毁临时对象与素材并关闭附加场景。编码入口为 `Tools/Unity/encode-electric-tower-preview.py`。
