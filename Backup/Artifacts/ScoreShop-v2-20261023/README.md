## 本次修正

用户要求只加入现有空投箱能有的商品，不加入新东西。正式单双人空投代码筛选正权重TemporaryWeapon／Support，并按MinArena／MaxArena限制；当前全池为喷火器、速射、散射、穿透射线、火箭、榴弹、镭射枪和支援无人机。

撤回v1中的炸弹、冲刺、旋转锯、战斗鸡、护甲套装及磁铁／火力专精建议。效果、数量和基础时长均按原有空投。用户随后以“是的 强度你看看合适吗”采用本版界面和价格；保留固定500刷新，已完成强度核对与接入。

本页以海岛结束、即将进入第2关为例：可选项只有喷火器、无人机、速射、散射四种；同屏三项不重复，刷新至少替换一项。按下一普通关序号过滤并在其开场领取已作为正式流程实现，后期空投武器不会提前出现。
