# 中文字体重建工具静态记录

菜单改名重建中文字体图集。独立内存TMP字体按原采样/图集参数重建，采用原材质属性和临时纹理，在隔离预览场景渲染样例，保存PNG及说明到Backup/Artifacts/FontPreview批次。缺字/空白截图/异常不提供正式写入；预览窗口取消或失效不写资源。多图集开启变化明确展示。

正式确认检查运行态、未保存字体、字体/meta、源字体/meta及清单变化；正式修改前持久备份资产与meta到FontRecovery批次，只SaveAssetIfDirty目标字体；失败恢复检查完整资产字节、字符集合、填充模式和多图集设置。应用字体菜单和Unicode过滤逻辑保持。

独立C#9语法解析1份零错误；静态核对正式入口仅从预览确认调用、备份早于源引用修改、无全局SaveAssets、应用入口至恢复方法前代码精确保持。未操作Unity、生成实际预览、更新字体、查询收集、运行测试或构建。实际TMP渲染、保存/恢复及正式UI显示均未运行验证；不代表字体发布/加载验证。
