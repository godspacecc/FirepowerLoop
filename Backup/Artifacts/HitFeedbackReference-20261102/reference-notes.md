# 外部受击反馈参考核对（2026-11-02）

本记录只核对外部官方资料，不以 FirepowerLoop 现有反馈为基准。未操作 Unity、未修改正式资源；下列项目建议仍是待用户看动态预览后确认的设计推导。

## 已核实的事实（3 个来源）

1. [Microsoft 官方 Halo 2 受伤动画文档](https://learn.microsoft.com/en-us/halo-master-chief-collection/h2/art/animation/animationdamageanims)：明确按伤害类型、方向、身体部位组织动画。轻伤使用叠加动画，重伤使用状态动画，通常表现为踉跄或侧移；方向包含前后左右，部位包含头、胸腹及四肢。这直接支持“方向／部位相关的身体反应”和“普通命中与明显硬直分层”，不证明每一枪都应造成停顿。
2. [Capcom《Resident Evil 4》官方操作手册](https://game.capcom.com/manual/re4/en/ps5/page/2/2)：聚焦准星后的射击提升敌人的硬直与暴击概率；完美招架造成明显硬直并提供追击机会。这支持“命中不等同于保证硬直；明显硬直具有战斗意义”。本次通过搜索工具读取官方手册正文，直接打开该站可能受访问限制。
3. [Halo Infinite 官方护盾说明](https://support.halowaypoint.com/hc/en-us/articles/24284987877524-Shields-in-Halo-Infinite)：自己的护盾耗尽时有低音警告，护盾条闪红；敌方普通护盾受击发光，破盾另有明亮闪光与后续能量火花。这支持“普通受击、关键状态变化、玩家危险提示分别表达”，并非本项目必须引入护盾规则。

## 对本项目新候选的推导（不是原作复刻事实）

- 命中点：在实际接触位置给短促局部提示，使玩家能辨认击中了谁、哪里。以上来源没有提供局部火花尺寸、颜色或持续时间；这些需在本项目预览中设计。
- 方向受力：身体向来弹受力方向产生短促偏转，再恢复姿态。以外部游戏的方向／部位反应原则为依据；具体偏转、位移量和恢复曲线为项目候选参数。
- 反馈分层：普通命中保留持续移动／攻击的可读性；只有游戏实际发生硬直或打断时才使用更明显的停顿或后退，避免视觉误导。
- 玩家危险：玩家受伤与敌人中枪使用不同提示层；严重危险再追加清晰警报。若候选使用屏幕红边、方向扇形或闪白，应标明为本项目方案，不能称为上述原作已核实的表现。
