# 幸存者地图尸潮：实现与验证

2026-10-31。用户确认“采用这个方向，继续接入”，采用 [动态规则示意](horde-preview.gif)。示意不是正式角色实拍；本次沿用正式模型、爬出动作及场地资源，没有制作新美术。

## 玩家行为

- 开局按固定地图分区建立视野外敌群，外围轮换方向成批向玩家推进；附近只保留少量爬出。
- 找不到安全、可达落点时跳过本次出生，不积压补刷。不设置活敌人总上限，保留敌种按时间解锁及固定属性。
- 远处新敌人只保留群体数据，每0.25秒沿体型共享导航推进；进入视野准备带后正常每帧最多展开2名。已见过的敌人离远后保留实际身份、血量和状态，不产生死亡或掉落。
- 已可见角色优先恢复：极端相机突变可超过常规准备预算，避免隐形敌人。此路径及近场无上限聚集没有恒定帧耗时保证。
- 加载时逐帧预热角色及导航，闲置池每种最多16个；这是缓存上限，不是存活上限。表现失败保留远场数量，暂停并给出错误；入口预热失败仍留在加载失败流程。
- 自动选敌和弹丸使用空间候选，爬出身体仍走原胶囊精判。

## 最终权威配置

3×3铺怪分区，每个成功分区6名；外围每8秒18名；每4次原附近出生周期保留1次爬出；远场步长0.25秒；每帧正常展开2名；准备/退出余量6/10米；每个出生候选最多8次尝试。数量可继续依据实际玩法反馈调校。Config/gen.bat 已双端生成；生成日志见 generation-budget.log。

## 真实资源与运行

资源检查实际调用 YooAsset BeginCollect，验证敌池三种实际请求地址对应 ArcadeZombieShambler、ArcadeZombieGaunt、ArcadeZombieBloated，标签 arcade；敌池配置 tbsurvivorenemy.bytes 标签 startup，正式爬出泥土材质与动画依赖存在于收集链。入口沿用既有 EnemyCtrl 敌池预加载事务，再执行实例预热；不会给每名远场敌人发资源请求。

真实Play从菜单按钮进入加载流程，使用实际 EnemyView 和资源。live-before-warmup / live-after-warmup 为移动试玩采样；live-budget2 是最终预算的静止压力输入。截图 [最终压力试玩](live-budget2.png)。临时探针仅本次Play锁生命并选择升级，结束自动退出Play；没有把保命或测试群写入正式规则。最后确认仍为 FirepowerLoop/Client、Boot、非Play（context-exit.json）。Console 最近错误为 MCP 断线重连日志（errors-final.json），探针未记录玩法 LastError。

以上为源收集及编辑器真实运行证据，未打包，未验证下载服务器、发布包或目标设备。

## 性能实测及边界

最终18秒采样共1327帧，第6秒在准备带以外加入一个静止的10000人群。它是受控压力输入，不是正式玩法配置。详见 live-budget2.csv、live-budget2-status.txt、performance-summary.json。

| 指标 | 加入前2～6秒 | 加入后8～18秒 |
|---|---:|---:|
| 样本数 | 444 | 436 |
| 完整战斗实体最大数 | 25 | 56 |
| 远场人数最大值 / 群数 | 24 / 4 | 10036 / 6 |
| 尸潮调度 p50 / p95 | 0.0193 / 0.0300 ms | 0.0205 / 0.0836 ms |
| 尸潮调度 p99 / 峰值 | 0.0878 / 0.1458 ms | 6.808 / 8.684 ms |
| 整帧 p50 / p95 / p99 / 峰值 | 8.447 / 12.595 / 18.573 / 32.007 ms | 20.663 / 39.768 / 48.484 / 69.013 ms |
| 整帧GC p50 / p95 / 峰值 | 34865 / 41579 / 101176 bytes | 63483 / 126739 / 604737 bytes |

一万远场人数没有创建一万模型，调度常态成本随群数而不是人数增长。展开仍有创建开销，近场角色与全游戏渲染仍随实际活跃数量增加；整帧GC不是尸潮模块专属分配。前后活跃敌人数与战斗阶段不同，不能把整帧差异当作单变量对照，也不能宣称稳定60帧或零GC。

前一轮预算4的样本中调度峰值22.86ms；预算2样本为8.684ms。两轮出生随机、活跃数和编辑器负载不同，只支持选择更小批量，不构成严格同输入加速比例。首次冷启动的旧记录出现大尖峰，已将实例/Animator及导航预热移到加载流程，不以平均数掩盖旧记录。

原计划的完整分辨率矩阵、100/1000/10000逐档实战、长时间内存趋势和同路线改前改后基准未执行；本轮以事务/空间规则、短程真实移动、最终一万远场受控采样和模块标记验证本次交付，明确不覆盖这些扩展性能结论。无上限玩法的长局群数和已展开个体例外仍会增长，没有偷偷删怪或恢复总量封顶。
