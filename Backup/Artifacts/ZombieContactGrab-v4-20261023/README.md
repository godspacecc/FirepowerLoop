## 根因和候选

旧v3是固定摆位/时间的动作采样：敌人X=-0.9、玩家X=0.6，中心相距1.5米，按时间起手，并未验证手指是否触及玩家。正式普通近战目前也以PlayerRadius 0.55+EnemyContactRadius 0.95=1.5米判定前摇范围，未按爪子可达距离单独判断。身体碰撞范围还用于行走/弹丸等，不能直接为修正抓挠而整体缩小。

本版隔离候选将起手门禁设为中心距离0.9米，使用正式敌人配置的移动速度和TelegraphSeconds，并调用正式TryCompleteMeleeAttack推进前摇。先追近，进入门禁后停步起手，完整0.4秒后前抓；第二段玩家跑开，取消再追。起手不再只由固定时间决定。0.9米距离和停步仍为预览输入，不是已经修改的正式规则，也不是完整单人/联机实录。

## 接触验证

候选手掌目标配合更近的位置调整，保持已采用的大幅后拉、前抓、内撕风格。正式主角与三种正式丧尸原尺寸同框，骨长/模型大小/相机不变。挥出时测量手指到主角实际采样网格三角形的最近距离：普通约0.2厘米、疾行约1.82厘米、重型约1.66厘米，关键帧已查看。距离阈值内开始到挥出均为0.40秒；三种各1次挥出、1次离开取消、0次范围外起手，见timeline.csv及inspection.txt。三段各100帧/20fps/5秒，编码和帧数/时长检查见verification.json。

正式Prefab、AnimationClip、AnimatorController、战斗/表现代码及Config均未修改；未运行测试或打包。当前大幅动作已确认，接触距离/停步具体动态待采用；正式范围与表现同步接入、单双人定向验证仍未完成。
