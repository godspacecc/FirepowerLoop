候选在临时克隆上用两段手臂旋转明确手掌轨迹：先约0.3秒后拉张臂，随后0.1秒前抓，在完整0.4秒处达到接触姿态，再向内下方撕扯并恢复。上身配合小幅蓄力、前倾及转身；取消时收手再追击。没有放大模型、改变骨长或提高镜头倍率。

三种正式丧尸与正式主角原尺寸同框，左侧为空手丧尸、右侧持枪者是主角。每段80帧、20fps、4秒，另有同时间刻度的v2/v3原速对照；对照采用同一相机和相同背景裁切。GIF帧数/时长已自动核验，资源触发与武器挂载检查见inspection.txt。
