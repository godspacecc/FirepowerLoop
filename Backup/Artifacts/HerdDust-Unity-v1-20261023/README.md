11.6秒，232帧，20fps，1280×840，H.264＋AAC双声道。画面由Unity本项目中正式农场、牛、主角和丧尸Prefab的隔离克隆直接渲染，没有AI修饰。尘团为本次临时程序面片；音频为离线合成后按同源落蹄CSV混入，非正式AudioSystem实录或真实战斗。

- 0–0.8秒：起势刨地小尘团、刨地声和低沉鼻息候选。
- 0.8–6.4秒：五牛前后纵队，正式尺寸、3米间距、7.15米/秒；主角同框作体量参照。临时蹄下薄尘，蹄声随与参考主角距离变化。
- 6.4–8.4秒：蹄下¼速近景，保持原音高，观察土尘扩散／消失。
- 8.4–11.6秒：一次接触土尘和闷撞，丧尸轨迹仅作既有击飞体量参照，不证明碰撞／伤害实装、不改变其他任务的玩家侧向落点。

牛腿动作取正式ArcadeHerdVisual，临时给不同牛错开0.07秒相位以展示交错蹄声。尘团低矮、有限寿命，切镜丢弃上一段事件；合成透明面片避免同步编辑器录制不推进原生粒子循环的问题。没有导入Assets或修改正式Prefab。新增素材只有预览目录中的音频与图像；编码器和临时录制源码位于Tools/Unity。
