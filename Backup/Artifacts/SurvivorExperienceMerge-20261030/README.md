# 经验掉落名称与邻近合并预览

- 用户要求去掉经验道具名字HUD，掉落在一起只显示一个。
- 原建议（已否决）：附近1米内的新经验累加到已有晶体。用户修正“不用 我是说完全重叠的可以合并”，不实施邻近半径合并。
- `comparison.png`为独立PreviewScene中用现有正式主角、经验晶体及拾取模板制作的临时模型数量示意。左侧三份邻近经验，右侧一份累计经验；非正式游戏实拍。此隔离渲染未显示原名称HUD，不作为旧HUD的前后实拍对比；右侧表达拟采用的无文字显示效果。
- 实施：完全相同落点才累加经验，使用Vector2.Equals，不使用带近似距离容差的==；保留原ID、原位置和晶体尺寸。旁边落点不同的仍独立，不显示名字或数量。100%掉率不变。
- 名称隐藏复用LootCtrl空displayName的已有路径，不修改通用拾取Prefab，其他道具名称不受影响。累计经验仍由SurvivorSystem拾取流程增加；沿用原数量上限及满额保全经验机制。
- 回归：同落点合并与空名称两项先失败，邻近不同位置原先通过；修复后SurvivorRuntimeTests限定29项全部通过，includePassingTests=true。新增1e-6米坐标差仍不合并的边界覆盖。
- 代码审查无阻断，定向diff --check通过。未改模型/配置/资源地址，未资源打包或Player Build，未整局人工试玩。
