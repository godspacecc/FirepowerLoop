# 幸存者农场自然地形边界预览

- 用户提出将玩家不能去的区域表现为山体、河流或海面，减少场外敌人被攻击以及经验落在不可达处的问题；范围明确选择“先调整当前幸存者农场地图”。
- 目标：自然地形清楚表达不可通行边界，敌人沿合理通道进入农场后参与战斗，经验留在可拾取地面。本次新要求优先于此前农场普通敌人在场外即可受击的冲突部分；其他模式不纳入本次改动。
- 候选方案：北、西、东三面低多边形山体，保留北山口及左右山口；南侧河流和桥梁入口，保留农场内部围栏、建筑与活动区。山体遮挡应与真实碰撞/弹道一致，自动索敌与经验落点按可战斗/可拾取区域裁决，不能仅加装饰后保留场外击杀问题。
- `boundary-overview.png`为全景，`boundary-detail.png`为与正式主角同框的尺寸近景。均为独立PreviewScene：复用正式农场、关闭临时副本的部分外圈树篱/墙渲染，叠加临时山体、河面、桥梁素材。不是正式接入后实拍，也不是已验证的导航/遮挡效果。
- 正式Prefab、Mesh、材质、配置和战斗规则未修改；三个山口/南桥的具体地形与行为方案等待用户确认。此前属性面板预览继续保留待确认，不因本任务取消。
- 确认后需同步真实地形边界、配置阻挡与入口、敌人安全出生/入场、索敌/命中和经验可达性，按Luban权威源生成并用resource-load-check核对动态资源。不得只改变画面或只加场外免伤来冒充自然遮挡。
