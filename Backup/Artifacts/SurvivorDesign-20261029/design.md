# 单人幸存者模式设计 v1

已确认：单人、固定竞技场、无尽生存、仅移动操作、自动射击、经验升级三选一。闯关及原双人规则保留。

## 玩家流程
开始页选择闯关模式进入现有新局/继续/结果流程；幸存者模式直接准备独立单人局。准备失败返回菜单并允许重试，重复点击不重复开局。双人入口明确归属闯关。
进入固定竞技场后自动瞄准射程内最近的可攻击敌人，保持原射击间隔；无目标时不射击。玩家仅移动，无需手动瞄准、射击或使用主动技能。敌人从边缘安全位置持续刷新，不能贴身生成。
击败敌人掉落经验，靠近拾取。经验达到阈值暂停战斗与生存计时，显示三个不同且可生效的强化；选择一次后恢复。连续升级排队逐次选择，不丢失经验或重复应用。
敌人数量与强度随有效生存时间增加；设置同屏敌人和掉落数量上限，达到上限延迟刷怪而不无限堆积。没有通关终点。
阵亡结算分数、时间、击杀数，提供再来一次与返回菜单。持久化仅本局结果与分数；首版建议不支持幸存者中途续局，退出时明确提示本局结束，不影响已有闯关进度。

## 实现边界
已检查 StartUICtrl 的独立开局绑定及已有存档入口，ArcadeCombatSystem 具备射击、拾取和强化基础。推荐增加独立幸存者局状态与规则，复用战斗投影和基础能力；避免将无尽刷新塞入现有四轮/过关/商店推进逻辑。具体共享接口在实施计划中明确。Model 保存状态，System 负责规则，Controller 转发操作，View 展示；配置以 Config 为权威并通过 gen.bat 双端生成。
首版建议复用现有主角、敌人和已采用场地素材，不新增角色模型或攻击动画。具体竞技场、经验掉落及HUD的实际视觉仍需后续预览；本次图仅确认菜单与三选一布局，不授权未展示视觉。
