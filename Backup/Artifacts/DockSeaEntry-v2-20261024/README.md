本版让两腿独立运动：水下错相划动与踝部摆动，抓边后收膝，前腿明显抬膝越过边缘、脚掌落地，后腿随后蹬起并补步，起身时逐渐伸膝并接回正式行走。保留原右侧缺口、撤通道、三只敌人错峰及正式主角尺寸参照。

v1主要以整体抬升／倾斜表现攀爬，中段采样Idle且只有一次单腿目标，膝盖与脚踝没有连续配合；本版全程采样连续步态，独立求解左右髋／膝／踝，落脚段约束脚掌位置与朝向，最后平滑释放到步态。保持头脸附件与身体的倾斜关系，以髋部为支点并分别约束两腿。

17.5秒、350帧、20fps、1280×720，无声。前3秒保留布局对照，接9秒正常速度演示，末5.5秒以半速显示收膝到站稳的腿脚近景。正式主角同框，近景只用于看动作。

输出检查见[audit.json](audit.json)：完整视频解码通过；8个正式码头源文件制作前后SHA256一致。[腿关节与足部记录](leg-motion.tsv)采样180个正常速度帧，检查攀爬期间左右膝屈伸变化均超过25度；这些数值只证明临时骨架动作存在，动作是否自然仍以用户查看视频为准。代表帧已目视检查。
