# 幸存者移动顿挫与出生可见性

## 移动性能

- 正式农场：半宽半高30.5米，50个静态障碍，0.4米导航格。站立复用目标，玩家换格则重算共享距离场。
- 原实现重算时，对每条格间边反复遍历所有障碍并做精确线段检查。20次交替换格平均50.3546ms，站立0.00068ms。
- 修复：建图时缓存静态格间双向通路，移动时广搜只遍历缓存；实际追击仍检查精确障碍，避免穿围栏或切角。
- 同样20次目标交替：移动平均0.253875ms，站立0.000535ms。一次准备121.107ms，准备阶段完成，未转移到每帧。
- 新回归测试先失败：20次换格触发998340次障碍遍历；修复后0次。SurvivorNavigationTests限定4项，全部通过，includePassingTests=true。覆盖所有农场入口、移动目标与对侧追击。
- 只读代码审查无阻断。此为局部计时与导航验证，不能代替完整游戏帧率或用户手感验收。未Player Build。
