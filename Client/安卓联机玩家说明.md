# 安卓联机玩家说明

## 开始前

- 安卓手机和运行联机服务器的电脑必须连接同一个 Wi-Fi；不要使用访客网络或开启了“客户端隔离”的热点。
- 安装部署者提供的 `AnotherDay-test.apk` 或 `AnotherDay-host-test.apk`。
- 首次安装测试包时，Android 可能提示来源未知；只安装来自可信部署者的 APK。

## 进入联机

1. 请服务器部署者先启动电脑上的 `启动联机服务器.bat`，并保持服务器窗口开启。
2. 手机保持连接同一 Wi-Fi，启动 Another Day。
3. 在开始界面选择“联机”，把服务器窗口显示的“同一 Wi-Fi 安卓地址”完整填入“服务器地址”，例如 `192.168.1.20:31001`，然后点击“保存地址”。
4. 新玩家选择注册；已有账号直接登录。用户名为 3～20 位 ASCII 字母、数字或下划线，密码可以为空，非空时为 1～8 位 ASCII 字母、数字或下划线。
5. 登录后可以创建房间，或输入房主给出的 6 位房间码加入。服务器地址只能在退出登录后修改。

## 无法连接时

按顺序检查：

1. 确认电脑服务器窗口显示“服务器进程已启动”，没有端口占用或异常退出提示。
2. 确认手机与电脑处于同一局域网；关闭手机移动数据后重试，可排除系统切换网络的影响。
3. 核对联机界面保存的地址是否与服务器窗口显示的“同一 Wi-Fi 安卓地址”一致。
4. 请部署者确认 Windows 当前网络类型为“专用网络”，并允许入站 TCP 端口 `31001`。
5. 公司、校园、酒店和访客 Wi-Fi 常会阻止设备互访；这种网络下请改用允许局域网互访的路由器或个人热点。

更换 Wi-Fi、电脑或电脑局域网 IP 后，在联机界面重新保存服务器窗口显示的新地址即可，不需要重新安装 APK。

## 更新安装包占用空间

包含自动清理功能的新版 Boot 会在每次启动时，按实际已安装版本清理游戏内下载的已安装及更旧版本安装包。取消安装或稍后更新时保留尚未安装的新版包；清理失败会在下次启动重试，不影响存档及资源缓存。

此功能需要重新生成并安装完整 APK，单独更新 Game 代码和资源不会生效。旧版下载时没有版本记录的安装包无法可靠识别，仍会保留。

## 卡在启动界面时

新版首包会在 `内部存储/Android/data/com.anotherday.game/files/Logs/boot-startup.log` 保存最近一次启动诊断，包括应用和资源版本、主场景加载、游戏初始化阶段，以及启动期间的警告与异常堆栈。

- 每次启动会覆盖上一份，上限为 256 KiB；卡住后先复制日志，再重启游戏，避免覆盖现场。
- 将 `boot-startup.log` 提供给部署者；若同目录还有 `boot-error.log`、`runtime-error.log`，一并提供。
- 文件管理器能否访问 `Android/data` 取决于手机系统权限。
- 该功能在 APK 内置 Boot 中，必须重新生成并安装包含此改动的首包，单独更新 Game 代码和资源不会生效。
